# Контракт Somewhere

[openapi.yaml](openapi.yaml) — машинный контракт первого рабочего среза:
вход, назначенная встреча, приглашение, RSVP и чат. Общие примеры находятся
в [fixtures/cases.json](fixtures/cases.json). Дизайн и бизнес-правила —
в [api.md](../openspec/changes/gathering-activity-feed/api.md).

Наличие операции в контракте не означает готовность её реализации.
`x-implemented: true` отмечает зарегистрированные маршруты. Сейчас работают
`GET /healthz` и анонимный `GET /api/v1/invitations/{token}`. Остальные маршруты
пока возвращают общий 404; вход, собственный RSVP в preview и приватные операции
добавляются после модуля identity. Сервер не принимает подставной user ID.
Для публичного приглашения `my_rsvp: null`, `my_rsvp_revision: "0"`;
наличие присланной cookie не меняет эти значения до реализации входа.

Из корня репозитория с Node.js и Go из закреплённых версий:

```sh
npm ci
npm run api:check
npm run api:test
```

`api:check` проверяет OpenAPI через Redocly CLI и 27 схем/12 fixtures через
Ajv 2020-12. Негативные проверки отклоняют приватное поле в приглашении,
некорректную дату, числовую ревизию и неизвестный ответ RSVP.
`api:test` дополнительно запускает Go-тест, записывает реальные HTTP-ответы
во временный каталог и сравнивает статус, JSON и заголовки с контрактом.
Каталог удаляется после проверки. `GO_BIN` позволяет явно задать путь Go.

В fixtures есть неизвестный тип записи и sequence больше безопасного целого JS:
клиенты сохраняют строковое значение и показывают безопасную заглушку.
Дополнительные поля ответа клиент игнорирует; публичный серверный DTO проверяется
закрытой схемой, чтобы случайное добавление приватного поля ломало проверку.
Тела запросов не допускают неизвестные поля. Примеры конфликтов и повторов
описывают требуемое поведение будущих операций и сами по себе не доказывают
реализацию идемпотентности или прав.

Валидаторы и их транзитивные зависимости закреплены в корневом lock-файле.
Проверка использует [Redocly lint](https://redocly.com/docs/cli/commands/lint)
и [Ajv JSON Schema 2020-12](https://ajv.js.org/json-schema.html#draft-2020-12).
