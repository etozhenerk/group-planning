# Десктопный чат · r2 · PROPOSED

04.11.2026. Исправление замечаний к r1: два входа в профиль, смещённые элементы
composer, неровные строки меню и неисправный поиск эмодзи. Это отдельный макет,
не реализация приложения и не продуктовая приёмка.

## Изменения

- Единственный вход в профиль — кнопка с аватаром и именем внизу sidebar.
  Повторный пункт удалён. Основные пункты имеют общие координаты иконки/текста,
  выравнивание по началу строки вместо центрирования разной длины подписей.
- Для composer опубликованный компонент подключён через изолированный CSS-
  адаптер прототипа. Плюс, однострочное поле, смайлик и отправка имеют общую
  вертикальную ось. Отступ текста 16 px, высота поля 48 px, вид/геометрия Send
  сохраняются при пустом/заполненном вводе; меняется только состояние.
- Меню действий использует фиксированные строки 48 px и отдельные колонки
  иконки/текста. Разделитель не участвует в расчёте высоты. Координаты не меняются
  при закрытии/повторном открытии.
- Строка поиска эмодзи общая для composer-picker и полного выбора реакции.
  Убраны наложенные стили обычного input, которые создавали второе поле.
  Очистка доступна отдельной кнопкой, возвращает фокус в поиск и сохраняет его
  ширину. Существующие русский каталог, категории и логика поиска сохранены.
- Composer-picker сохраняет высоту при полном, коротком и пустом результате:
  прокручивается только область эмодзи, строка ввода и категории не прыгают.
- В полной панели реакций исправлен обработчик outside press: родительское
  всплывающее меню больше не закрывает dialog при клике внутри него. До правки
  воспроизведено закрытие от клика по поиску; после — проверены клик, очистка и
  выбор реакции. Закрытие самого dialog сохраняется.

## Проверка предложения

Сборка esbuild и Prettier check прошли. Самопроверка живого макета в IAB:
один профиль, совпадающие оси/координаты, отсутствие сдвига Send при вводе,
постоянная геометрия поиска для ready/found/empty/clear, фокус после очистки,
выбор 🍕 в реакции, одинаковые координаты пяти пунктов при повторном открытии.
Измерения и 10 проверенных условий — evidence/checks.json; новые console errors
после финальной исправленной сборки отсутствуют, evidence/console.json.

На 740×720 внешний document ровно 740×720, composer видим; evidence/compact.json.
Широкий вариант 1440×900 сохранён отдельно. Ранний локальный сбой клика по
поиску не скрыт успешным поиском через программный fill: после исправления
повторно выполнен настоящий click в поле и click очистки.

Сервер/реальный send/API/native/WebKit, полный type/lint/app build и независимые
design-review/feature-test не проверялись. Приложение, tokens/contracts,
мобильные макеты и параллельная приёмка не изменялись. r1 сохранён отдельно;
следующие дизайн-шаги — принятие чата, затем список/календарь, затем знакомство.
