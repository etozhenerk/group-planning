# Принятый чат r2 · входные данные публикации

04.11.2026 пользователь принял чат: «окаю го некс». Точный HTML и hash
зафиксированы в APPROVAL.json. Повторное согласование r2 не требуется.

Применён design-system-publish: сверены действующие роли навигации,
сообщений, реакции, прочитанности и composer. Для desktop-композиции нужны
дополнения к контрактам navigation/chat: sidebar 222/76 px с одним профилем,
ограниченная ширина переписки, правая колонка сведений/компактный desktop-
dialog, стабильные координаты меню и composer, поиск эмодзи без вложенного
поля и закрытия родительского меню. Цвета и смысловые роли повторно
используются; случайные новые глобальные токены не опубликованы.

Статус: **approved / publication staged**, не published. Общая публикация
требует согласованной записи вместе с текущим исполнителем мобильного MVP:
рабочее дерево содержит его активный выпуск 6.0.0, обновление authority,
generated tokens, registry и manifests. Изолированный desktop-прототип не
перезаписывает этот выпуск и не инвалидирует его приёмку.

До реализации desktop необходимо включить точные r2 refs и этот desktop-
контракт в отдельное OpenSpec-изменение, опубликовать общую версию и manifest
с отдельными viewport/state references, выполнить design:generate/check/test.
Затем разрешённая реализация и независимая приёмка по каждой заявленной
платформе. Сейчас разрешён дизайн, app-код не меняется; публикация и
design:ready не заявляются выполненными.
