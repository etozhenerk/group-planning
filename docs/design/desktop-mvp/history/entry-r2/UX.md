# Знакомство и вход · desktop r2 · PROPOSED

04.11.2026. Отдельный интерактивный макет, не реализация клиента.
Превью: http://127.0.0.1:8797/desktop-entry-r2/preview.html.
Прежнее знакомство осталось в onboarding-deferred и не является эталоном.
Основания новой композиции: принятые chat-r2 и list-r2; точные hashes —
artifact.json. Мобильные восемь страниц не заменяются этой длинной страницей.

## Композиция и содержание

Шапка: знак слева от somewhere, ссылки на возможности и фотографии, «Войти».
Первый экран: крупный заголовок слева, фото встречи справа с настоящей принятой
карточкой и тремя ответами. «Попробовать» открывает диалог входа. Иллюстрация
не записывает RSVP. Ниже последовательно показаны функции встреч; профиля,
выдуманных метрик, отзывов и обещаний о будущих картах нет.

| Блок | Отдельный смысл текста | Иллюстрация / источник |
| --- | --- | --- |
| Приглашение | Назначьте дату, отправьте ссылку, узнайте ответы друзей | MeetingCard из принятого list-r2, реальные ResponseButtons |
| Список / календарь | Просмотрите все встречи или выбранный день | Та же карточка, CalendarGrid с логикой продукта и desktop CSS |
| Чат | После «Приду» доступны переписка, фото/файлы, реакции и прочитанность | Пузырь, угол, фото и галочки из принятого chat-r2; презентативная производная с новыми репликами |
| Дата | Большинство участников автоматически определяет новую дату | Настоящий DatePollCard с завершённым опросом; подсказка «Выберите один вариант» скрыта только в этой завершённой иллюстрации |
| Место | Меняется после опроса при большинстве проголосовавших за | Настоящий PlacePollCard с результатом; карты не обещаются |
| Подготовка | Ответственность возникает после принятия, выполнение отдельно | Настоящий TaskCard, принятая Мишей задача |
| Фото | Общий альбом, просмотр и сохранение всех снимков | Фотокомпозиция с принятой подписью «Сохранить все» |
| Вход | Без отдельной регистрации; затем открываются встречи | Центрированный desktop-dialog и одна кнопка Яндекс ID |

Применён product-copy-editor: смысловой порядок взят из принятых текстов
onboarding-r5 (preparation/onboarding-copy.json). Десктопные заголовки и
реплики адаптированы по месту. Нет второго повторного перечня функций и
блока про профиль. Повтор «Попробовать» внизу длинной страницы сохраняет
доступ к действию. Сервисные ссылки находятся один раз в футере.
Help/privacy/cookies ведут в прежние отдельные превью: новый desktop-дизайн
этих страниц этим макетом не утверждается.

## Взаимодействие и движение · somewhere-motion / Stageshow

| Действие | Начало → результат | Непрерывность / motion |
| --- | --- | --- |
| «Попробовать» / «Войти» | Страница → диалог | Страница остаётся под scrim; готовая поверхность появляется без растяжения текста, fast 150 ms |
| Вход через Яндекс ID | Ready → busy → демонстрационная ошибка | Одна кнопка и постоянный слот статуса; размер не меняется; новой кнопки «Отменить» нет |
| Закрыть / Escape | Диалог → прежняя страница | Нативный dialog удерживает фокус; начальный фокус на Яндекс ID, возврат к инициатору |
| Список ↔ календарь | Другой пример в постоянной сцене | Единая перемещающаяся подложка navigation 260 ms, постоянная высота сцены |
| За дату ↔ за место | Другой реальный опрос и пояснение | Готовая карточка появляется целиком за cover; поверхность сохраняется |
| Ссылка на возможности / фото | Первый экран → соответствующий блок | Плавная прокрутка; Reduce Motion даёт мгновенный переход |

Примеры продукта inert и имеют доступные пояснения; кликабельны вход,
демонстрационные переключатели и ссылки страницы. Иллюстрации не выполняют
серверные операции. Вход в этом макете не запускает настоящий OAuth:
кнопка показывает ожидание и через 1.4 s демонстрационную ошибку. Успех
авторизации не имитируется. В панели вне продукта можно выбрать login,
busy, error, cancelled и обычный вид. Перед реализацией нужен настоящий
auth/return-context, включая отдельный вход из приглашения без автоподтверждения.

Reduce Motion убирает локальные перемещения и анимацию загрузчика.
Токены и смысловые роли взяты из системы; новые глобальные роли не опубликованы.
Позиции и размеры desktop-композиции пока предложение. Native/mobile UI,
манифесты и текущая приёмка параллельной реализации не изменялись.

## Проверка

Strict TypeScript и esbuild прошли; исходники TS/TSX и CSS Modules сохранены.
Архивный build собирается из fixture-source и локальных assets. Точный показанный
HTML сохранён отдельно от результата проверки пересборки; его hash — artifact.json.

Самопроверка IAB: 740×800, 1440×900 и текущее окно; горизонтального overflow
и переполнения заголовков/абзацев не обнаружено. Просмотрены приглашение,
список/календарь, чат, оба опроса, задача и фото. Нативным кликом проверено,
что смена опроса не сдвигает страницу. Проверены открытие, фокус на главной
кнопке, Escape, busy/error/cancelled; размеры кнопки во всех трёх состояниях
совпадают. Новая кнопка отмены не появляется. После финальной перезагрузки
новых console errors в выполненном проходе нет. См. evidence/checks.json.

Это самопроверка дизайн-предложения. Системный Reduce Motion, независимые
design-review/feature-test, production build и платформенная приёмка
не выполнялись и не заявляются готовыми. r2 ожидает решения пользователя.
