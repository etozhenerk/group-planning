# Приглашение по ссылке · desktop r1 · PROPOSED

Превью: http://127.0.0.1:8797/desktop-invite-r1/preview.html?state=guest&rev=1.
Применены somewhere-motion / Stageshow и product-copy-editor. Это изолированный
прототип, не приложение: OAuth/RSVP/API не вызываются. Рабочие mobile-исходники,
общие tokens/authority/manifests и чужая приёмка не менялись.

## Композиция

Публичная страница без sidebar авторизованного приложения. Header содержит
круглый знак somewhere и контекстную навигацию: «О somewhere» до входа, «Мои
встречи» и единственный аватар аккаунта после входа. Меню аватара — имя/выход.
Слева крупная обложка с опубликованной рамкой/radius.cover, справа полные
детали и действия в потоке. При ширине до850px — обложка-баннер над деталями.
В низком широком окне сокращены вертикальные отступы, чтобы действия/ошибки
оставались видимыми. Нет ложного sticky-блока. Без обложки — цельная поверхность
с деталями, без пустой колонки или фиктивного изображения.

Последнее решение круглого бренда сохранено: ../brand-round-r1/decision.json.
Макеты desktop-create-r2 и будущая карта create-map-r2 уже APPROVED; карта не
входит в стартовый MVP и в это приглашение не добавляется.

## Состояния и права

- Гость видит доступные детали/полное описание и «Войти через Яндекс ID».
  Вход возвращает в то же приглашение, не выбирает RSVP и не открывает чат.
- После входа — «Приду», «Возможно», «Не смогу». Последний подтверждённый ответ
  различим; «Возможно» соответствует разделу приглашений, без сохранений.
- «Приду» даёт действие «Открыть встречу»; организатор получает его без RSVP.
- При закрытом приёме без «Приду» остаются детали и уведомление «Участие закрыто».
  Все ответы/панель убраны, их место не зарезервировано. Существующий участник
  сохраняет действие открытия; после смены «Приду» на другой ответ оно исчезает.
- Ошибки входа/ответа находятся в стабильном слоте у действия; busy блокирует
  повтор, не создаёт кнопку отмены. Unknown сохраняет подтверждённый ответ,
  блокирует новые варианты и предлагает повтор той же демонстрационной попытки.
- Есть загрузка, отдельные ошибка загрузки и недоступная ссылка; длинные данные,
  отсутствие обложки/времени/места. Время не подменяется полуночью.

Все даты/права/закрытие и ответы в фикстуре демонстрационные, без серверной
проверки отсечки/доступа. Реальный return context, OAuth, idempotency и восстановление
ответа между браузерами проверяются при реализации, не этим макетом.

## Карта текстов

| Блок | Вопрос читателя / действие |
| --- | --- |
| Приглашение на встречу / заголовок | Что прислали и как называется встреча |
| Фото и «Приглашает Лена» | Кто зовёт; нет букв вместо фото |
| Дата/время/часовой пояс/место | Когда и куда прийти, включая отсутствие данных |
| Описание | Полные детали организатора, без обрезания |
| Вход / нейтральная подсказка | Как ответить; вход не подтверждает участие |
| Ответы / статус / открыть | Явный выбор, результат и доступное продолжение |
| Закрытие / ошибки | Что недоступно и какой следующий шаг возможен |

Не возвращена отклонённая подпись «Вы отвечаете как Миша». Нет лишнего
онбординга/перечня фич, повторной идентичности у кнопок, сохранений и карты MVP.
Реестр строк: PublicHeader, InvitationDetails/Facts, SignInAction,
ResponseButtons/Panel, ClosedNotice, OrganizerAction, InvitationState.
PreviewControls вынесен за продуктовую страницу.

## Движение и доступность

| Действие | Начало → результат | Сохраняющийся объект / motion |
| --- | --- | --- |
| Войти | Кнопка → busy → ответы | Обложка/детали неизменны; кнопка50px сохраняет размеры и label для доступности; слот статуса постоянный |
| Ответить | Вариант → pending → подтверждённый ответ | Три цели48px остаются, spinner внутри выбранной; остальные заблокированы |
| Приду | Подтверждение → действие открытия | Новая строка освобождает место через grid0fr→1fr/navigation, opacity/fast; текст не масштабируется |
| Закрытие после смены ответа | Ответ → закрытая поверхность | Недоступные действия убираются сразу, права не задерживаются анимацией |
| Меню аккаунта | Фото → popup → закрытие | Привязка к фото, Escape возвращает фокус |

Уменьшение движения отключает spinner/раскрытие; отдельный системный прогон
не выполнен. Страница прокручивается целиком над демонстрационной панелью;
длинные данные не маскируются обрезанием и не превращаются в полоски.

## Самопроверка и ограничения

Strict TypeScript на frozen источниках и esbuild pass. IAB:740 и1440px без
внешнего horizontal overflow, на740 полное длинное название переносится в2строки.
Проверены вход без автоматического RSVP, «Возможно», «Приду»/доступный переход,
закрытие без ответов, сохранение доступа текущего участника и его потеря после
«Не смогу», ошибка ответа/повтор, unknown-блокировка, retry загрузки, account
menu/Escape. Проверены/сняты загрузка, ошибка, без обложки, длинный вариант.
Формы без времени/места подготовлены, отдельный сквозной проход этих комбинаций
не выполнен. Новых console errors на проходе нет.

Обычный координатный клик подтверждает неизменность busy-кнопки:
x713.59/y585.27/w478.41/h50 при1280×720 до/после. Playwright locator сам
прокручивал страницу перед кликом; это не изменение геометрии продуктом.
Auth-error после уплотнения на низком окне заканчивается на617px при720px.
Снимки — evidence/, точный показанный hash — artifact.json.

Это самопроверка предложения, без независимых design-review/feature-test,
backend/native и design:ready/qa:ready. «Открыть встречу» ведёт к принятому
макету chat-r4 с демонстрационными данными. Ошибки/права задаются селектором
фикстуры и не доказывают работу сервера. Общая публикация — после принятия UI.
