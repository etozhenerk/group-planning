# Мои встречи · десктоп · r1 · PROPOSED

Дата: 04.11.2026. Отдельный прототип, не реализация приложения.
Живое превью: http://127.0.0.1:8797/desktop-list-r1/preview.html.
Принятый предшествующий экран — чат r2; подтверждение: «окаю го некс».

## Композиция

Слева согласованная навигация чата: два основных раздела и один вход в профиль
через фото внизу. До 1100 px остаётся узкая панель с иконками. Шапка содержит
название раздела и создание встречи. Под ней предстоящие/прошедшие и общий
переключатель списка/календаря. Положение переключателя постоянно.

В списке две колонки карточек, до 1000 px — одна. Карточка использует настоящий
образец продукта: выступающая дата, наклонённая обложка, разные роли буднего
и выходного дня, фотографические аватары. Для отсутствующего фото — силуэт,
не инициалы. Непрочитанные находятся в нижней строке слева, люди справа;
строка находится в потоке и не перекрывает длинные тексты. Заголовок и место
переносятся полностью. Прошедшие встречи имеют отдельную строку альбома.

Календарь использует действующую логику дней и клавиатуры, с отдельной CSS-
адаптацией десктопа. Выделение числа — прямоугольник со скруглением, по центру
своей колонки. Справа встречи дня; на компактной ширине — под календарём.
20 встреч не растягивают боковую панель: её содержимое прокручивается.
Встречи без даты доступны отдельной кнопкой в обоих видах.

## Состояния и переходы

| Действие | Результат | Непрерывность / motion |
| --- | --- | --- |
| Список ↔ календарь | Другая форма тех же встреч | Шапка и переключатель неподвижны; подложка перемещается за navigation 260 ms; выбранный день и позиции чтения сохраняются |
| Предстоящие ↔ прошедшие | Другой период | Подчёркивание перемещается за navigation 260 ms; последний день хранится отдельно для периода |
| Выбор дня / месяца | Обновление панели дня | Сетка остаётся в той же колонке; движение не задерживает ввод; клавиатурное управление унаследовано из CalendarGrid |
| Наведение на карточку | Подъём карточки и обложки | Роли card/cover из системы; при Reduce Motion перемещения отключены |
| Карточка ужина → чат → возврат | Принятый чат r2, затем прежний список | View/period/day и scroll хранятся в sessionStorage только этого прототипа |
| Ошибка загрузки → повторить | Демонстрационный успешный ответ | Шапка остаётся; ошибка называет операцию, повтор возвращает обычное состояние |
| Ошибка обновления | Список остаётся доступным | Компактная строка с повтором, карточки сохранены |

Панель снизу относится к демонстрации, не к продукту. В ней доступны обычное
состояние, длинный текст, 99+ непрочитанных, 20 встреч в день, пустой день,
загрузка, ошибка загрузки/обновления и отсутствие встреч. Период и вид
переключаются в самой шапке. Отдельных стики-панелей с CTA на этом экране нет.

## Тексты · product-copy-editor

| Блок | Вопрос пользователя / факт / действие | Решение |
| --- | --- | --- |
| Шапка и вкладки | Где я и какие встречи вижу? | «Мои встречи», «Предстоящие», «Прошедшие», «Список», «Календарь» |
| Карточка | Когда, где и кто придёт? | Дата, реальное название и место, фото людей; повторный описательный текст не добавлен |
| Непрочитанные | Что требует внимания? | Согласованный компактный текст; 127 отображается как 99+; полный доступный label сохраняет количество |
| Пустой список | Почему нет карточек и что можно сделать? | «Нет предстоящих встреч» и приглашение создать встречу; прошедшие предлагают вернуться к предстоящим |
| Ошибка | Что не получилось и как повторить? | «Не удалось загрузить встречи» / «Повторить загрузку»; причина не выдумывается |
| День без встреч | Что запланировано на выбранный день? | «На этот день встреч нет.» без повторного объяснения календаря |

Проверены строки во всех новых TSX, включая aria-label; подписи общие для
платформ. Сохранения/закладки и новые продуктовые функции не добавлены.

## Проверка и границы

Собраны и отформатированы TypeScript/CSS Modules. Отдельная strict-проверка
TypeScript прототипа с импортируемыми модулями продукта прошла. Архивный build
повторно собирается из fixture-source и сохранённых assets. Сборка архива
может иметь другой бинарный hash из-за пути исходников; эталон — точная копия
показанного live HTML, hash в artifact.json.

Самопроверка в IAB: 740×800 и 1440×900; перенос длинного заголовка и места;
один вход в профиль; одинаковая геометрия переключателя; сохранение выбранного
7 ноября между видами; 20 карточек в панели дня с внутренней прокруткой;
ошибка и повтор; пустое состояние; прошедшие и без даты; 99+; переход ужин →
чат → список. См. evidence/checks.json и screenshots. Горизонтального overflow
на проверенных ширинах нет. После финальной перезагрузки новых console errors
на выполненном проходе нет. Reduce Motion предусмотрен CSS, отдельный
системный live-прогон не выполнен.

Фикстуры локальные, серверные операции не выполняются. Только карточка ужина
соединена с принятым чатом r2. Остальные карточки, создание, приглашения,
профиль и альбом пока показывают композицию; их desktop-сценарии не соединены.
Это не полная функциональная приёмка и не independent design-review.
Мобильные эталоны, production-код, токены и текущая приёмка не изменены.
Этот r1 ожидает согласования пользователя.
