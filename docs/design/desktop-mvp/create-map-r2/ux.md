## Форма и выбор

К ручному полю добавлено «Выбрать на карте». После подтверждения — адрес и
«Изменить на карте»; ручная правка снимает связь с выбором. Остальные поля и
принятый CTA create-r2 сохраняются, черновик остаётся под окном карты.
Выбор — desktop dialog, без bottom sheet/ручки/swipe-to-close. Площадь до1120×720,
на compact — окно с отступами16px и24px по вертикали. Поиск/результаты слева,
большая карта справа. Слева собственная прокрутка результатов, выбранный адрес
и «Выбрать это место». Карта не двигает окно и не прокручивает страницу.
Крестик/Escape отменяют только неподтверждённый выбор; подтверждение возвращает
адрес в форму. Фото/заголовок/дата/описание сохраняются.

Состояния: карта/выбранный адрес/точка, поиск/нет результатов/ошибка поиска,
загрузка/ошибка карты/повтор/ручной ввод. При недоступной карте подтверждение
заблокировано, доступен ручной ввод. Контролы фикстуры вынесены в нижнюю панель
«Будущий этап · Яндекс Карты», ссылка «Стартовая форма» ведёт к create-r2.

## Тексты и движение

Шапка отвечает что выбрать. Поиск находит место/адрес; результат содержит адрес,
выбранное состояние и галочку. Строка на карте объясняет выбор точки. Подтверждение
называет результат. Ошибка называет сбой карты/поиска, не обещает причину.
Не повторяются инструкции о будущей интеграции внутри рабочего сценария.

| Действие | Начало → результат | Непрерывность |
| --- | --- | --- |
| Выбрать на карте | Форма → dialog | Форма и draft сохраняются, opacity/translate8 за fast; начальный фокус в поиске |
| Найти/выбрать адрес | Запрос → результаты → candidate | Геометрия поиска и действия постоянна; результат и маркер показывают один candidate |
| Перетащить | Карта → сдвинутая карта | Изображение следует pointer на каждом кадре без transition; порог5px отличает tap от drag, pointercancel прекращает жест |
| Масштаб | Карта → другой zoom | Ограниченный demo zoom1–1.8; точка вычисляется обратным transform, без закрытия dialog |
| Подтвердить | Candidate → поле формы | Окно закрывается, изменяется только место; до подтверждения исходный адрес не перезаписывается |
| Cancel/Escape | Dialog → форма | Неподтверждённая точка не сохраняется, фокус возвращается открывшему действию |

Reduce Motion отключает появление/вращение загрузки; drag остаётся прямым вводом.
Статические контролы карты не сдвигаются при resize: overflow:clip исключает
программный scroll canvas с отрицательным overscan. Верхние углы/тень принятого
sticky CTA применяются только при реальном overflow формы; карта не bottom sheet.

## Что в макете и что позже

Подложка — растровый фрагмент публичного виджета Яндекс Карт. Полный исходный
скриншот сохранён assets/yandex-reference-full.png; вариант без собственной
метки в исходном URL: https://yandex.ru/map-widget/v1/?ll=37.642100%2C55.758500&z=16.
В UI сохранена ссылка/подпись источника и «Схема для макета». Поиск по трём
примерным адресам, геокодирование точки, camera и жесты — локальная демонстрация.
API-ключей, настоящего SDK, запросов геокодера/поиска и production-интеграции нет.
Растр имеет ограниченную детализацию; его нельзя поставлять как рабочую карту.

В отдельной будущей проработке нужны выбор API/SDK и условия использования,
связь provider place/id/адреса/координат, реальные поиск и reverse geocoding,
геолокация только после явного действия/разрешения, unknown/cancel/timeout и
доступность карты на клиентах. Подписи/условия провайдера нельзя перекрывать.
Официальные источники: [JS API](https://yandex.ru/maps-api/docs/js-api/ref/index.html),
[быстрый старт](https://yandex.com/maps-api/docs/js-api/common/quickstart.html).
Точный контракт/тариф/ключи не выбраны и не объявляются согласованными.
