# Принятый будущий вариант карты r2

Принято04.11.2026. Макет вне стартового MVP; ручное место create-r2 сохраняется.
Сопоставлено через design-system-publish: desktop dialog, карта с inset16 и
radius.control12, отдельные поиск/результаты/подтверждение; без swipe-to-close.
Подписи и источник карты не перекрываются. Статические данные — только макет,
SDK/геокодер/ключи/условия требуют отдельной проработки. Общая публикация staged,
не меняет текущие mobile tokens/manifests и не заявляет работающую интеграцию.
