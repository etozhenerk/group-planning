## Чат · PROPOSED · r1

Живое превью: http://127.0.0.1:8797/desktop-chat-r1/preview.html.
Исходники, фиксированная сборка, фотографии и evidence — chat-r1/.
Это отдельный прототип с локальными демонстрационными данными, не реализация
клиента. Общие tokens/contracts/authority/manifests и мобильные эталоны
не менялись. Публикация возможна после согласования.

Композиция: навигация слева, ограниченная по ширине переписка в центре,
сведения справа. На ширинах до 1100 px — компактная навигация, сведения
открываются отдельным desktop-dialog. Bottom sheet на десктоп не переносится.
Основная sidebar и текущая кнопка возврата в этом превью показывают композицию;
переходы на следующие desktop-экраны ещё не соединены.

Использованы принятые мобильные решения: угол пузыря к отправителю, реакции
внутри сообщения, одна/две различимые галочки и список прочитавших, компактный
значок ошибки с повтором, тонкая улыбка, отправка стрелкой вверх и фотоаватарки.
Чтение и отправка в прототипе демонстрационные. Реальные API/transport/outbox
не подменяются этим кодом при последующей реализации.

Composer действительно закреплён над прокручиваемой перепиской: верхние
скругления, тень вверх, прилегание к трём краям центральной области. Высота
composer резервируется в содержимом. Правая колонка прокручивается отдельно;
её действия находятся в потоке без ложного sticky-оформления.

Основной пример — Миша, обычный участник. Шаринг организатора ему не показываем.
В сведениях показан подтверждённый ответ; его изменение в этом макете не связано
с сервером и намеренно не интерактивно. Нужен отдельный будущий проход ролей/
приглашения/настроек; это не потерянная продуктовая операция.

## Переходы и движение

| Действие | Начальное → конечное состояние | Непрерывность и motion |
| --- | --- | --- |
| Открыть/закрыть сведения на широком экране | Правая колонка 0 → 280 px | Колонка сохраняется, grid меняется за navigation 260 ms; содержание не масштабируется, opacity за fast 150 ms |
| Сведения на компактном десктопе | Чат → диалог поверх того же чата | Содержимое и draft чата остаются; Escape/закрытие возвращает контекст |
| Плюс | Закрыто → меню над кнопкой | Существующие add-menu enter/exit, без смены маршрута; выбор открывает desktop-modal |
| Реакция | Пузырь → привязанное меню → реакция в пузыре | Пузырь сохраняет положение, backdrop/menu текущего r7; нет обводки вокруг всего сообщения |
| Галочки | Отправлено/прочитано → детали → список людей | Данные фикстуры, стабильная геометрия; фото и имена, Escape/закрытие |
| Ошибка отправки | Значок ошибки → действия → повтор | Текст сообщения сохраняется, большого блока ошибки нет |
| Ввод/отправка | Draft → локальная отправка → подтверждённая фикстура | Composer остаётся, лента сохраняет привязку к концу, если пользователь читал конец |

Уменьшение движения предусматривает мгновенное переключение вместо CSS-
переходов; отдельный системный live-прогон Reduce Motion не выполнен.
Формы даты/места/подготовки сейчас наследуются из существующих компонентов:
открытие проверено для даты, их новый desktop-дизайн этим макетом не утверждён.

## Тексты

Назначение текста: шапка идентифицирует встречу; сведения дают дату/место/состав;
реплики остаются разговором, а статусы — подтверждением действий. Длинные
инструкции не добавлены. Подписи общие с mobile. Из примера убрана одна повторная
реплика; последнее сообщение — «Тогда до пятницы!». Демо-имена/фотографии
не являются утверждением об участии реальных людей.

## Локальная проверка прототипа

- Сборка esbuild и форматирование исходников выполнены. Новые React-компоненты
  разделены по каталогам, TypeScript, CSS Modules, alias imports/arrow declarations.
- В IAB проверены 740×720, 900×800 и 1440×900: внешнего overflow нет,
  composer остаётся доступным, сведения на компактной ширине открываются отдельно.
- Проверены локальная отправка/очистка поля, меню плюса и открытие формы даты,
  меню реакции/постановка 🔥, галочки → «Прочитали 3» → три имени с фото,
  ошибка отправки → повтор. После финальной перезагрузки новых console errors
  на выполненном проходе не было.
- Обнаруженные при сборке ошибки высоты grid, размеров селектора и загрузки
  русской локали исправлены; ранние screenshots не являются финальным эталоном.
- Это самопроверка предложения. Полные type/lint/app build, backend/native,
  независимые design-review/feature-test и product gates не выполнялись.
