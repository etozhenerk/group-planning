somewhere-motion / Stageshow и product-copy-editor; исходники и сборка рядом.

## Композиция и ревизия действия

Форма и обложка рядом; при ширине менее1000px обложка переходит в компактную
строку над полями. Sidebar222/76px из принятого desktop-list-r2. Тонкий шеврон
с target44 без подписи «Назад»; один вход в профиль. Название120, описание4000,
ручное место500, обязательная дата, необязательное время. Карты не добавлены
по последнему решению пользователя в mobile-mvp-design-refresh.

В r1 кнопка была оторвана от формы, под обложкой справа. Пользователь отклонил
её положение и на компактной, и на широкой версии. R1 сохранён отдельно.
В r2 широкая кнопка220×48 совпадает левым краем с полями и находится под ними.
На компактной ширине действие заполняет всю ширину с равными отступами24px.
Слот error/unknown расположен над действием, а не в дальнем конце страницы.
Подложка, верхние углы и тень только при реальном overflow: нижний sticky
footer прилегает к краям scroll-области, его высота остаётся в потоке формы.
При достаточной высоте обычный footer без подложки/тени. ResizeObserver
пересчитывает состояние при изменениях окна/высоты полей/ошибок.

## Карта текстов

Заголовок называет действие; легенда объясняет заметную звёздочку Названия/Даты.
Метки полей не заменяются примерами. Время сопровождает правило «можно уточнить
позже» и часовой пояс. Место вводится вручную. Описание помогает сообщить друзьям
детали. Обложка даёт действие и форматы, без подписи «необязательно».
FieldMessage сохраняет место и описывает ошибку у конкретного поля; FormActions
отличает известную неудачу от неподтверждённого результата. При неизвестном
результате данные заблокированы, предлагается «Повторить отправку».
DiscardDialog: «Выйти из формы?» / «Встреча ещё не создана», продолжить/выйти.
Реестр: PageHeader, MeetingDetails, TextField/DateField/TimeField, CoverPicker,
FormActions, DiscardDialog. PreviewControls отделён от рабочего интерфейса.
Подписи кнопок совпадают с mobile.

## Движение

| Действие | Начало → результат | Сохраняющийся объект / motion |
| --- | --- | --- |
| Дата | Поле → popover календаря → дата | Привязка к полю, flip/shift удерживают popup в окне; ввод/выбор закрывает с возвратом фокуса |
| Полевая ошибка | Отправить → invalid | Поле и слот ошибки сохраняют геометрию; фокус первого invalid, остальные поля не вытесняются |
| Фото | Выбрать → загрузка → обложка | Рамка сохраняется, чтение локального файла, pending блокирует отправку; отмена picker не удаляет фото |
| Создать | Кнопка → pending → чат | Кнопка остаётся прежней ширины/высоты, содержимое заменяется spinner; повтор pending блокирован |
| Ошибка/unknown | Pending → статус рядом с действием | Черновик остаётся; unknown фиксирует исходные данные до повтора |
| Уйти | Заполненная форма → desktop dialog | Форма сохраняется под поверхностью, opacity/translate8 за fast; Escape/продолжение возвращают контекст |

Reduce Motion выключает переход modal и вращение индикатора; отдельный системный
проход не выполнен. Новые цвета и библиотеки в приложение не добавляются.

## Проверка и пределы

Strict TypeScript на frozen источниках pass, esbuild pass, git diff --check pass.
IAB: 740×620 и1440×900, внешнего horizontal overflow нет. В compact кнопка
x100..716, ширина616 при main x76..740 и равных отступах24. На wide кнопка и
поле начинаются сx331, sticky=false. Сохранены снимки filled/error/ready r2.
В общем проходе r1→r2 проверены required/фокус, выбор даты6ноября в календаре,
исправление после отсутствовавшей locale, размещение календаря без обрезания,
изменение фото через реальный file chooser, сохранение названия при выходе/
продолжении, unknown/блокировка/повтор и переход к принятому chat-r4. В r2
повторно проверены изменённые компоновка/sticky/error на обеих ширинах.
После финальной загрузки новых console errors не обнаружено. Старый сбой locale
в историческом журнале сохранён; не выдаётся за ошибку текущей ревизии.

RSVP/создание/API не вызываются. Отправка —900ms mock; успех ведёт к существующему
макету chat-r4 с демонстрационными данными, не создаёт настоящий ресурс. Черновик
локален sessionStorage, его объём зависит от браузера; полноценный upload/
идемпотентность/сервер/native и независимая приёмка не выполнены. При переносе
нельзя заменять ими работающий контракт. Это самопроверка предложения, без
заявления design:ready/qa:ready или завершённой общей публикации.
