# Входы публикации круглой подложки

Применён design-system-publish к решению пользователя: меняется только фон знака,
вместо rect1254×1254 используется circle(cx627,cy627,r627), углы прозрачны.
Глиф, оттенки, размеры, оптическая позиция и движение не меняются. Коррекция общая
для шапок/sidebars/входа/запуска на web/iOS/Android, без новой рамки вокруг подписи.
Активные desktop-макеты и источники обновлены; старый SVG сохранён.

Публикация staged. Общие version/authority/contracts/manifests и клиентские ресурсы
синхронизировать согласованно с активной mobile-реализацией до переноса в приложение;
не переносить старые pass на изменённый ресурс. Общие файлы/проверки работающего
приложения этим макетным проходом не переписывались.
