# Навигация

Основные разделы: встречи (список/календарь), приглашения «Возможно», профиль.
На desktop — боковая панель. На телефоне — три равных пункта компактной плавающей
панели; иконка `component.navigation.icon`, размеры и отступы из navigation-токенов.
Выделение перемещается за `motion.duration.navigation`; reduced motion мгновенно
меняет выбор. Кликабельная область больше рисунка: минимум target платформы.

Коррекция 26.10.2026: нижняя панель присутствует только на основных экранах
этих трёх разделов. На чате, создании, формах, альбоме, помощи, документах и
других вложенных экранах её нет и не остаётся отступа под неё. У вложенного
экрана есть Back и корректная системная история; возврат восстанавливает
раздел/дату календаря/прокрутку. «Сегодня» видно и на узком календаре.

Футер существует только в desktop-онбординге. Помощь, обращение, версия,
разработчик и документы доступны из профиля; их нет в сведениях о встрече.
Старые HTML с другой областью показа панели/футера не отменяют эту коррекцию.

Ревью: ширины 320/390/768/1440 web, safe area native, увеличение текста,
переключение трёх разделов, последний элемент выше панели, Back и отсутствие
пустого резерва панели на вложенных экранах.
