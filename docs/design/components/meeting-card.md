# Карточка встречи

Назначение: быстро понять что, когда, где и с кем; открыть чат. Используется
одинаково в списке и календаре. Эталон `meeting-experience-refresh/assets/list.html`;
`list-names.html` и `participants.html` — отвергнутые варианты, не источник.

Слева: дата на выступающем ярлыке, название, место/состояние места. Справа сверху:
наклонённая обложка, выступающая наружу. Справа снизу: перекрывающиеся круглые
аватары, затем +N. Корона рядом с названием обозначает собственного организатора,
доступное имя «Вы организатор»; отдельная строка роли отсутствует.

| Часть | Токены / правило |
| --- | --- |
| Фон / ярлык / текст ярлыка / рамка | color.weekday* или color.weekend* |
| Геометрия обложки | component.card.cover.*; radius.cover |
| Аватары / перекрытие | component.card.avatar*, component.card.avatarOverlap |
| Название | typography.size.cardTitle / cardTitleMobile; lineHeight.cardTitle |
| Контейнер | radius.card; minimumHeight — ориентир, не фиксированная высота |
| Движение | motion.duration.card / cover; hoverLift / coverLift |

Будни и выходные определяются датой в часовом поясе встречи; день недели
написан словами, цвет лишь дополняет. Нельзя выбирать цвет по индексу карточки.
Кастомизация цвета пока отсутствует. Без обложки текст занимает доступную ширину.
Длинные название и место переносятся, не обрезаются фиксированной высотой.
Недоступный аватар → инициалы; полный состав доступен отдельно. Имена доступны
ассистивным технологиям; личных контактов на карточке нет.

У прошедшей встречи заметен вход в вайб. Карточка остаётся ссылкой на чат;
вложенное действие альбома не вызывает одновременно открытие чата. Empty/loading/
error — состояния списка, не фиктивные встречи. На touch нет зависшего hover.
Hover мышью поднимает карточку на 3 px и раскрывает аватары; reduced motion
отключает смещения, фокус остаётся видимым. Снимок по умолчанию без hover.

Ревью: обычная/длинная/без обложки карточка, 1 и много участников, weekday/weekend,
прошедшая, фокус, hover/reduced motion, открытие и возвращение к позиции списка.

Данные и правила списка — [personal-meetings](../../../openspec/changes/meeting-experience-refresh/specs/personal-meetings/spec.md).
