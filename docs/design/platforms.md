# Платформенные адаптации

Сценарий, роли цвета, иерархия, состав и состояния общие. Реализации остаются
React, SwiftUI и Compose. Системные панели, клавиатура, safe area и доступность
адаптируются явно; pixel-identical web и native не требуется.

| Свойство | Web | iOS | Android |
| --- | --- | --- | --- |
| Размеры | CSS px, относительная раскладка | pt, safeArea | dp, WindowInsets |
| Текст | текущий font stack, масштаб браузера | системный SF, Dynamic Type | системный sans-serif, sp |
| Область нажатия | минимум target.web | минимум target.ios | минимум target.android |
| Назад | история + видимая кнопка | системный жест/кнопка | системный Back |
| Уменьшение движения | prefers-reduced-motion | accessibilityReduceMotion | системный scale анимаций |

Нижние панели чата используют общие поверхность, радиус, заголовок и порядок
содержимого. Web использует опубликованные `color.sheetBackdrop` и
`component.sheet.backdropBlur`; SwiftUI sheet и Compose ModalBottomSheet сохраняют
системное затемнение/индикацию перетаскивания. Это явная платформенная адаптация,
а не разрешение добавлять произвольный фон, второй header или сервисные действия.

Шрифт нельзя молча заменить загруженным похожим: это меняет метрики.
Текущий web stack начинает с Inter, но без установленного Inter используется
системный fallback. Для screenshot-окружения фиксируйте ОС, доступные шрифты,
вес, locale ru-RU, timezone, масштаб текста и viewport. Новый bundled font
публикуется вместе с лицензией, кириллицей и проверенными метриками.

`typography.size` — исходный размер, `lineHeight` — множитель. SwiftUI должен
использовать масштабируемые стили/ScaledMetric, а не глобально фиксировать размер.
У BrandTypography вес 850 — прежний адаптер между Heavy/Black, он не разрешает
произвольные новые веса. В Compose размер экспортирован в sp; lineHeight
вычисляется из того же sp и множителя. Размер иконки не равен hit target.

Снимки регрессии сравниваются внутри одной закреплённой платформы и среды.
Сравнение с макетом отдельно оценивает композицию, токены и поведение.
Fixture одинаково задаёт дату, участников, текст, изображения и состояние API.
Загрузить шрифты/изображения, дождаться стабильного состояния; тестовые баннеры
не входят в release-снимок. Для статичного снимка отключить анимации, для
motion-проверки включить и отдельно проверить reduced motion. Baseline нельзя
обновлять из actual только ради зелёной проверки.

## Мобильный чат · 1.3.0

Одобренный `2026-10-27-telegram-chat` задаёт общую мобильную композицию для web,
iOS и Android. Emoji-док заменяет нижнюю область клавиатуры, сохраняет composer
и Send над сеткой без backdrop. Search вызывает реальную клавиатуру по явному
действию; передача selection между текстовым вводом и доком обязательна.
IME/VisualViewport/WindowInsets учитываются по фактическому устройству. Минимумы
дока и sheet из токенов уменьшаются при нехватке пространства, не перекрывая
основные действия; сетка/поля прокручиваются. Поворот телефона не переводит
мобильную форму в desktop route. В 2.0.0 desktop 768/1440 использует
центрированную модалку над чатом, mobile landscape остаётся нижней панелью.

Quick/full reactions остаются привязаны к сообщению и ограничены областью
разговора. Native popover/custom overlay допустим только с тем же контекстом,
системным long press и доступным полным выбором; один системный emoji keyboard без
поиска/категорий/недавних и реакций не подменяет принятый сценарий. Unicode-glyph
зависит от ОС, сравнение формы самого emoji между платформами не требуется.
Код/каталог демо не заменяет полноценную локализацию/системный ввод.

Компактные info/settings/task/action sheets используют `component.mobileSheet`
и `typography.*.mobileSheetTitle`; native sheet/switch/date-time picker/Share
сохраняют платформенную семантику. Web-эталон этой sheet без backdrop blur;
системное затемнение/жест native — явная адаптация. Native target минимум 48dp
Android и 44 pt iOS, web 44 px; меньше видимая иконка не уменьшает область нажатия.
Текст/высота строк растут с масштабом, 19 — базовый размер заголовка, не hard cap.

Проверка: 320×760, 390×844, низкое 390×430 и landscape 844×390 как логические
web viewports; iOS/Android — сопоставимые размеры/ориентации реального simulator/
QA emulator с точными model/OS/fontScale/insets в capture. VoiceOver/TalkBack,
клавиатура и системные picker проверяются реально. CSS-scale рамки workbench,
fixture-кнопки — только средства просмотра макета; raw 2.0.0 показывает также desktop-модалки.

### Web-поля без случайного zoom · 1.4.1

[Прежнее уточнение](../../openspec/changes/gathering-activity-feed/mobile-scroll.md)
от 25.10.2026 требует минимум 16 px для полей на телефоне. Роль
`typography.size.mobileWebInput` применяется к composer, search, input/textarea/select
мобильных панелей, включая readonly Share. Роль body 15 остаётся для native
и обычного текста; одинаковые CSS/native размеры здесь намеренно не требуются.
Генератор может экспортировать эту явно web-роль вместе с остальными размерами;
native клиенты не применяют её вместо body 15.

Raw mobile-web прототип теперь содержит эту адаптацию; его прежние 3 CSS и индекс
hashes сохранены в history/1.4.0. Размеры иконок 22 и emoji-toggle 23 независимы
от targets 44 web/iOS и 48 Android. Пользовательский zoom не отключается,
viewport-fit/safe area/IME сохраняют прежние правила. Новый снимок должен быть
снят с исправленного raw, никогда с actual приложения ради совпадения.

### Жесты и обратная связь · 2.0.0

На native long press сообщения открывает picker; long press чипа — людей
с фильтром emoji; tap чипа переключает собственную реакцию. Не размещать
постоянные дополнительные кнопки возле сообщений. VoiceOver/TalkBack — custom
actions на сообщении/чипе; web — keyboard/context menu. Native recognizer
учитывает scrolling/cancel и поглощает tap после удержания. Enter/exit/pressed
берутся из reaction motion-токенов; Reduce Motion убирает scale/translation.
Улыбка composer использует единый SVG viewport 24×24, размер роли 23. Placeholder/caret
используют общую метрику текстового ввода без двойных insets. Дата окончания
«28 октября», без weekday; равная высота date/time, stacked при нехватке ширины
или крупном тексте. Системный date picker и формат времени сохраняются.
