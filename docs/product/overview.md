# Somewhere

Somewhere помогает компании друзей организовывать встречи и путешествия:
договориться о деталях, подготовиться и держать актуальный план под рукой.
Постоянное техническое имя проекта — `group-planning`.

## Общая идея

Встреча и поездка — два сценария одного продукта. Их объединяет совместный
план: участники, время, места, решения и подготовка. Продолжительная поездка
может дополнить эту основу программой по дням, документами и расходами.

Пример встречи: создать план → пригласить друзей → выбрать дату и место →
распределить подготовку → встретиться.

Пример поездки: предложить направление → согласовать участников и даты →
выбрать места → подготовить программу → пользоваться планом в дороге.

Эти примеры объясняют направление продукта. Детальные требования и границы
первой версии ещё предстоит проработать.

## Что уже решено

- Это пет-проект с веб-клиентом, бэкендом и целями iOS и Android.
- Для первой версии не требуется работающая нейросеть в самом продукте.
  AI используется как инструмент разработки.
- Встречи и путешествия развиваются в одном сервисе.
- Код, продуктовая документация и инструменты агента находятся в монорепозитории.
- Для SDD выбран оригинальный OpenSpec, процесс самостоятельный и без AIFF.

## Термины для дальнейшей проработки

- **План** — организуемая встреча или поездка.
- **Компания** — группа людей, которые планируют совместные события.
- **Участник** — человек, участвующий в конкретном плане.
- **Предложение** — вариант даты, места или действия, который обсуждается.

Роли, правила членства и жизненный цикл этих сущностей уточняются в спецификациях.

## Границы текущего состояния

Сейчас реализована только среда разработки агента. Пользовательских функций,
API и приложений нет. Первое изменение продукта начнётся с определения
пользователя, основного сценария и критериев приёмки.

Открытые решения перечислены в [open-questions.md](open-questions.md).
