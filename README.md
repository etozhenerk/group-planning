# group-planning

**Somewhere** — сервис для совместного планирования встреч и путешествий
компанией друзей.

`group-planning` — постоянное техническое название проекта. Somewhere — название
продукта.

## Структура

```text
backend/             API и бизнес-логика
frontend/web/        Веб-клиент
frontend/ios/        Клиент iOS
frontend/android/    Клиент Android
```

## Начальное состояние

Создан минимальный каркас монорепозитория. Технологический стек ещё не выбран;
приложения, сборки и тесты пока не добавлены.

Для следующего этапа согласованы:

- отдельные правила агента в корневом `AGENTS.md` и в каждом приложении;
- общий API-контракт в `contracts/`;
- продуктовая и архитектурная документация в `docs/`;
- оригинальный OpenSpec для проработки, планирования и реализации изменений;
- локальные навыки агента в `.agents/skills/`.

OpenSpec и навыки ещё не подключены. Проект использует самостоятельный процесс
для пет-проекта, без AIFF.
