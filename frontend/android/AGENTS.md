# Клиент Android

Применяй [общие правила](../../AGENTS.md). Эта область отвечает за приложение
Somewhere для Android и его платформенные интеграции.

## Текущее состояние

Выбраны Kotlin и нативная оболочка на Jetpack Compose. Основные продуктовые
экраны управляются через BDUI; см. [ADR 0001](../../docs/architecture/0001-bdui.md).
Движок и способ его встраивания, версии SDK и команды сборки ещё не выбраны.
При создании приложения добавь соглашения о коде и реальные команды проверок.
Приложение и интеграция рендерера пока отсутствуют.

## Правила изменений

- Следуй общему API-контракту и сохраняй совместимость с сервером между
  независимыми выпусками. Обрабатывай состояния сети и повторные действия.
- Основные экраны получаются из общего BDUI-описания. Оболочка выполняет
  поддерживаемые действия и системные интеграции. Отличай серверную правку
  от изменений рендерера и SDK, требующих новой сборки; проверяй старую сборку.
- Для ссылок-приглашений проектируй вход в нужный план, авторизацию по
  согласованному сценарию и возврат к исходному действию.
- Учитывай пересоздание экрана, уничтожение процесса и восстановление состояния.
  Подтверждение участия и голоса не должны зависеть от жизни экрана.
- Уведомления, календарь, фотографии и другие системные возможности подключай
  по требованиям фичи с обработкой отказа в разрешении.
- Для затронутых экранов проверяй системную навигацию назад, доступность
  и увеличение размера текста.

## Проверки

Сборка и тесты Android ещё не настроены. Пока доступна проверка обвязки
`npm run agent:check` из корня. При появлении приложения укажи точные команды
сборки, модульных тестов и сценариев на устройстве или эмуляторе.
