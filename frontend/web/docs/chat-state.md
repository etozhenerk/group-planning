# Состояние чата web

`entities/meeting` владеет канонической лентой, receive/change cursors,
проекциями карточек и поколением доступа. `loadChat` выбирает совместимый HTTP
или snapshot/sync по capabilities; ACK отдельной отправки не заменяет receive
cursor. `createChatUpdates` связывает официальный SDK с catch-up и fallback.
События потока служат подсказками: данные принимаются через проверяемый API.

Ключи приватного Query-кэша включают профиль, встречу и access epoch. После
отзыва доступа поздний ответ прежнего поколения не возвращает данные.
`FeedTimeline/useViewport` хранит ID и смещение видимой строки; обычное окно
ограничено 500 серверными записями, виртуализатор — 200 смонтированными строками.
Фокус и pending защищены отдельно. Догрузка, resize и ACK сохраняют якорь;
новый хвост не переключает читателя из истории без его действия.

`features/send-message` хранит черновик, selection и несколько исходящих в
приватной IndexedDB `somewhere-private-chat`. Scope/lease разделяют аккаунты
и встречи. Сохранение на устройстве предшествует POST; стабильный intent key
сохраняется при повторах и подтверждении. Между вкладками согласуется один
владелец очереди. Ошибка локального хранения оставляет текст и не считается
успешной отправкой. SessionStorage хранит контекст приглашения, а не эту очередь.

Состав участников — отдельный Query. Meeting/membership invalidation и
заменяющий историю snapshot обновляют его вместе с текущими сведениями;
обычный текстовый hint не вызывает лишней перезагрузки состава. Карточки
опросов/задач обновляются через собственные projection versions. Прочитанность
использует видимость конца сообщения и dwell; перекрывающая панель приостанавливает
read-through. Владелец viewport сохраняется при открытии и закрытии панелей.

Сценарии и бюджеты: [UX чата](../../../openspec/changes/chat-reliability-and-sync/ux.md)
и [план измерений](../../../openspec/changes/chat-reliability-and-sync/validation-plan.md).
Browser-наборы объявлены в `playwright*.config.ts`; физический Safari и измерения
frame/memory фиксируются отдельно от эмуляции WebKit.

Композиция сохраняет опубликованный chat-actions: desktop modal и mobile sheet
открываются поверх той же ленты. Меню, emoji dock и реакции не создают второй
экран чата. `useVisualViewport` привязывает composer и панели к видимой области,
учитывает offsetTop и не вмешивается в pinch zoom. `DelayedSkeleton` откладывает
показ заглушки; догрузка истории сохраняет строки, черновик и якорь вместо
замены всей ленты. Pending занимает постоянный слот, индикатор виден после 2 с.
