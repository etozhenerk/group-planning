# Веб Somewhere

Первый рабочий срез: знакомство с сервисом → вход → личный список → создание
встречи с датой → ссылка другу → ответ → переписка. Организатор меняет настройки;
участники видят состав и ответы. «Возможно» и «Не смогу» закрывают переписку.

## Установка и запуск

Нужны Node.js **22.22.3** (`nvm use` из корня) и Go **1.27.2**.
Все команды ниже запускаются из корня репозитория после `npm ci`.

```sh
npm run web:demo
```

Открой `https://127.0.0.1:8443`. Сертификат локальный и самоподписанный:
для этого адреса браузер попросит разрешить подключение. На странице входа
можно выбрать тестовый профиль Саши или Лены; для второго участника открой
ссылку в отдельном профиле/приватном окне браузера.

Демо собирает клиент в режиме `demo` и запускает `TestBrowserFixture` из
`backend/internal/httpapi/browser_fixture_test.go`. Это настоящий Go HTTP API,
куки, CSRF и in-memory Store. Подменяется только внешний OAuth-provider,
который существует исключительно в `_test.go`. Обычный сервер и обычная
сборка не получают обхода входа. Не публикуй этот тестовый процесс в интернете.
Ctrl+C останавливает его; перезапуск удаляет встречи, сообщения и сессии.
`GO_BIN` позволяет явно выбрать исполняемый файл Go, если его нет в PATH.

Для обычной разработки отдельно запусти `go run ./cmd/server` из `backend/`,
затем `npm run web:dev`: Vite проксирует `/api` на `127.0.0.1:8080`.
Без настройки Яндекс ID доступны публичные экраны, а начало входа даёт
понятное сообщение. Реальную авторизацию пользователь отложил до конца.
Конфигурация — в [инструкции бэкенда](../../backend/docs/auth.md).

## Проверки

```sh
npm run web:check
npm run web:build
npx --no-install playwright install chromium
npm run web:test:e2e
npm run format --workspace @somewhere/web
```

`web:check`: типы, ESLint, отступы между CSS-блоками, AST-правила FSD,
Prettier и Vitest. `web:build` создаёт обычный production bundle в `dist/`.
Браузерные тесты собирают отдельный demo bundle и запускают свежий Go-процесс
на `https://127.0.0.1:8444`. Рабочий процесс демо на 8443 им не подходит:
изолированное состояние необходимо для проверки пустого списка и повторов.

CI использует те же команды, устанавливая Chromium с `--with-deps`.
Результаты сценариев и снимки — в
[отчёте веб-среза](../../openspec/changes/gathering-activity-feed/web-verification.md).

## Устройство

React 19.3.1, TypeScript 6.0.3, Vite 8.3.4, React Router 8.5.0,
TanStack Query 5.104.5. Точные версии всех инструментов — в `package.json`.

- `app` — маршруты, провайдеры, общие стили и смысловые токены v0.7.
- `pages` — композиция экранов и переходы.
- `widgets` — навигация, лента, состав и детали встречи.
- `features` — вход, создание, приглашение, ответ, настройки и отправка.
- `entities` — модели сессии/встречи, запросы, преобразование DTO и доступ.
- `shared` — проверяемый JSON transport, время, инфраструктура и UI-примитивы.

Внутренние импорты используют `@/`; между slices доступен только публичный API.
Компонент — один `const` со стрелочной функцией и свой тип Props в `.tsx`.
Хуки, мапперы и сетевой код находятся отдельно. Остальные функции тоже `const`.
Код, тесты и конфигурации — TypeScript; CSS хранится отдельно от компонентов.
ESLint проверяет фигурные скобки и пустые строки между логическими блоками,
Prettier — отступы/переносы. Проверка на PostCSS AST разделяет CSS-блоки.

JSON принимается как `unknown` и проверяется Zod; nullable и неизвестные типы
ленты не заменяются вымышленными данными. Куки не читаются из JavaScript;
CSRF хранится в памяти. Черновик и контекст приглашения изолированы по профилю
в sessionStorage. При 401 приватные кеши очищаются. При 403 поколение доступа
меняется, поздние ответы старого поколения не открывают переписку.

## Что ещё не готово

Реальный Яндекс OAuth, iOS/Android и постоянное хранение — отдельные этапы.
Календарь/прошедшие встречи, выбор даты голосованием, смена места голосованием,
задачи и загрузка обложек остаются в MVP и пока показаны только как примеры
с пометкой «Следующий этап» на онбординге. Рабочие экраны не подставляют
чужую обложку и не изображают эти действия как доступные.
