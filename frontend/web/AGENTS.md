# Веб-клиент

Применяй [общие правила](../../AGENTS.md). Эта область отвечает за браузерный
клиент Somewhere, в том числе открытие приглашений по ссылке.

## Текущее состояние

Выбраны React + TypeScript. Основные продуктовые экраны управляются через BDUI;
веб содержит браузерную оболочку и интеграцию рендерера. См.
[ADR 0001](../../docs/architecture/0001-bdui.md). Движок, сборщик, версии
и команды приложения ещё не выбраны. Добавь реальные команды при создании веба.

## Правила изменений

- Привязывай экран к пользовательскому сценарию и общему API-контракту.
  Правила доступа проверяются сервером, а интерфейс отражает их результат.
- Основные экраны собираются из общего серверного описания. Для новых
  компонентов и действий явно указывай необходимость обновления клиента.
  Проверяй обработку неподдерживаемого описания и совместимость контракта.
- Продумывай открытие прямой ссылки, обновление страницы и возврат назад.
  Не определяй самостоятельно, какие действия доступны гостю: это открытое
  продуктовое решение до спецификации приглашений и авторизации.
- Для сетевых операций предусматривай загрузку, пустой результат, ошибку
  и повторную попытку. Сохраняй введённые пользователем данные при ошибке.
- Используй семантические элементы и доступные подписи; проверяй клавиатурную
  навигацию и адаптацию к узкому экрану для затронутых сценариев.

## Проверки

Сборка и браузерные тесты ещё не настроены. Пока доступна проверка обвязки
`npm run agent:check` из корня. При появлении UI зафиксируй здесь команды
проверки кода и сквозных браузерных сценариев.
