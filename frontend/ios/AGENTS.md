# Клиент iOS

Применяй [общие правила](../../AGENTS.md). Эта область отвечает за приложение
Somewhere для iOS и его платформенные интеграции.

## Текущее состояние

Выбраны Swift и нативная оболочка на SwiftUI. Основные продуктовые экраны
управляются через BDUI; см. [ADR 0001](../../docs/architecture/0001-bdui.md).
Движок и способ его встраивания, версии SDK и минимальная версия iOS ещё
не выбраны. При создании приложения добавь правила кода, команды сборки,
схему и цель симулятора. Приложение и интеграция рендерера пока отсутствуют.

## Правила изменений

- Следуй общему API-контракту и сохраняй совместимость с сервером между
  независимыми выпусками. Обрабатывай состояния сети и повторные действия.
- Основные экраны получаются из общего BDUI-описания. Оболочка выполняет
  поддерживаемые действия и системные интеграции. Отличай серверную правку
  от изменений рендерера и SDK, требующих новой сборки; проверяй старую сборку.
- Для ссылок-приглашений проектируй вход в нужный план, авторизацию по
  согласованному сценарию и возврат к исходному действию.
- Учитывай жизненный цикл приложения: сворачивание, восстановление и возврат
  из системных диалогов. Состояние общего плана подтверждается сервером.
- Уведомления, календарь, фотографии и другие системные возможности подключай
  по требованиям конкретной фичи с обработкой отказа в разрешении.
- Проверяй доступность затронутых экранов и увеличение системного размера текста.

## Проверки

Приложение и его сборка ещё не настроены. Для сборки iOS потребуется macOS
с Xcode. Пока проверяй эту инструкцию через `npm run agent:check` из корня;
не представляй такую проверку как успешную сборку iOS.
