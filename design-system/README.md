# Дизайн-система somewhere

Источник значений — [tokens.json](tokens.json), версия — [version.json](version.json),
читаемый [каталог](catalog.md). [Реестр эталонов](authority.json) связывает публикацию
с одобренными макетами; [контракты](../docs/design/components/README.md) определяют
композицию, состояния и платформенные различия.

```sh
npm run design:generate
npm run design:check
npm run design:test
npm run design:ready -- --manifest openspec/changes/<change>/design-manifest.json
```

Генератор использует Style Dictionary 5.7.1 и ограниченное DTCG-подмножество:
`color` (sRGB), `dimension` (px), `duration` (ms), `number`, `fontFamily`,
`fontWeight`, `cubicBezier`, типизированные алиасы. Другие типы/единицы и циклы
отклоняются. Это не заявление полной совместимости с DTCG 2025.10.
CSS/TS получают CSS-значения, Swift — Color/CGFloat/секунды, Compose — Color/dp/sp/ms.
Масштабируемые текстовые стили и safe area — ответственность платформенного адаптера.
Общие геометрические `breakpoint.chatCompactHeight/chatNarrowWidth` экспортируются
в native как CGFloat/dp; только web-routing `breakpoint.mobile/tablet` исключены.
Имена native — `breakpointChatCompactHeight` и `breakpointChatNarrowWidth`.

Новые компоненты используют роли `color`, `space`, `typography`, `radius`, `motion`,
`component`; primitive `palette` не экспортируется. Геометрические 0/1,
относительная раскладка и вычисления из данных не требуют бессмысленных токенов.
Новый визуальный смысл оформляется токеном после согласования дизайна.
Обход через вычисленные цвета или перенос legacy-значения запрещён.

`legacy-literals.json` — инвентарь прежнего долга по файлу/строке/числу повторов,
не разрешение использовать эти значения в новом коде. Проверка лексическая,
не универсальный анализ всех выражений. Не обновляйте инвентарь для прохождения CI:
удаляйте покрытые записи при миграции через `npm run design:prune` (только удаляет,
никогда не разрешает новый literal). Изменение исключения требует причины,
ссылки на решение и отдельного ревью. Прежние iOS accent/selectedSegment и
Android message временно сохраняются в адаптерах; они отмечены в каталоге.

## Публикация

Навык `design-system-publish` применяется после подтверждения дизайна пользователем.
Обновите источник, контракты, authority и версию одной поставкой. SemVer:
patch — исправление документации/генерации без смены смысла; minor — новый
совместимый токен/вариант; major — удаление/переименование или изменение
действующих значений/поведения. В [CHANGELOG](CHANGELOG.md) укажите затронутые
компоненты. Generated-файлы коммитятся вместе с источником, вручную не меняются.

Начальная публикация покрывает основы и пилотные компоненты. Она не объявляет
весь существующий UI мигрированным. Новые UI-изменения сразу следуют системе,
остальные экраны переносятся при следующем изменении соответствующей области.
