# Изменения дизайн-системы

## 3.0.0 · 2026-10-28

По требованию пользователя изменён web-путь выбора медиа: сначала форма,
затем явный picker. Отмена не закрывает форму. Добавление вайба напрямую,
компактная desktop-модалка; полный снимок без обрезки. Прежние токены сохранены.
Native-поведение не объявляется исправленным; вся приёмка остаётся открытой.

## 2.5.2 · 2026-10-28

По прямому решению пользователя уточнено удаление на desktop: Backspace в
composer, без отдельной кнопки в панели. При фокусе поиска редактируется запрос.
Мобильная кнопка сохраняется; raw-композиции и значения токенов не меняются.
Исправлено противоречие общей формулировки теста. Добавлены пропущенные calendar
состояния в manifest по уже принятому календарному макету; прежние отчёты
сохранены, готовность требует нового независимого прохода.

## 2.5.1 · 2026-10-27

Заполнен пробел raw для уже описанного пункта «Кто прочитал» при нулевом
receipt: строка под реакциями внутри меню собственного сообщения, переход
после exit в readers и возврат фокуса. Значения и утверждённое поведение
прежние; добавлены конкретные состояния manifest всех трёх клиентов.
Raw2.5.0 сохранён. Новый исходный фрагмент проверен во встроенном браузере;
это не независимая приёмка приложений.

## 2.5.0 · 2026-10-27

Принятый UX v1 read/unread и окна чата опубликован в raw/контракте трёх
клиентов: badge, divider, readers sheet, догрузка и переход к новым. Используются
существующие роли; новых токенов нет. Независимая приёмка открыта.

## 2.4.1 · 2026-10-27

Уточнён исходный межплатформенный scope UX v1: очередь в одной строке на
web/iOS/Android. Нативные состояния явно внесены в manifest; новые токены и
композиции не добавлены. Независимая приёмка всех клиентов открыта.

## 2.4.0 · 2026-10-27

Публикация same-row web outbox из разрешённого chat UX v1.
Новых токенов нет. Источники raw проверены только по коду; live UI/design review
остаются checkpoint, прежние pass не перенесены.

Уточнён телефонный iOS scope: кнопки, жесты и экранная клавиатура. Hardware
Escape сохраняется как дополнительная проверка; исторические результаты неизменны.

## 2.3.0 · 2026-10-27

По прямому уточнению пользователя добавлен motion-вариант меню composer по плюсу:
opacity/сдвиг 8, enter 180/exit 150 ms, retained exit, rapid reopen, Reduce Motion.
Используются существующие space.s8, mobileSheet/fast и standard; новых токенов нет.
Raw 2.2.0 и отчёты сохранены. Композиция и состав меню прежние.

## 2.2.0 · 2026-10-27

Дополнен motion-контракт панели эмодзи: mobile height/opacity, desktop opacity,
enter 180 / exit 150 ms, мгновенный Reduce Motion, безопасное повторное открытие.
Опубликованы роли emojiPanelEnter/Exit на существующей шкале. Композиция прежняя.
Raw обновлён, snapshot 2.1.0 и прежние отчёты сохранены; новая приёмка обязательна.

## 2.1.0 · 2026-10-27

Совместимое дополнение ролей существующих raw-карточек: максимальная ширина,

## 1.1.0 — 26–27.10.2026

Опубликованы роли форм из утверждённого styles.css: ширина колонки,
отступы на desktop/tablet, мобильный и desktop-заголовки, трекинг и интервал полей.
Добавлены ширины боковых панелей, планшетная граница и толщина рамки обложки.
Добавлена рамка `color.subtleBorder` из `.button.subtle` утверждённого styles.css.
Опубликованы роли `component.button` и `typography.size.button` из того же
утверждённого `.button`, в том числе для вторичного приглашения из сведений встречи.
Уточнена область мобильных нижних панелей
по принятой коррекции пользователя. Удалён устаревший путь обращения из сведений
встречи. Для возобновлённой реализации опубликована подробная матрица форм,
состояний и viewport; исторический пилот не подменяет новую live-приёмку.
Существующие значения токенов не менялись.
Коррекция 27.10: мобильный онбординг не содержит дополнительного знака вопроса
или панели помощи/документов; независимая проверка охватывает весь экран приложения.
Принятая коррекция панелей получила отдельную ревизию реальных HTML-макетов
`2026-10-27-chat-sheets`; старые raw и evidence сохранены. Добавлены роли
`color.sheetBackdrop` и `component.sheet.backdropBlur` из принятого `.poll-overlay`
макета даты. Они не извлечены из реализации; системное затемнение native —
явная платформенная адаптация. Непокрытые макетами состояния остаются в манифесте.
Роли `component.icon.strokeWidth` и `focusOffset` воспроизводят SVG-штрих и
клавиатурный фокус иконки из исходного styles.css; применяются к новому варианту
панели, не меняют несвязанные компоненты.
Компактный состав в сведениях и боковой панели получил роли
`color.participantChip*` и `component.participantChip`: финальные общие
`.people`, `.person`, `.people-more` исходного styles.css (29 px, три цвета,
инициал и счётчик). Перекрывающиеся круглые аватары карточек списка не заменяются
плашками; варианты отвергнутых `.compact` карточек не используются как источник.
Размеры текста плашек опубликованы в `typography.size.participantChip*`, чтобы
на Android генерировались sp; вес инициала — `typography.weight.participantChipAvatar`.
`typography.size.sectionHeading` воспроизводит h3 исходного CSS для сведений встречи.
