# Изменения дизайн-системы

## 1.1.0 — 26–27.10.2026

Опубликованы роли форм из утверждённого styles.css: ширина колонки,
отступы на desktop/tablet, мобильный и desktop-заголовки, трекинг и интервал полей.
Добавлены ширины боковых панелей, планшетная граница и толщина рамки обложки.
Добавлена рамка `color.subtleBorder` из `.button.subtle` утверждённого styles.css.
Опубликованы роли `component.button` и `typography.size.button` из того же
утверждённого `.button`, в том числе для вторичного приглашения из сведений встречи.
Уточнена область мобильных нижних панелей
по принятой коррекции пользователя. Удалён устаревший путь обращения из сведений
встречи. Для возобновлённой реализации опубликована подробная матрица форм,
состояний и viewport; исторический пилот не подменяет новую live-приёмку.
Существующие значения токенов не менялись.
Коррекция 27.10: мобильный онбординг не содержит дополнительного знака вопроса
или панели помощи/документов; независимая проверка охватывает весь экран приложения.
Принятая коррекция панелей получила отдельную ревизию реальных HTML-макетов
`2026-10-27-chat-sheets`; старые raw и evidence сохранены. Добавлены роли
`color.sheetBackdrop` и `component.sheet.backdropBlur` из принятого `.poll-overlay`
макета даты. Они не извлечены из реализации; системное затемнение native —
явная платформенная адаптация. Непокрытые макетами состояния остаются в манифесте.
Роли `component.icon.strokeWidth` и `focusOffset` воспроизводят SVG-штрих и
клавиатурный фокус иконки из исходного styles.css; применяются к новому варианту
панели, не меняют несвязанные компоненты.
Компактный состав в сведениях и боковой панели получил роли
`color.participantChip*` и `component.participantChip`: финальные общие
`.people`, `.person`, `.people-more` исходного styles.css (29 px, три цвета,
инициал и счётчик). Перекрывающиеся круглые аватары карточек списка не заменяются
плашками; варианты отвергнутых `.compact` карточек не используются как источник.
Размеры текста плашек опубликованы в `typography.size.participantChip*`, чтобы
на Android генерировались sp; вес инициала — `typography.weight.participantChipAvatar`.
`typography.size.sectionHeading` воспроизводит h3 исходного CSS для сведений встречи.

## 1.0.0 — 26.10.2026

Первая техническая публикация утверждённых основ: цветовые роли, типографика,
интервалы, размеры, движение, карточка встречи, навигация, формы чата и вайбы.
Источники: пакет meeting-experience-refresh от 25.10 и коррекции 26.10.
Генерация web/SwiftUI/Compose; новые значения контролируются, старые
расхождения перечислены отдельно. Нативные legacy-алиасы сохраняют прежний
внешний вид до приёмки соответствующих экранов.
