# UX: контракт существующего дизайна

Новый пользовательский сценарий не добавляется. Источник —
[утверждённый UX](../meeting-experience-refresh/ux.md) и его макеты,
согласованные 25.10.2026, с коррекциями 26.10.2026. Прототипы не переписываются
под текущий код. `docs/design` становится точкой входа, машинные значения —
`design-system/tokens.json`. Новый вид требует решения пользователя;
извлечение уже утверждённых значений повторного согласования не требует.

Пилот процесса: список/календарь с карточкой встречи и действия чата.
Карточка: обложка справа выступает наружу, перекрывающиеся аватары справа снизу,
дата на ярлыке, корона организатора; будни сливовые, выходные серо-зелёные.
Длинный текст расширяет карточку. Отсутствующее фото/аватар имеют fallback.
Hover отсутствует на touch; reduced motion выключает перемещения.

Переход карточка → чат → назад восстанавливает список/календарь. Меню плюса
открывает выбранное действие; на мобильных web/iOS/Android это нижняя панель
поверх чата, на desktop отдельная страница. Отмена сохраняет черновик,
успех возвращает чат; ошибка сохраняет поля и ключ повтора. Нижней навигации
и сервисных ссылок внутри панели нет. Последняя коррекция имеет приоритет
над оболочкой `action-*.html`; эти HTML задают содержимое формы.

Матрица ревью включает обычную/длинную/без обложки карточку, перекрытие аватаров,
клавиатурный фокус, reduced motion, открытие/закрытие/ошибку формы и клавиатуру.
Для native учитываются pt/dp, safe area, VoiceOver/TalkBack, увеличение текста,
системный Back. Web проверяется на 320/390/768/1440 CSS px. Изображения разных
платформ не обязаны совпадать пиксельно: проверяются свои baselines и общий контракт.

Приостановленная реализация `meeting-experience-refresh` не возобновляется
этим инфраструктурным изменением. Пилот проверяет применимость правил на
доступных материалах и сообщает реальные несоответствия; исправления экранов
остаются в её задачах. Исторические скриншоты не считаются свежим evidence.
