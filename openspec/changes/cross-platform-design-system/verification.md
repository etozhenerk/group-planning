26.10.2026. Исходный main: daeefe5. Проверяется инфраструктура публикации и
ревью, подключение эквивалентных палитр; приостановленные UI-задачи не закрываются.

## Пройдено

- `design:test`: 28 тестов. Алиасы/единицы/циклы, воспроизводимость, ручная
  порча generated, новые/повторно введённые literals, устаревшие входы/эталоны,
  пропущенные платформы/состояния, evidence, независимость, provenance,
  checkbox-гейт, ошибочные пути/ID и остановка без зацикливания.
- `design:check`: генерация, authority, инвентарь legacy, manifest и отчёт.
  Это структурная проверка, не визуальная приёмка приложения.
- `agent:check`: OpenSpec strict, ссылки, три проектных навыка и закреплённые версии.
- `quick_validate.py`: оба новых навыка валидны. PyYAML для валидатора установлен
  только в `/tmp/somewhere-skill-validator`, окружение проекта Python не менялось.
- CI routing: 37 тестов; release tooling: 28 тестов; actionlint 1.7.12 — без ошибок.
- Web: `web:check` (включая 85 unit-тестов), `web:build` — прошли.
  Архитектурная проверка допускает отдельный generated-файл глобальных токенов,
  остальные правила FSD/TS/компонентов сохранены.
- iOS: чистая simulator-сборка и анализ через build.sh; целевой swift-format
  для AppPalette/DesignTokens — прошёл.
- Android: целевой ktlint DesignTokens/SomewhereTheme прошёл. Debug/Release APK, lintDebug/lintRelease, unit и Debug instrumentation
  APK — прошли. XML-палитра тоже генерируется, чтобы сохранить системные resources.
- `design:ready` на пилоте завершился ненулевым кодом: UI-отчёт historical,
  не принят и после доработок контекста устарел. Это ожидаемый негативный результат.
- `design:inspect-report` проверяет /tmp отчёт без записи в приложение и честно
  возвращает currentAcceptance=false.

## Ограничения и оставшаяся проверка

- Полный native pipeline не зелёный из-за прежнего checkpoint: swift-format
  находит ошибки в формах/моделях и MeetingActionDraftTests; Android formatCheck
  — в прежних UI/state-файлах. Эти файлы не изменялись данной задачей.
- QA Android APK собирается, но QA instrumentation не компилируется:
  ExperienceUiTests.kt:62–65 обращается к CustomActions; ошибка есть в исходном
  daeefe5 и код теста в этой поставке не менялся. Отдельные Debug-тесты собираются.
- Полные E2E/live-сценарии трёх клиентов и новая визуальная приёмка не выполнялись.
  Перенос оставшихся компонентов/literals, свежие fixtures/baselines и исправление
  экранов продолжаются в meeting-experience-refresh после возобновления.
- Hook проверен тестами с событиями Stop; фактическая загрузка и доверие точной
  конфигурации в установленном Codex не подтверждены. Основной обязательный
  порядок действует через AGENTS/OpenSpec и проверки независимо от hook.
- Новые библиотеки native snapshot-тестов не установлены. Их подключение
  относится к миграции конкретных компонентов; существующие runners сохранены.
- npm audit сообщает прежний moderate fast-uri через уже существующий ajv;
  это не новая зависимость Style Dictionary. Автоматический upgrade API-инструментов
  в эту задачу не включался.

Система опубликована как версия 1.0.0. Это основа и обязательный процесс для новых
изменений, не заявление полной миграции и приёмки всех прежних экранов.
