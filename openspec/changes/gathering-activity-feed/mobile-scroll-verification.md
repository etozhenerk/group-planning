# Проверка мобильной прокрутки

25 октября 2026 года. Область: web, без изменения API или нативных клиентов.
Исходное сообщение пользователя — лишняя горизонтальная и вертикальная
прокрутка на iPhone 18 Pro. Конкретный экран пользователь не уточнил.
[Ожидаемое поведение и состояния](mobile-scroll.md).

## Воспроизведение и исправления

- В локальном WebKit длинный адрес без пробелов выходил за ширину панели
  «Детали встречи». `min-width: 0` и перенос внутри значения факта исправляют
  также публичное приглашение; иконка сохраняет размер.
- У мобильных полей вычисленный размер шрифта был 15 px. Теперь минимум
  16 px применяется и к обычным полям, и к полям даты/времени Gravity.
  Пользовательский zoom не ограничивается.
- Чат занимает видимую область браузера; Visual Viewport API обновляет высоту
  и смещение при открытии клавиатуры. Панели используют ту же доступную высоту.
  При pinch zoom перерасчёт не выполняется. Скролл остаётся внутри ленты
  и длинного содержимого панели.
- Открытый диалог фиксирует фон и сохраняет координаты страницы. Для body
  используется `overflow: clip`, чтобы sticky-шапка не меняла scroll container
  и не уезжала. После закрытия возвращаются прежние стили, позиция и фокус.

Короткие страницы в обычном состоянии до исправления не показали лишней
высоты. Вертикальная прокрутка длинного лендинга, создания встречи и календаря
с повесткой необходима и сохранена.

## Проверки

Среда: macOS arm64, Node.js 22.22.3, Go 1.27.2, Playwright 1.64.1,
Chromium и WebKit 27.2 (v2370). Новый проект Playwright эмулирует мобильный
WebKit профилем iPhone 13 Pro с изменённым viewport 402×874; это размер
проверки для экрана iPhone 18 Pro, а не запуск Safari на этом устройстве.

Команда затронутых browser-сценариев из корня:

```sh
npm run test:e2e --workspace @somewhere/web -- \
  tests/27-mobile-scroll.spec.ts tests/03-layout.spec.ts \
  tests/15-poll-modal.spec.ts tests/16-dialog-motion.spec.ts \
  tests/18-loading-logout.spec.ts tests/26-account-deletion.spec.ts
```

Проверяются ширины 320, 390, 402, 430, 768 и 1440 px: длинные строки,
поля формы, отсутствие второго scroll в чате, панели опроса/деталей,
сохранение sticky-шапки и позиции списка, возврат фокуса, анимации,
reduced motion, skeleton/logout и подтверждение удаления аккаунта.
В CI и инструкции установки добавлен WebKit.

| Проверка | Результат |
| --- | --- |
| Указанный browser-прогон | 31 сценарий: 26 Chromium и 5 mobile WebKit, все пройдены |
| `npm run web:check` | TypeScript, ESLint, CSS, FSD/AST, Prettier и 62 unit-теста пройдены |
| `npm run web:build` | Production-сборка пройдена |

## Ограничения

Изменение visual viewport в E2E моделируется событием: тест доказывает
реакцию раскладки, но не поведение системной клавиатуры, адресной панели
и жестов Safari на физическом iPhone. Эта ручная проверка остаётся.
Backend, iOS и Android повторно не собирались: их исходники не менялись.
Публикация и перезапуск сервисов в рамках исправления не выполнялись.
