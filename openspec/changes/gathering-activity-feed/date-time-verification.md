# Проверка полей, шапки и панелей встречи

20 октября 2026 года. Веб-формы создания и настроек используют Gravity DatePicker
и отдельное поле времени. Выбор пояса заменён автоматическим определением;
сохранённый черновик и встреча продолжают использовать исходный IANA-пояс.
Иконки стоят слева в одинаковой области шириной 44 px; очистка даты — справа.

## Результат

- `npm run web:check`: типы, ESLint, CSS, FSD/AST, Prettier и 20 модульных тестов.
- `npm run web:build`: обычная production-сборка; demo build собирается отдельно.
- `npm run web:test:e2e`: 22 сценария Chromium с настоящим Go API в новом
  тестовом процессе. Работающее пользовательское демо не перезапускается.
- `npm run agent:check` и строгая валидация OpenSpec проверяют обвязку/документы.

Браузерные проверки подтверждают открытие кликом на текст и свободную область поля,
выбор дня, переключение месяцев, Alt+↓,
Escape и возврат фокуса, отсутствие горизонтального переполнения на 320/390/1440 px,
независимость даты и времени. Геометрия иконок измеряется относительно края
каждого поля: одинаковая линия по центру, свободное место перед иконкой ≥12 px.

Дата и время обязательны; неполная форма не отправляет создание.
В поясе Екатеринбурга сервер получает `2026-10-24T19:00:00+05:00` и
`Asia/Yekaterinburg`. Повторяющийся час в Нью-Йорке требует явного выбора
варианта в пользовательском списке. Изменение описания из другого пояса
сохраняет исходный instant, включая секунды и доли секунды. Календарь
в настройках остаётся поверх нативного dialog; Escape закрывает только его.

Модульные тесты покрывают пустую/неверную дату, високосный год, недопустимые часы,
IANA-пояс нового черновика, несуществующее и повторяющееся местное время.
Тексты проверены по проектному `product-copy-editor`: подписи называют вводимые
данные, пояс уточняется один раз, ошибка сообщает необходимое действие.

## Детали и действия без повторов

Шапка содержит одно название, а текущие детали находятся в единственном
адаптивном блоке: сайдбаре от 1170 px или панели по `i` ниже этой границы.
Браузерные сценарии проверяют одну реализацию при изменении ширины туда/обратно,
один заголовок, отсутствие вступления ленты с теми же данными.

Для личного списка проверены загрузка, ошибка, пустой и непустой результат
на 320/1440 px: ровно одна ссылка создания, правильное размещение и отсутствие
горизонтального переполнения. Повтор загрузки остаётся отдельным действием.

Шапка проверена по вертикальным координатам текста и кнопок. Кнопка приглашения
использует Share; стили шапки не меняют размер и текст действий внутри панели.
Проверены появление диалога/нижней панели, её положение, читаемость кнопки
копирования, Escape/фокус и отключение анимации при reduced motion.

## Снимки и границы проверки

Снимки находятся в [assets/date-time-fields/](assets/date-time-fields/):
`date-time-fields-*` — поля с иконками слева, `date-picker-*` — открытый календарь.
В [assets/ui-polish/](assets/ui-polish/) сохранены шапка встречи, панели приглашения
и состояния личного списка. В имени указана ширина в CSS px. Клавиатурное выделение даты оставлено намеренно.

Среда: macOS arm64, Node.js 22.22.3, Go 1.27.2, Chromium из Playwright 1.64.1.
Мобильная проверка здесь означает ширину браузера; Safari, реальные устройства
и нативные клиенты ещё не проверены. API и серверное хранение не менялись.
Реальная авторизация, календарный вид списка и загрузка обложки — отдельные этапы.
