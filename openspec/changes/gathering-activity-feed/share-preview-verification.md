# Короткие приглашения и серверное превью

20 октября 2026 года. Новая ссылка — `/i/` + 22 символа из 128 случайных бит.
32-байтные токены и прежний путь продолжают работать. Пользователь отдельно
подтвердил публичность полного описания по ссылке; это отражено в API, форме,
приглашении и продуктовых документах. Секреты OAuth/сессий не сокращались.

## Реализация

Go `internal/webui` отдаёт собранный React-клиент и формирует экранированные
метатеги в HTML приглашения: title/description, canonical, Open Graph и Twitter
card. Один публичный mapper используется в JSON API и HTML; профили, ответы
других участников и переписка не попадают в preview. Пустое описание заменяется
датой/местом. Картинка — [фирменный PNG](../../../frontend/web/public/share-card.png)
1200×630 с существующим знаком; загрузка обложек остаётся отдельным этапом.

Web включается через `SOMEWHERE_WEB_DIST`/`SOMEWHERE_WEB_ORIGIN`, без настройки
Яндекс ID. Базовый HTML читается при запросе, данные — из текущего snapshot.
Абсолютные URL берутся из доверенного origin. Старый путь сохраняет query
при переходе на `/i/`; логика входа и RSVP поддерживает оба размера токена.

## Проверки

- Go: тесты с race detector, vet, сборка и обязательное оформление.
- Контракт: OpenAPI, положительные fixtures и реальные HTTP-ответы; отрицательные
  проверки по-прежнему отвергают сообщения и профили в публичном DTO.
- Web: типы, линтер, FSD/AST, Prettier, 20 модульных тестов.
- Playwright: 23 сценария с настоящим Go API и test-only provider, включая
  создание/вход/RSVP с коротким токеном и отмену входа без потери приглашения.
- Новый сценарий запрашивает приглашение в браузере с выключенным JavaScript:
  проверяет метатеги, один title/description, канонический адрес, PNG и размеры,
  HEAD, старый путь, отсутствие приватных полей, экранирование script/кавычек
  и обновление описания. Неизвестный токен даёт 404 без данных встречи.
- Go-тесты дополнительно подтверждают существующий 43-символьный токен,
  неподдельность configured origin, отсутствие OAuth-зависимости web и fallback даты.

Фактическая карточка Telegram/Discord ещё не проверена: localhost недоступен
внешнему боту. После публикации нужны публичный HTTPS и доступный PNG;
собственный кеш мессенджера может обновляться независимо от страницы.
Спецификация полей — [Open Graph](https://ogp.me/).
