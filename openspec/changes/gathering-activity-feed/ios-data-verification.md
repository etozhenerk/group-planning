# Проверка данных и сессии iOS — 6.2

Проверено 20 октября 2026 на macOS / Xcode 26.0.1 (17A400), Swift 6.2,
iPhone 17 / iOS Simulator 26.0.1. Языковой режим Swift 6, minimum iOS 17.

- `sh scripts/format.sh --check`: строгий swift-format без нарушений.
- `sh scripts/build.sh`: clean/build/analyze прошли после форматирования.
- `sh scripts/test.sh`: 29 тестов в 6 наборах Swift Testing прошли без пропусков.
  Результат: `.build/TestResults-20261020T135153-64839.xcresult` (локальный артефакт).
- `npm run agent:check` и строгая структурная проверка OpenSpec прошли.

Покрыты общие fixtures контракта, nullable и отсутствующие поля, большие
строковые sequence/revision, неизвестные события, RFC3339 и частичный PATCH.
API проверен на Bearer, стабильные request UUID, ошибки 401/403/503,
некорректные ответы, запрет перенаправлений и отмену настоящего URLSession
через тестовый URLProtocol. Сетевых запросов в живой демостенд тесты не делают.

Настоящий Security/Keychain проверен на сохранение, обновление, удаление,
изоляцию окружений и `WhenUnlockedThisDeviceOnly`. Использован уникальный
тестовый service и временный симулятор, удаляемый скриптом. Тестовый хост имеет
локальную подпись Xcode с simulated entitlements. Пользовательский симулятор
и его данные не сбрасывались.

Проверены очистка всей приватной памяти при 401/выходе, закрытие конкретной
встречи при 403 чтения, сохранение чата при отказе в правах организатора,
поздние ответы старой сессии, отмена восстановления, сохранение предыдущих
данных при сетевом сбое и порядок перекрывающихся загрузок.

Экраны списка/встречи/чата, реальный Яндекс ID, Universal Links, публикация
и запуск на физическом устройстве не проверены: это следующие задачи.
Запуск на минимальной iOS 17 не выполнялся. Анимация знака добавлена в
[план брендинга](../../../docs/design/branding.md), её реализация ещё впереди.
