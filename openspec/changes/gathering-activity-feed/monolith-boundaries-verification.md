# Проверка границ модульного монолита

Дата: 22.10.2026. Задача 2.6 изменения `gathering-activity-feed`.

## Изменения

- `server.Serve` создаёт прикладной сервис встреч и связывает его с HTTP,
  публичным web-превью и проверкой приглашения в identity.
- `httpapi` получает готовый сервис, `webui` — только `InvitationReader`.
  Проверка приглашения для identity возвращает наличие и ошибку без доступа
  к хранилищу встречи. API и правила атомарных изменений сохранены.
- `go run ./cmd/check-dependencies` проверяет направления импортов и текущие
  порты хранения/конструкторы по `internal/architecture/policy.go`.
  Проверяются production-файлы под любыми build tags; тестовые fixtures исключены.
- В Backend Checkers появился отдельный шаг Dependency boundaries с собственным
  результатом и логом. Фильтры запуска по платформам сохранены.
- ADR 0003 описывает фактическую сборку, владение данными и будущие границы
  подписки, активаций помощника и модерации. Пустые модули не добавлены.

## Результаты

Проверки реализации выполнены на копии `main` с файлами только этой задачи.
Ранее начатые изменения календаря исключены из копии и сохранены без изменений.

| Проверка | Результат |
| --- | --- |
| `go run ./cmd/check-dependencies` | Нарушений нет. |
| `go test -race ./...` | Все пакеты проходят; гонок не обнаружено. |
| `go vet ./...`, `go build ./...` | Успешно. |
| `sh scripts/format.sh --check`, `gofmt -l .` | Успешно; замечаний нет. |
| `go run ./cmd/storage-demo` | Сценарий memory-хранилища проходит. |
| `npm run api:test` | 28 схем, 13 fixtures и 106 реальных HTTP-ответов соответствуют OpenAPI. |
| CI routing / reporting | 26 Node-тестов и 10 Python-тестов проходят. |
| `actionlint` v1.7.12 | Workflow проходит. |
| `npm run agent:check` | Инструкции, ссылки, схема OpenSpec и закреплённые инструменты проходят. |

Тесты контроллера проверяют разрешённые и запрещённые направления, зависимость
ядра от адаптера, чужое хранилище, алиасы, dot/blank-импорты, неактивный build tag,
неизвестный пакет, вложенный модуль и неверные исходники. Отдельно проверены
ошибки и отмена чтения приглашения, отсутствие побочных изменений и копирование
публичного снимка.

## Ограничения

Контроллер проверяет объявленную политику, а не доказывает все свойства архитектуры.
Новые области, адаптеры и порты требуют обновления политики и её тестов.
Права, повторы и атомарность покрываются прикладными и HTTP-тестами.

Реальная БД, очередь и сохранность после перезапуска остаются в группе 14.
UI, нативные приложения и реальный провайдер авторизации этой задачей не менялись.
