# Проверка опросов даты в web · 23.10.2026

## Реализация

Web поддерживает обязательный день с необязательным временем, создание опроса
из чата, настройки, голосование и смену голоса, добавление даты, скрытые результаты,
выбор организатора при ничьей и отображение итогов. Собственные сообщения и карточки
располагаются справа. Сервер предоставляет операции по контракту этапа 10.2.

## Исправления после проверки пользователем

- Создание и редактирование встречи, RSVP и напоминание о времени остаются
  системными строками по центру, без имени и аватара. Бот отправляет только
  уведомления о голосовании. Клиент соблюдает это и со старым ответом сервера,
  который ошибочно добавлял `sender.kind=bot` обычным событиям.
- Плюс имеет фиксированный размер 24 px внутри области 44 × 44 px.
- Иконка шаринга — 20 px, по центру мобильной кнопки 44 × 44 px;
  скрытая подпись не оставляет пустого места.
- Карточка опроса помещается в строку с аватаром при ширине 320 px;
  переключатели и чекбоксы не наследуют размеры текстовых полей.
- Стиль удаления варианта не затрагивает кнопки календаря внутри поля.
- Подсказка поля сообщения помещается на узком экране.

## Границы проверки

Проверки выполнены в Chromium с тестовым OAuth-provider и хранилищем в памяти.
Реальная авторизация и постоянное хранилище остаются отложенными.
Нативные клиенты этим отчётом не подтверждаются. Для закрытия всей задачи 10.3
нужен оставшийся проход ошибок, потери доступа и переходов времени в UI;
серверные проверки этих правил не заменяют браузерную приёмку.
