# Основа Android · 7.1

21 октября 2026 года. Область — минимальное Compose-приложение и его сборка.
Минимум API 26, compile/target SDK 36, Build Tools 36.0.0, JDK 17.
Закреплены Gradle 8.14.3, AGP 8.13.1, Kotlin/Compose compiler 2.2.20,
Compose BOM 2025.11.01, Activity 1.11.0 и ktlint 1.5.0.
Это совместимый закреплённый набор, не заявление о самых новых версиях.

Результат реализации и проверки —
[android-bootstrap-verification.md](android-bootstrap-verification.md).

## Экран и границы

Точка входа — MainActivity, Compose Surface и статичная фирменная подпись
по [брендингу](../../../docs/design/branding.md): знак слева и `somewhere`,
графитовый фон и белый текст из [основы v0.7](../../../docs/design/foundations.md).
У подписи на этой поверхности шрифт 37,5 sp, знак 45 dp и промежуток 13,5 dp.
Рисунок знака точно перенесён из существующего SVG в VectorDrawable.
Пользовательские встречи и вход ещё не подключены: этот корневой экран служит
только проверке Android-сборки. Он не изображает бесконечную загрузку.
Новых продуктовых экранов, кнопок входа и новых форм задача 7.1 не добавляет.

Системные отступы учитываются через safeDrawingPadding; status/navigation bar
используют светлые значки. Dynamic Color отключён, чтобы сохранять согласованную
палитру. Системный splash Android 12+ использует тот же знак и фон. Отдельный inset drawable
оставляет 42% поля с каждой стороны: знак занимает около 46 dp внутри системной
области 288 dp и помещается в круглую маску. Не передавай исходный вектор
напрямую в windowSplashScreenAnimatedIcon — система растянет и обрежет его.
Однократная анимация с названием и дальнейший переход относятся к 7.4,
где появится настоящий онбординг из пяти слайдов и состояние загрузки.
Смысл функций, цвета, компоновка карточек и собственные сообщения справа
сохраняют согласованные v0.7 и мобильное уточнение; новая дизайн-концепция не вводится.

## Структура и проверки

Один модуль `app`: Activity, небольшой root UI, тема и компонент бренда.
API/Repository/ViewModel добавляются в 7.2, без искусственных пустых слоёв.
Gradle version catalog фиксирует библиотеки; wrapper содержит SHA-256 дистрибутива.
Форматирование — ktlint с Android Studio style, четырьмя пробелами и лимитом 100.
Compose-функции сохраняют UpperCamelCase. Kotlin warnings и Android Lint warnings
считаются ошибками. Release использует R8/resource shrinker и остаётся без
публикационной подписи. Обычная сборка не содержит обхода авторизации.

План проверки: строгий форматтер, чистые Debug и Release, Lint для обеих
конфигураций, доступные unit-тесты, запуск на одном существующем Android AVD.
На этом этапе бизнес-логики нет: отсутствие unit-тестов нельзя выдавать за
пройденный набор. Проверки владельцев состояния добавляются в 7.2.
CI выполняет ту же команду, не создавая эмуляторы.

Совместимость: [AGP 8.13](https://developer.android.com/build/releases/agp-8-13-0-release-notes),
[Kotlin и AGP](https://developer.android.com/build/kotlin-support),
[Compose BOM](https://developer.android.com/develop/ui/compose/bom),
[ktlint 1.5.0](https://github.com/ktlint/ktlint/releases/tag/1.5.0).

Уведомления Lint о новых версиях (`AndroidGradlePluginVersion`, `GradleDependency`,
`NewerVersionAvailable`) остаются информационными: закреплённый совместимый стек
обновляется отдельной проверяемой правкой. Остальные предупреждения Lint блокируют
сборку. Baseline и подавления ошибок кода не используются.
