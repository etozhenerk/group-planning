# Tasks

Работа выполняется по [design.md](design.md), [api.md](api.md), [auth.md](auth.md)
и [макетам v0.7](ux.md). Статусы задач отражают только проверенную реализацию.
20 октября 2026 года пользователь отложил базу данных: сначала memory.Store
без PostgreSQL, Docker и миграций. Задачи 2.1–2.2 независимы от HTTP-контракта.

20 октября пользователь отложил реальное подключение и проверку Яндекс ID
до заключительного этапа. Выполненная серверная группа 3 сохраняется;
интеграционные тесты используют provider из `_test.go`. Клиентские экраны
можно разрабатывать на fixtures, тесты API — с тестовым провайдером.
Реальные циклы web/iOS/Android из 5.3, 6.3, 7.3 и 8.1 проверяются в конце,
перед итоговой приёмкой. Пока они не выполнены, весь сценарий не считается готовым.
Runtime-обход входа не добавляется.

**Первый рабочий срез — группы 1–8.** Пользователь подтвердил назначенную дату,
создание встречи, приглашение, ответ и чат на web, iOS и Android. Эти группы
можно начинать после принятия технического предложения; остальные функции
сохраняются в MVP. Группы 9–13 стартуют только после своих продуктовых/UX условий.
Их декомпозиция уточняется по принятым решениям до выполнения кода соответствующего этапа.

## Отложено: постоянное хранение

PostgreSQL, pgx/goose, SQL-миграции, интеграционные тесты реальной БД и резервное
копирование вынесены за текущий временный этап. Перед постоянным использованием
нужны отдельный план подключения и проверка репозитория теми же сценариями;
тесты memory.Store не закрывают надёжность хранения на диске.
