# Проверка серверной части опроса даты

Дата: 23.10.2026. Область: задача 10.2 на memory.Store и моках фоновых задач.
Проверки интерфейсов web/iOS/Android в этот отчёт не входят.

## Реализованное поведение

- Календарный день хранится отдельно от необязательного часа. Создание по старому
  `starts_at` совместимо с новым API; `starts_on` доступно в деталях, списке,
  приглашении и истории. Известный день без часа участвует в календаре и
  автоматически переходит в историю в начале следующего местного дня.
- Опрос создаёт любой пользователь с доступом к чату. Есть пять согласованных
  настроек, срок, добавление вариантов, замена/снятие собственного выбора,
  контроль ревизий и повторных запросов.
- Большинство от текущего состава применяется сразу для видимых результатов.
  Скрытый опрос ждёт фонового закрытия. Несколько лидеров разрешаются по максимуму;
  равенство максимальных результатов с большинством ожидает организатора.
- Перенос сохраняет местный час или его отсутствие, не сбрасывает RSVP и закрывает
  опрос. Неоднозначный/несуществующий час при смене смещения требует явного выбора.
- Одновременно активен один опрос. Выход из чата исключает голос, возвращение
  восстанавливает его. Закрытый результат уже не меняется от позднего RSVP.
  Ручная смена дня отменяет активный опрос без отложенного перезаписывания даты.
- Перенос, расписание перехода в историю и уведомление бота сохраняются атомарно.
  Системные записи имеют `sender.kind=bot`, исходный человек остаётся в `actor`.
  Бот не является участником и не увеличивает знаменатель большинства.
- Фоновое закрытие запускается независимо от чтений. Ограниченные повторы,
  backoff, состояние ошибки, ручной повтор и восстановление отсутствующей задачи
  проверены с управляемыми часами. Диагностика не содержит бюллетеней и текста чата.

## Результаты

| Проверка | Результат |
| --- | --- |
| `go test -race ./...` | Все пакеты проходят. После последней правки HTTP повторно проверен `go test -race ./internal/httpapi`. |
| `go vet ./...`, `go build ./...` | Успешно. |
| `go run ./cmd/check-dependencies` | Границы модулей соблюдены. |
| `sh scripts/format.sh --check`, `gofmt -l .` | Замечаний нет. |
| `npm run api:test` | 39 схем, 19 fixtures, 178 реальных HTTP-ответов соответствуют OpenAPI. |
| `npm run agent:check` | Ссылки, обвязка и структура OpenSpec валидны. |
| `git diff --check` | Замечаний нет. |

Сценарии включают 3 голоса из 6 без применения, четвёртый голос с применением,
одновременные решающие голоса, голос на дедлайне против закрытия, повторную
доставку, потерянный HTTP-ответ, ни одного голоса, максимум 5:4 и ничью 4:4.
Проверены запрет выбора лидера неорганизатору, потеря доступа перед повтором,
скрытые/анонимные результаты, отсутствие промежуточного результата в ленте,
добавление и сортировка вариантов, запрет переголосования и устаревшая ревизия.

Проверены откат при ошибке записи события, лимит неудачных закрытий, задержка
повторов, ручное восстановление с сохранением счётчиков, отсутствие записи
при GET после срока, изоляция вложенных бюллетеней в mock-транзакциях.
Дата без времени проверена в пагинации календаря, при очистке/возврате часа,
смене UTC-смещения, пропущенной полуночи, пропущенном дне и смене года.

## Ограничения

Данные и задачи остаются в памяти: перезапуск их теряет. Реальная БД, очередь,
сохранность и эксплуатационные инструменты относятся к группе 14.
Клиентские формы и карточки нового API ещё не подключены; 10.3–10.5 не закрыты.
До их реализации нужно закончить дополнительные состояния UX в 10.1.
Пользовательский демостенд не перезапускался; его данные не сбрасывались.
