# Функциональная проверка MVP на временном хранилище

25 октября 2026 года. Проверка группы 13 и первого среза 8.3–8.4.
Применяется к Go API с memory.Store и моками очереди, web, iOS и Android.
Группа 13.6 и пункт 8.4 остаются незавершёнными. По просьбе пользователя
работа сохранена до окончания полного повторного набора iOS и общего
межплатформенного прогона. Ниже зафиксированы только полученные результаты.

## Проверки сборок и API

- Go: полный `go test -race ./...`, vet, границы зависимостей, build,
  gofumpt/wsl — успешно после добавления стендов мобильных обложек.
- OpenAPI: 49 схем, 32 fixtures, 341 реальный JSON-ответ; двоичные PNG/HEAD
  проверяются отдельными HTTP-тестами, JPEG — тестами сервиса.
- Web: 62 unit-теста, строгие статические проверки и production/demo-сборки.
  Из 89 обычных browser-сценариев 88 исполняемых прошли (полный прогон и
  исправленный повтор основного сценария); общий native-сценарий выполняется отдельно.
- iOS: 108 Swift Testing тестов; строгий swift-format, чистые Debug/Release
  build + analyze. Для обложек три UI-сценария на iPhone 18 Pro / iOS 27.0.
  В повторном полном наборе до остановки прошёл 21 сценарий без ошибок,
  два CrossPlatformUITests были пропущены; весь набор не считается пройденным.
- Android: 112 JVM-тестов, чистые Debug/Release APK, Lint без ошибок/предупреждений,
  formatCheck, Debug/QA instrumentation APK. Все 35 UI-сценариев прошли на
  Somewhere_API_36; отдельные два этапа instrumentation с остановкой процесса
  подтвердили восстановление сообщения и черновика.

## Сброс после перезапуска

Команда из корня с Go 1.27.2 в PATH:

```sh
python3 scripts/test-mock-restart.py
```

Она собирает тестовый HTTP binary и последовательно запускает два отдельных
процесса с собственными memory.Store и тестовым OAuth-provider. В первом через
API создаётся встреча. После его остановки второй процесс возвращает 401
для старой Bearer-сессии, 404 для прежнего приглашения и встречи; новая сессия
имеет пустой личный список. Проверка прошла. Пользовательский API и его данные
не перезапускались. Конфигурация, credentials и временный бинарник удаляются
после проверки. PostgreSQL/Docker, хостинг и реальные OAuth-секреты не нужны.

## Совместимость клиентов

Проверены текущие исходники всех трёх клиентов с одним OpenAPI. Существующие
поля не удалены и не переименованы. Новые DTO/события читаются с допуском
неизвестных полей, старый PATCH без `cover` сохраняет обложку, старый клиент
может продолжать создание без фотографии. `cover_url` остаётся nullable-строкой.
Новый клиент отличает отсутствие поля PATCH, удаление `null` и новое фото.
Хеш идемпотентности старых запросов без обложки сохранён через `omitempty`.

Android декодирует дату без обязательного `starts_at`; общий fixture с фото
обнаружил и закрепил этот случай. Нативные клиенты сохраняют готовые JPEG-данные
в черновике, а не временный URI библиотеки. API проверяет bytes/MIME/пиксели и
не скачивает внешние URL. Проверки сборок не заменяют проверку старых опубликованных
бинарников: их матрица и реальные store-релизы относятся к заключительной приёмке.

## Границы результата

Реальный вход пользователь подтвердил для локальных трёх клиентов ранее.
В этом прогоне используются тестовые профили. Полный реальный OAuth-путь из
приглашения, повтор после уничтожения процесса, единая идентичность на платформах
и ручные VoiceOver/TalkBack остаются отдельно отмеченными незавершёнными проверками.

Встречи, сессии, изображения, receipts и очередь хранятся в памяти и теряются
при перезапуске API. Нет проверки SQL-миграций, сохранности, восстановления из
копии, доставки реальных уведомлений или стоимости облака. Это группа 14,
которую ведёт соседняя работа. Деплой в этой задаче не выполнялся; изменение
OpenSpec не архивируется до завершения всей согласованной приёмки.
