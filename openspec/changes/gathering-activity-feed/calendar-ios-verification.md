# Календарь iOS — проверка 22.10.2026

Реализована задача 9.4: список и календарь используют CalendarPage общего API.
Периоды, civil date, часовой пояс встречи, полный счётчик дня и даты без времени
согласованы с web. Переход в прошедшие определяется сервером; клиент обновляется
по refresh_after_seconds/next_transition_at и после возвращения на экран.

## Состояние и переходы

- Сохраняются выбранный день каждого периода, месяц и контекст после Back.
- «Сегодня» открывает текущий месяц, выбирает и фокусирует сегодняшний день.
- Недатированные встречи переключаются отдельно. Смена периода выходит из этого режима.
- Ошибка обновления сохраняет подтверждённые данные; 409 календаря сбрасывает
  пагинацию с сохранением фильтра. Старый ответ не заменяет текущий выбор,
  ответ после выхода не восстанавливает данные.
- Создание из календаря передаёт выбранную дату и сохраняет остальные поля
  черновика. Неопределённая отправка сохраняет прежнее тело и ключ повтора.
- Единственный CTA остаётся доступным над календарём. В пустом дне нет дубля.

## Оформление

По последнему решению пользователя закреплены только бренд и строка
«Мои встречи / Создать», во всю ширину экрана. Переключатели периода и вида
прокручиваются вместе с содержимым при любом размере текста. У нижней строки
при прокрутке скругляются только нижние углы; тень находится только снизу.
У бренда, верхних углов и боковых краёв тени нет. Полосы между строками нет.

Активный сегмент соответствует v0.7: #46414e. Его геометрия не меняется при
смене вида. Семь колонок календаря помещаются при AXXXL: размер цифр ограничен,
полная дата и количество встреч сохранены в accessibility label.

## Проверки

- Swift Testing: 77 тестов в 18 suites, включая calendar state/selection,
  обновление статуса, пагинацию, отмену, даты и создание из календаря.
- CalendarUITests: 4 сценария — неизменное положение переключателя при смене
  вида, выбор даты/месяца/периода/Back/Сегодня, пустой календарь и подстановка
  даты, AXXXL. Проверяется сохранение доступности создания при прокрутке
  и уход переключателя вместе с содержимым.
- Test-only Go HTTP fixture: race-тесты и форматирование прошли.
- Debug/Release build + analyze, swift-format и agent:check — штатные команды проекта.

Все UI-прогоны выполнены последовательно на одном уже открытом iPhone 17 / iOS 26,
UDID 761775B8-5C18-4928-ADDC-4A2EDC4AE0CB. Новые симуляторы не создавались.
Сессия используется только через отдельный UI-test host и test-only API.
Проверка VoiceOver на физическом устройстве не выполнялась: у пользователя
пока только симулятор. Реальный OAuth и постоянное хранилище остаются отложены.
Android-календарь — отдельная задача 9.5.
