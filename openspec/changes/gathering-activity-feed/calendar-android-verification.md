# Календарь Android — проверка 22.10.2026

Реализована задача 9.5. Список и календарь используют общий CalendarPage API:
разделы предстоящих/прошедших, отдельные встречи без даты, полные счётчики,
локальные даты в часовом поясе встречи и догрузку страниц.

## Поведение

- При первом открытии календаря выбирается ближайшая встреча раздела,
  при пустом разделе — сегодняшний день устройства. Календарь содержит
  42 дня с понедельника; смена месяца ограничивает выбранное число его длиной.
- Выбор вида, раздела и дня каждого периода сохраняется в SavedStateHandle.
  Back и пересоздание Activity сохраняют контекст; возврат на экран обновляет данные.
- Клиент не меняет статус встречи. Обновления следуют серверным
  refresh_after_seconds/next_transition_at; в фоне опрос приостанавливается.
  Ошибки используют увеличивающуюся задержку до 60 секунд, данные сохраняются.
- Устаревший ответ не заменяет новый выбор. 409 calendar_changed сбрасывает
  страницы с сохранением фильтра. Обычное обновление повторно загружает уже
  открытые страницы; выход из профиля очищает календарь вместе с приватными данными.
- Создание из календаря меняет только дату черновика, не подставляет время
  и сохраняет остальные поля. Уже отправленный запрос с неопределённым
  результатом сохраняет прежнее тело и ключ повторной отправки.

## Дизайн и доступность

Сверены v0.7, entry-home.md и итоговые снимки iOS. Бренд и строка
«Мои встречи / Создать» закреплены во всю ширину; период и вид прокручиваются.
Скруглены только нижние углы закреплённой панели; тень рисуется только снизу.
В календаре одна кнопка создания находится в шапке, в пустом списке — в пустом состоянии.

Активный сегмент #46414e, выбранный день светлый; сегодня обозначено контуром.
Под сеткой — общая панель дня с временем и местом каждой встречи. При крупном
системном шрифте переключатели становятся вертикальными, названия не рвутся
посреди слов. Числа календаря ограничены 22 sp, подписи дней недели — 16 sp;
семь колонок сохраняются, полная дата и число встреч доступны семантике Android.

## Воспроизведение

Из frontend/android при настроенных JDK 17, SDK 36 и Go 1.27.2:

```sh
sh scripts/check.sh
sh scripts/test-ui.sh calendar
```

Проверки выполнены на единственном Pixel_XL_API_36 / Android 16,
serial emulator-5554. До запуска adb не показывал устройств: запущен существующий
AVD, новые устройства не создавались. Скрипт тестов сам эмуляторы не запускает.

- Чистые Debug/Release APK, Kotlin formatCheck, Android Lint обеих конфигураций,
  JVM-тесты и сборка Debug/QA instrumentation APK.
- 78 JVM-тестов: общие fixtures, календарные даты/периоды, срок обновления,
  фон/возврат, сохранённый выбор, пагинация/409, поздние ответы, отмена,
  сброс сессии, создание из календаря и неизменность незавершённой отправки.
- 3 Compose UI-сценария по реальному test-only Go HTTPS API: список/календарь,
  два события в день, месяцы/периоды/Сегодня/Back/пересоздание Activity;
  пустой календарь, одна неподвижная кнопка и подстановка даты;
  font_scale=1.8, целые названия переключателей и семь колонок сетки.
- Race-тесты HTTP-пакета Go и его форматирование; agent:check и строгая
  валидация OpenSpec.

Снимки сняты через Compose captureToImage после завершения layout,
