# Вариант знака Somewhere · v1

19 октября 2026 года. Создан встроенным инструментом imagegen по запросу
пользователя о более оригинальном знаке вместо стрелки. Это предложенный
вариант, а не утверждённый логотип. Дизайн экранов пользователь одобрил отдельно.

[Исходный PNG](somewhere-mark-v1.png): три сходящиеся округлые петли,
светлый знак на графитовом фоне. В макетах заменяет декоративную стрелку рядом
с названием; стрелки навигации и действий сохраняют своё назначение.
Это растровый вариант для просмотра, готового векторного мастер-файла пока нет.

Первые два опыта с прозрачностью отклонены из-за артефактов по контуру.
В макетах используется третья генерация на сплошном фоне; изображение
скопировано из каталога generated_images в проект без изменения пикселей.
