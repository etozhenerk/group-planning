# Локальный Яндекс ID и web · 24.10.2026

Пользователь подтвердил реальный вход через ngrok после исправления callback
с дополнительным параметром cid. Конфигурация: [backend/docs/auth.md](../../../backend/docs/auth.md).
Токены и локальные настройки исключены из Git. Мобильные циклы 6.3/7.3 остаются открытыми.

Итоговый прогон: 54 unit-теста и 59 browser-сценариев прошли;
один общий web/iOS/Android сценарий штатно пропущен без мобильного стенда.
Проверены задержанный переход, Back/bfcache, ошибка/повтор, 401 и приглашение
без автоматического RSVP, reduced motion и ширины 320/390/768/1440 px.
Production-сборка обновлена без перезапуска сервера; публичный ngrok отдаёт
новый bundle с Cache-Control: no-store. Demo/E2E вынесены в .cache/web-demo.

Серверные race/vet/build/format и API-контракт (39 схем, 19 fixtures,
178 HTTP-ответов) проходят. iOS swift-format и чистая Debug simulator
build/analyze, Android formatCheck, Debug/Release и оба Lint проходят.
Ограничения мобильных unit-тестов описаны в [environment-verification.md](environment-verification.md).

## Итоговые состояния

- Кнопка входа сохраняет размер и доступное имя; текст и стрелка скрыты,
  единственный спиннер находится по центру. Блокировка продолжается после
  ответа API до ухода со страницы. Back/bfcache восстанавливает кнопку.
- OAuth-return показывает логотип и индикатор без технических заголовков.
  Сетевая ошибка предлагает повтор чтения сессии; 401 — новый вход с прежним
  приглашением. Вход не записывает RSVP автоматически.
- Начальные загрузки списка, встречи/ленты, приглашения, участников, формы,
  ссылки и опроса используют скелетоны в геометрии соответствующих блоков.
  Приватная оболочка тоже имеет скелетоны до проверки сессии. Загруженные данные
  не исчезают при фоновом запросе. Декоративные блоки не фокусируются;
  контейнер имеет доступное имя и aria-busy. Reduced motion отключает движение.
- Выход очищает приватный кеш сразу после подтверждения API. Mutation остаётся
  pending до завершения перехода на главную, и guard старого маршрута показывает
  скелетон вместо предложения войти. Проверка задерживает загрузку JS главной
  на 400 мс и наблюдает DOM: промежуточный экран входа не появляется.
  При сетевом отказе выхода страница сохраняется, повтор доступен.
