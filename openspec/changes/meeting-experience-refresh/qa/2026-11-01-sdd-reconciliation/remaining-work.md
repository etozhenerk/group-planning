## Текущая квалификация · 01.11, 22:12 МСК

Источник клиентов заморожен на время независимых прогонов. Web: обязательный
check прошёл 217 тестов; основные браузерные сценарии — 282 PASS и один явный
SKIP, отдельная синхронизация — 38/38 PASS в Chromium и WebKit. Прочитанность и
bounded window проверяются далее. Независимые шесть HTTP-сценариев подтвердили
исправление отмены ZIP до ACK, потерянного ACK и неуспешного DELETE; проверены
очистка, повтор и содержимое архива. Эти результаты ещё не принимают весь UI.

Последний полный iOS XCTest выполнил 99 применимых сценариев без ошибок, два
межплатформенных сценария были явно пропущены. Общая команда завершилась
ошибкой из-за QA fixture: read-marker ошибочно считался повторным RSVP.
Маршрут fault ограничен только RSVP, регрессия и исходный UI-путь прошли
независимо. На текущем источнике выполняется один новый полный прогон;
историческая ошибка сохранена, общий PASS ей не приписан.

На Android исправлены подтверждённые ошибки QA-диспетчера и синхронизации
действий теста. В независимом запуске обнаружен конфликт подписи только
тестового host; удалены и переустановлены только QA host и instrumentation
на согласованном эмуляторе. Обычное приложение не затронуто. Текущий полный
прогон начат заново после успешного unit suite; результат пока не завершён.

Серверный обязательный Go suite на текущих 413 inputs прошёл. Независимый
агент проверяет union из 36 серверных кейсов и критерии полных задач.
Неизменность production/SQL зависимостей должна быть доказана отдельно от
нового HTTP-прогона: старые SQL timestamps не переименовываются в новые.
До обновления canonical acceptance refs `qa:check` сообщает об устаревших
implementation inputs прежних серверных подтверждений. Это известный
незавершённый этап сверки, не успешный общий gate.
