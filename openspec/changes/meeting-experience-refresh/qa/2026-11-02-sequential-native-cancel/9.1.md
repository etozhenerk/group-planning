Основной агент, CUA, Google Chrome/macOS. Пользователь разблокировал Mac. Только локальный memory/demo стенд8466, frozen web `/tmp/somewhere-sequential-web-information-rsvp-fixed`. Встроенный браузер не позволял проверить OS окно, поэтому использована отдельная разрешённая QA-вкладка Chrome.

Ничего не опубликовано: в чате остаются те же три исходных сообщения.

Space/Enter в responsive-панели открывают ровно один NSOpenPanel; после Cancel фокус возвращён на picker. При Tab виден keyboard focus, после pointer отмены самопроизвольной рамки нет.
