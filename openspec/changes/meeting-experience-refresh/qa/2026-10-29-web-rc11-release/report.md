# Web rc11: выпуск и проверка

29.10.2026 MSK на smwhere.ru установлен web `0.1.0-rc.11`, build11,
commit `823d93d36f1b4a223a4b43d28d46654fcfa96f28`.
Основание выпуска при незавершённой полной приёмке — прямое поручение владельца
«Релизь, я в проде сам чекну». Это исключение, не успешный qa:release-ready.

## Что изменилось

- Нижние панели mobile web закрываются ручкой/жестом без крестика и лишнего
  обновления данных; ограничения во время отправки и защита черновика сохранены.
- Список прочитавших сохраняет размер при загрузке, ошибке, пустом ответе и
  пагинации. Индикатор отправки появляется после двух секунд в постоянном слоте.
- Фокус после мыши/касания сохраняется без ненужной рамки. Подтверждённые
  реакции не исчезают при смене видимого диапазона и сетевой ошибке; устранён
  цикл запросов и повторных рендеров, вызывавший React185.

конфигурация и база не менялись.
