# Web rc8: фокус кнопок и touch-свайп

28.10.2026 на `https://smwhere.ru` установлен `web/v0.1.0-rc.8`, build8,
commit `3b39b1c8008a918797239cf3be2b344b186bafa5`.
Архив SHA256: `46636493411e4e650b01b2ab726b3bf81c77cd29b0ec7519168de20752cec035`.
Manifest SHA256: `00bb403520d73809d3bc35d78711187e709b2a887cb31d0077ccb4486394a483`.

Safari сохранял клавиатурную обводку кнопок после открытия и закрытия окна
указателем. Теперь режим указателя скрывает только эту обводку, сохраняя
фокус, возврат к вызвавшему элементу и видимое выделение при клавиатуре.
Перелистывание стопки касанием сбрасывалось из-за всплывающего
`lostpointercapture` вложенной кнопки фотографии; потеря захвата дочернего
элемента теперь не отменяет жест контейнера.

## Проверки

- Проверки TypeScript, ESLint, CSS, FSD, Prettier и 175 unit-тестов прошли.
- На точном релизном артефакте автор прошёл 33/33 сценария регрессии
  реакций, медиа, фотостопки, касаний и фокуса. Отдельная проверка identity:
  2 pass, 2 skip; пропуски не считаются успешной приёмкой.
- Независимый агент `web_stack_release_review` прошёл 25/25 браузерных
  сценариев без skip/retry. WebKit и Chromium проверены при ширине390/1440;
  настоящий для браузера touch проверен через Chromium CDP, включая
  всплывающее событие потери захвата от кнопки фотографии.
- Установщик прошёл 11 проверок, включая автоматический откат. На сервере
  сверены контрольные суммы перед переключением; после него проверены
  health/readiness, версия, entry assets и PNG для превью. Отдельная внешняя
  проверка с Mac получила200 для health/readiness, главной и build-info.
- В GitHub CI этого коммита Build и Checkers прошли. На момент записи Tests
  ещё выполняется; окончательный результат не подменяется локальным прогоном.

## Выпуск и ограничения

Использовано прямое поручение владельца: «Релизь, я в проде сам чекну».
Это выпуск для проверки с оговорённой неполной ручной и дизайн-приёмкой,
а не полный `qa:release-ready` или `design:ready` pass.

Переключена только ссылка web/current с rc7 на rc8. Backend rc5, процессы API
и Caddy, конфигурация и БД не изменились; откат не понадобился. Предыдущая
сборка rc7 сохранена. Анонимные API/WebSocket запросы получили401;
авторизованный production-сеанс для smoke не использовался.

Живые жесты в Safari на iPhone, системная отмена выбора файлов и полный
визуальный проход остаются непроверенными: Mac заблокирован. Автоматический
cancel-сигнал не выдаётся за действия в системном picker. Доступ к Telegram
пользователь запретил; появление картинки в Telegram этим выпуском не
подтверждается. Новая функциональность выгрузки всего альбома не входит в rc8.

Полные локальные результаты и audit хранятся в
`infra/local/releases/candidates-3b39b1c8/` и
`qa/2026-10-28-web-input-hotfix-independent/`. Задача15.1 остаётся открытой
до требуемой полной приёмки.
