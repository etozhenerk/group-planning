# Проверка 4.4 — часовая отсечка web

2 ноября 2026. Локальный Go API, memory.Store, синтетические Саша/Лена; production не затронут.

- Chromium и mobile WebKit: переход через границу по таймеру; refresh после focus/visibilitychange и изменения часов; детали сохранены, запрещён только новый «Приду».
- Устаревшая страница: реальный сервер возвращает 409 `join_closed`, приглашение обновляется, «Приду» блокируется, приватный чат не открывается; организатор сохраняет чат.
- Дата без времени: «Приду» доступно. После вступления перенос начала внутрь часа не отбирает чат. После отказа повторное вступление закрыто и прямой HTTP-запрос отклонён.

6 адресных сценариев PASS: 2 в results-corrected.json (stale), остальные 4 в results-final.json. Повторы успешных сценариев не запускались. Граница до/ровно/после и атомарность дополнительно покрыты существующим backend/internal/meetings/join_cutoff_test.go.

Первые ошибки были в новом тестовом коде: UTC-строка с Europe/Moscow, nested revision, искусственное истечение часовой сессии при переносе часов на два часа и ожидание автоматического открытия чата вместо явного «Открыть встречу». Исправлены тестовые данные и ожидания, приложение для 4.4 не менялось; исходные результаты сохранены.

Clock/visibility — управляемый browser integration, не физическое сворачивание iPhone. Общая дизайн-приёмка и устаревшие hash других задач этим результатом не закрываются.
