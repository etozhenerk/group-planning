# VoiceOver: активация остаётся открытой

04.11.2026. XCUIVoiceOverService действительно прочитал и сфокусировал
«Создать встречу». Синтетический XCUICoordinate.doubleTap в центре окна
не открыл форму; это не PASS и пока не доказанный продуктовый дефект.
Служба восстановления выключила VoiceOver до исходного false.

Публичный XCUIVoiceOverService имеет чтение и forward/backward/in/out,
но не отдельную активацию и не Rotor. Ограничение API сверено с SDK27.1 header
и https://developer.apple.com/documentation/xcuiautomation/xcuivoiceoverservice.
Причина несрабатывания двойного нажатия требует отдельного подтверждения;
обычный tap по конкретному контролу не выдаётся за VoiceOver-активацию.

Probe и исходный провал сохранены здесь. Он не включён в обычный UITest target
и не добавляет известное падение в регулярный suite. Продукт не менялся.
Полный VoiceOver/Rotor остаётся незакрытым. Доступные остальные проверки
продолжаются, старый PASS чтения/фокуса не обнуляется и не повторяется.
