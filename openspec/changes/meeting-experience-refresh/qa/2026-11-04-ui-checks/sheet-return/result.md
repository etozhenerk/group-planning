# Возврат из панели без IME · 04.11.2026

Закрыт конкретный визуальный пробел sheet-return-no-ime старого отчёта
design-review-5.0.0.json. Один адресный XCUITest (46.926с, PASS): настоящая
клавиатура, ввод в task-sheet, свайп вниз, возврат в чат; затем info-sheet,
свайп вниз и возврат. В обоих случаях IME отсутствует, draft «Вернусь\nк сообщению»
сохранён, composer доступен. Реальные PNG и capture JSON просмотрены агентом;
выполнен только нужный метод, остальные chat UI-тесты не запускались.

iPhone18Pro simulator 31262733-50DC-46A5-938E-4C462D70F109, iOS27.0/Xcode27.1,
402×874pt, ru_RU, системный L, обычные анимации. Оригинальная настройка
QA_KEYBOARD_AUTOMATIC_MINIMIZATION_RESTORED=1 восстановлена runner.
Production UI этим пунктом не менялся; в существующем тесте добавлены снимки
после двух уже проверявшихся возвратов и scoped-команда chat-keyboard-return.

Исторический blocked с его исходным hash не переписан. Этот actual подтверждает
указанные два состояния новой сборки; общий0.3/design:ready не объявлен пройденным.
Попытка продолжить web UI через существующую вкладку8466 закончилась ошибкой
инструмента browser.user is unavailable до получения страницы. Новые браузерные
действия, физический touch long-press и полный VoiceOver/Rotor не заявлены.
