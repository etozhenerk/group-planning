# UI: крупное содержимое нижних вкладок iOS

04.11.2026, основной агент, только iPhone18Pro test simulator/iOS27.0.
Нижняя навигация сохраняет исходные размеры48/62pt и прежние цвета/иконки.
Добавлен системный accessibilityShowsLargeContentViewer для каждого раздела:
при реальном удержании доступна крупная иконка/название; обычное нажатие
переключает раздел как прежде. Изменения шрифта и роста самой панели отклонены
и полностью отменены: они не соответствовали принятой компактной композиции.

Это нативный адаптер доступности, а не новая палитра/макет. Основание:
[Apple, SwiftUI large content viewer](https://developer.apple.com/documentation/swiftui/view/accessibilityshowslargecontentviewer(_:))
и [WWDC24: Get started with Dynamic Type](https://developer.apple.com/videos/play/wwdc2024/10074/).
Apple специально рекомендует этот механизм для компактной постоянной навигации.

Адресный XCUITest PASS24.388с: прежние48pt на обычном и AX XXXL тексте,
доступность/выбор всех трёх вкладок, прокрутка к нижнему действию над панелью.
Системная настройка симулятора реально включена на время scope и восстановлена
в large; настройка экранной клавиатуры также восстановлена. Оптический проход
по final/hold.mp4 и точному кадру3.5s final/held-profile.png подтверждает
большую системную панель «Профиль» с иконкой во время5s удержания.

Ранние проверки высоты/записи являются диагностикой, не успешной приёмкой HUD.
Первое предположение о необходимости роста tab bar оказалось неверным: оно
отменено после сверки нативных рекомендаций Apple. Видеокадр извлечён с
нулевым time tolerance, а не ближайшим keyframe. Собственный фон навигации,
тексты, typography tokens и существующие макеты не перепубликовывались.
Полный accessibility/VoiceOver/Rotor и общий design gate этим не закрываются.
