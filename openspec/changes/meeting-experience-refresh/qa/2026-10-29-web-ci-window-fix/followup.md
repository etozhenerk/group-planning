# Повторная проверка CI 39

Linux run 40855558482 на 15b6dbd3 показал два других сбоя после исправления краткого выравнивания anchor: один повтор остановился у границы 172 без запроса следующей страницы; второй сравнивал first-visible ID при уменьшении высоты самой строки. Третий повтор прошёл.

## Дозагрузка

Последний scroll-event ставит scrollTop=1, но HTTP-запрос before_sequence=172 отсутствует. В scroll handler ветка restoring/correcting раньше завершалась без повторной проверки границы. Она теперь планирует prefetch на следующий кадр, сохраняя запрет перезаписи anchor в момент коррекции. Проверки concurrent requests и локальной ошибки остаются в прежних местах. Остальные scroll/anchor механизмы не менялись. Это устраняет пропущенный сигнал у границы; окончательное подтверждение — следующий Linux прогон.

## Измерение resize

Независимый анализ сохранённого Linux DOM подтвердил нулевое смещение исходного anchor: −113 px до и после. Его высота уменьшилась 127→106, так что первая видимая строка закономерно стала следующей. См. resize-oracle-independent.md и resize-geometry.json. Тест теперь после resize измеряет прежний ID, а не выбирает новый. Допуск 2 px, присутствие непротектированной строки, assertions последующих действий и таймауты сохранены.
