# Нативный аватар при ACK · 04.11.2026

`TC-CHAT-NATIVE-AVATAR-ACK` пройден основным агентом на обеих платформах:
iPhone18Pro simulator 31262733-50DC-46A5-938E-4C462D70F109, iOS27.0/Xcode27.1;
emulator-5554/API36. Только изолированный QA API и синтетические пользователи.
По поручению пользователя проверка самостоятельная, отдельного ревьюера нет.

## Исправления

Android заменял собственный профиль урезанным actor из серверного сообщения:
первый кадр ACK действительно показывал букву вместо фотографии. Теперь
собственная строка использует текущий профиль, чужая — своего серверного автора.
Исходные снимки: android-http-initial/avatar-ack/http-ready.png и http-0.png.

На обеих платформах потерянный успешный ответ сначала создавал блок ошибки,
смещая аватар/строку, а затем сверка убирала его. Теперь перед uncertain
выполняется HTTP-сверка: строго совпавшее по автору, встрече, ключу и содержимому
сообщение принимается без повторного POST. При отсутствии подтверждения
сохраняются uncertain и прежние повторы. Android проверяет последнюю страницу;
если запись уже вышла из неё, действует прежний механизм синхронизации/повтора.
Ошибки валидации не превращаются в успех; чужие записи не подтверждают отправку.

## Проверено

Три адресных UI scope каждого клиента: avatar-ack-http, avatar-ack,
avatar-fallback. Всего десять путей: HTTP, потерянный HTTP-ответ, realtime до
HTTP-ответа, потерянный ответ при realtime, профиль без портрета. Реальные
транспорт/API/SDK; только удержание/потеря ответа внедрены в QA targets.
Для realtime подтверждено: SDK получил изменение и каноническая строка уже
видна, пока успешный HTTP201 удерживается. После сверки на сервере одна запись.

240 выборочных изображений аватара: ни одной подмены портрета/заглушки,
координаты до/во время/после ACK в допуске1pt/px. Прокрутка реально меняет
положение строки, оставляя портрет или исходную букву видимыми. Это выборка
промежуточных кадров, не запись каждого display frame и не доказательство FPS.
Полные снимки before/accepted/scrolled просмотрены; исходные рисунок/размеры
сохранены. Эталон портрета — публичный стандартный Yandex avatar
https://avatars.yandex.net/get-yapic/0/0-0/islands-200, копия рядом с отчётом.
Новых дизайн-решений и изменений токенов нет.

Unit: iOS217/0fail, Android199/0fail/0skip. Добавлены регрессии урезанного
actor, сверки потерянного ответа без второго POST и сохранения чужого автора.
iOS swift-format и clean Release build/analyze PASS. Android check.sh:
format, clean Debug/Release, оба Lint, unit, Debug/QA instrumentation APK PASS.
Backend fixture unit/format, agent:check и git diff --check PASS.
Команды и полный вывод — logs/*.txt; кадры — в папках платформ/режимов.

## Границы закрытия

Функциональный сценарий аватара принят на этих двух симуляторах. Реальное
устройство, production OAuth, FPS и прочие состояния чата этим не проверены.
Автоматизация partial/unknown: opt-in scopes ещё не являются регулярным suite.

Общая10.3 остаётся открытой: design:ready отвергает соседнее новое изменение
mobile-mvp-design-refresh без manifest; qa:ready/qa:check сообщают
Stale catalog or unresolved coverage. Эти команды выполнены, PASS не подделан,
чужие config/новый редизайн не изменены. Предыдущие прогоны других восьми кейсов
не переименованы в приёмку всего нового кандидата. Релизов, CI-правок и Telegram нет.
