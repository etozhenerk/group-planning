# Web: инженерная проверка переноса чата

Это результаты исполнителя, не независимая функциональная или дизайн-приёмка.
Задачи остаются открытыми. Источник композиции — принятая Telegram-ревизия,
опубликованная в дизайн-системе 1.4.1. Прогоны run01–04 сохраняют историю прежней ревизии.

## Проверенные исправления

- Emoji-док сохраняет выделение, повторные вставки и составные Unicode-символы;
  кнопка клавиатуры возвращает текстовый фокус и курсор. Черновик остаётся в
  прежнем приватном query cache, но controlled input читает синхронные изменения:
  отложенные уведомления больше не сбивают ввод.
- Settings/Share возвращаются в ту же панель сведений, сохраняют черновик и
  фокус реальной кнопки открытия, включая WebKit. Browser Back проверен отдельно.
- Quick/full реакции остаются возле сообщения и внутри доступной области;
  composer виден на 320×760, 390×430 и 844×390 при touch-вводе.
- Открытие emoji-дока сохраняет позицию чтения. Кнопка новых сообщений
  расположена над composer при изменении его высоты и переводит к последней записи.

В каждой папке сохранены исходный лог и SHA256 входов. Failure PNG/context
сохранены рядом с соответствующими ошибками. Полные Playwright trace находятся
в игнорируемой `.cache/qa/2026-10-27-telegram-chat/web-implementation/`.

Полный `web:check` после исправлений: TypeScript, ESLint, CSS spacing, FSD,
Prettier и 97 тестов в 26 файлах прошли повторно в итоговом run07. Production
web:build также прошёл. Полный браузерный набор — 158 pass / 1 skip / 0 fail;
пропущен прежний test08 без отдельно настроенного native bridge. Это не доказывает
сквозную совместимость всех трёх клиентов.

## Независимый ручной проход

Проверка доступности отдельного fixture на `https://127.0.0.1:8445/` во внутреннем
браузере остановлена ошибкой `ERR_CERT_AUTHORITY_INVALID`; см.
[исходное наблюдение](manual-access-check.json). Сертификат не обходился,
пользовательские действия в приложении не выполнялись. Инженерный Playwright
с локальной TLS-конфигурацией не заменяет независимую ручную приёмку.

Остаются независимые feature-test/design-review
с актуальными входами и итоговые `qa:ready`/`design:ready`.
