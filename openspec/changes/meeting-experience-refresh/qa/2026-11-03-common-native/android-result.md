# Общие поверхности Android · 11.3

03.11.2026. Проверка основным агентом, без отдельных агентов по прямому решению
пользователя. Общий независимый design/qa gate 0.3 не заявлен пройденным.

## Результат

CommonNavigationUiTests.movingTabsReducedMotionProfileBackAndCoverFirst —
PASS 9.914 с, emulator-5554 / Android16. Форматирование и сборка QA/test APK
прошли. Production-код Android не менялся: повторный общий чистый набор
Debug/Release/Lint/197 unit из проверки readers сегодня не запускался.

- На настоящем HomeNavigation сняты начальное, промежуточное и конечное
  положения подсветки; промежуточное находится между двумя конечными.
  Проверены движение в профиль и возврат во встречи.
- Системный animator_duration_scale временно установлен в 0. После выбора
  профиля индикатор уже в конечном положении через 64 мс тестовых часов,
  вместо постепенного обычного перемещения. Исходная настройка восстановлена
  в finally и проверена равенством.
- About и Help закрываются системным Back в выбранный профиль; выхода во
  встречи нет. Снимки просмотрены. Название somewhere присутствует один раз
  в общей шапке, в About нет повторного заголовка с именем продукта.
- Выход — после всех сервисных ссылок. Удаления аккаунта и версии в профиле нет.
- В начале создания видна заметная кнопка «Добавить фото», её нижняя граница
  выше поля «Название»; навигационной панели на форме нет. Проверены geometry
  и screenshot, без открытия системного picker в этом сценарии.
- Календарный кэш проверен ранее сегодня той же production-реализацией:
  completeMonthSuppliesDayWithoutLoadingFlashOrAnotherDaysMeetings,
  incompleteMonthDoesNotClaimAnUnloadedDayIsEmpty,
  revokedMeetingIsRemovedFromAllCachedDays. Сохранён исходный JUnit XML.
  Кэш полного месяца немедленно даёт нужный день без сброса в loading;
  неполные данные и отозванные встречи не подменяются успешным кэшем.

## Уточнения новой проверки

Первые запуски выявили ошибки самого нового теста: тип публичного JUnit-правила,
вспомогательный screenshot, продвигающий часы, отсутствие каталога для PNG,
а также строгое сравнение оттенка без стандартного ripple после нажатия.
Они исправлены в QA-коде. Продукт не менялся ради зелёного теста. Проверка
геометрии учитывает светлый ripple поверх опубликованного выбранного цвета;
области текста и фона исключены. Начальные/средние/конечные изображения сохранены.
Асинхронный callback переключения экрана не интерпретируется как синхронный
кадр разворота: этот дополнительный, не заявленный здесь бюджет не подтверждён.

[исходные календарные unit](android/calendar-existing-source.xml), PNG/контекст
лежат рядом. Реальные устройства/Яндекс ID, FPS/memory бюджеты, release и
общие формальные gates эта адресная проверка не заменяет.
