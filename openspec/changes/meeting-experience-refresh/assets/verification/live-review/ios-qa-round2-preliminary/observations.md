# Предварительный просмотр iOS QA round2

Лично просмотрены все 5 PNG из sheet-media-02 и keyboard place/task из
sheet-gestures-06. Это прогоны исполнителя, не независимый rerun после freeze.
В metadata есть фактическая screen capture, 402×874pt, 1206×2622px, iOS27.0,
ru_RU приложения, Europe/Moscow, SFUI-Regular/Bold, textScale categoryL.
Source hash этих двух scoped runs пока не сопоставлен; pass не выставляется.

Фото соответствует boardgame fixture. Визуально фото и документ сохраняются
после reopen, подпись «Правила встречи, черновик» совпадает. X, удаление,
видимость участникам и Send CTA присутствуют, горизонтального переполнения
не видно. Media-01 с неопределённым изображением в эту evidence не включён.

Keyboard кадры показывают реальные QWERTY keys. Focused поля не закрыты
клавиатурой, заголовок и X видны. В place-keyboard плавающая системная кнопка
«Готово» частично перекрывает нижний правый край CTA; текст и центр CTA доступны.
В task-keyboard такого пересечения нет. Это не объявлено дефектом до проверки,
можно ли прокрутить CTA целиком выше toolbar. Нахождение CTA ниже/на краю
viewport само по себе не является ошибкой при доступной прокрутке.

Жест swipe, удаление, отмена picker и сохранение composer проверяются scoped
XCTest; выводы об их выполнении требуют собственного актуального rerun, а
сохранённые screenshots здесь служат раннему обнаружению визуальных проблем.

Дополнительно просмотрены sheet-date-picker и sheet-date-after-picker: системный календарь ввода имеет видимые Close/Готово, после закрытия видна форма с двумя датами и доступным подтверждением. Этот input surface не подменяется ожиданием QWERTY для даты.

Из navigation-02 дополнительно просмотрены long-title-no-cover, list-large-text и list-no-cover-large-text. Обычный длинный заголовок виден целиком в3 строки, корона и аватар присутствуют. На AccessibilityXXXL переключатель Список/Календарь переносит слова, без потери букв. No-cover large кадр не показывает низ карточки целиком за нижней навигацией; это ограничение позиции capture, а не доказанный дефект. Для приёмки целевой карточки нужна дополнительная прокрутка и просмотр.
