## Проверенные переходы

- Shared design fixture → список → карточка «Настолки у Саши» → плюс → формы задачи, места, даты. Тест вводит «Заказать пиццу», закрывает клавиатурную панель кнопкой «Готово», затем закрывает каждую форму крестиком и возвращается в чат. Живые UI-действия выполнены XCTest после свежей компиляции.
- Отдельный запуск с Accessibility XXXL → каждая из трёх форм → проверка доступности крестика → закрытие. Прокрутки до CTA в этом тесте нет.
- Чат → компактное меню → повторное нажатие плюса → эмодзи. Меню визуально содержит пять строк, состав и расположение соответствует raw chat-menu.html.
- Список → календарь → список → профиль → создание. Скриншот списка показывает две карточки с обложками, weekday/weekend и шестью участниками; no-cover виден лишь частично и этой картинкой не принимается.
- Чат → сведения встречи → редактирование → ввод черновика → закрытие → повторное открытие и сохранённый черновик → сведения → чат → профиль. Тест проверил отсутствие сервисных действий в панели встречи и их доступность в профиле.

Лично просмотрены `design-list`, `design-chat`, `design-menu`, `design-action-task`, `design-action-place`, `design-action-date`, все три `*-large-text`, `design-meeting-info`, `design-settings-keyboard`. Reference: исходные HTML list/chat-menu/action-task/action-place/action-date/share/upload-file, сохранённые через IAB; применены последние коррекции ux.md о bottom sheet, нижней навигации и футере.

Normal action forms: тёмная нижняя панель поверх сохранённого чата, заголовок/крестик, поля и CTA читаемы; нет отдельного Back, основной нижней навигации или футера. Платформенный SF и системные date controls допустимы по docs/design/platforms.md. Опрос даты содержит два варианта — это сохранённое бизнес-ограничение, уточнённое в UX.

## Ограничения

Этот прогон не является полной приёмкой manifest. Название `settings-keyboard` не доказывает видимую программную клавиатуру: на снимке она отсутствует, видна только кнопка «Готово». Нужна отдельная keyboard-проверка. Для large-text ещё требуется прокрутка до основной CTA и проверка геометрии header/close во viewport. Ошибка/повтор, потеря доступа, reduced motion, длинное название, полный no-cover, member и загрузки не покрыты этим набором live captures.

Source hash изменится после правок тестов: эти результаты останутся evidence первого прогона, а не pass новой ревизии. Pixel regression не выполнялась.
