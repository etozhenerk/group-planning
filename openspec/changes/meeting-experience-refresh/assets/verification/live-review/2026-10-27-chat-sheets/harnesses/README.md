# Review harness новой ревизии

Копии старых рецептов с новыми reference URLs и CDP font scope, направленным
сначала на активный data-view/dialog, затем main. Исторические рецепты не менялись.
Ни один из этих файлов ещё не выполнялся в браузере. Source freeze и runtime
handoff обязательны; синтаксическая проверка не является live run.

Перед запуском требуется актуализировать info/settings navigation после
готовящегося отдельного раскрытого состояния. Рецепт remaining пока сохраняет
старый путь к существующему действию настроек; не считать его возможный selector
failure продуктовым дефектом без чтения опубликованного нового пути.

Непокрытые source states перечислены в referencePolicy. Снимок упрощённой даты,
создания встречи или emoji picker не разрешает pass полной multi-date формы,
настроек или списка поставивших реакцию. Новые actual/reference и взаимодействия
сами по себе ещё требуют личного визуального просмотра и записи verdict.

Рекомендуемый REVIEW_OUTPUT: 2026-10-27-chat-sheets/web-<scope>-<short-hash>.
Browser zoom использует только собственный временный профиль и extension из
этого каталога. Настройки пользовательских браузеров не меняются.
