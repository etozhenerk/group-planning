# Промежуточная проверка web: состав встречи

Дата: 2026-10-27. База: `7fa0a5f`. Дизайн-система: 1.2.0.
Это проверка исполнителя, **не независимая функциональная или дизайн-приёмка**.
Исходники других клиентов менялись параллельно. Состояние для общей приёмки
будет заморожено координатором отдельно; checkbox этой записью не закрывается.

## Реализация

- В информации о встрече по умолчанию показаны три имени из текущих «Приду»
  и организатора, затем точное число остальных. Раскрытие и сворачивание полного
  состава остаются внутри информации; фокус переносится на «Скрыть состав» и обратно.
- Полный состав показывает все ответы, включая «Возможно» и «Не смогу».
  Имена используют body 15, подписи caption 12, аватары 30 и опубликованные роли.
- Настройки/приглашение организатора и RSVP участника расположены вне раскрываемого
  блока. Вариант RSVP внутри информации не дублирует «Открыть встречу».
  Desktop sidebar и карточка приглашения сохраняют отдельную композицию.
- После Info → Share → Info → закрытие задан явный ref возврата фокуса к кнопке
  информации. Этот последний фикс скомпилирован, но повторный E2E ещё не выполнен.
- Внутренний скролл мобильной формы получил нижний буфер `space.s1`, чтобы
  округление scrollHeight не обрезало CTA на 0.125–0.25 CSS px.

Тестовая OAuth-фикстура расширена только в `browser_fixture_test.go`: Саша,
Лена, Миша, Аня, Дима, Катя, Олег и Ира. `meetingRoster` создаёт настоящую встречу
через HTTP и получает семь ответов через отдельные браузерные контексты и UI.
Получается шесть текущих «Приду»/организатор, один «Возможно», один «Не смогу».
Production auth, API и права не менялись.

В новом E2E desktop Share теперь проверяется как `main` с «Назад» и нулём
модальных окон, mobile — как dialog с «Закрыть» и одним modal. Это соответствует
существующему платформенному контракту. Требование focus и ratio=1 не ослаблялось.
В run01 файл03 был ошибочно назван в CLI и не выбран; настоящий `03-layout`
проверен в run02. Для нового полного roster-сценария нельзя заявлять проход всех
ролей/ширин: run02 остановился на focus до завершения матрицы.

После run02 внесён явный returnFocus. Последний `check-run06`, production/demo
run03 успешны. По указанию координатора новый targeted и полный E2E отложены
до общего feature-плана и сборок native; необходимо повторить 33/16 и полный
`web-e2e` через `qa:run-suite`, затем независимые feature-test и design-review.
