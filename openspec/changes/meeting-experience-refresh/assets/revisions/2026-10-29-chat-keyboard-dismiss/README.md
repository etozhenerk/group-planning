# Скрытие клавиатуры вне сообщения · 5.0.0

Используется принятая композиция чата из 2026-10-27-telegram-chat;
цвета, размеры, тексты и иконки не меняются. Ревизия задаёт только новое
поведение фокуса, остальные актуальные коррекции contracts сохраняются.

Открой index.html, поставь курсор в черновик и нажми свободную область
истории: фокус уходит, текст сохраняется. Первый клик по Send/+ /emoji
выполняет действие. Клик внутри textarea сохраняет редактирование;
Tab и ввод в другом поле не перехватываются. Настоящую экранную клавиатуру
проверяют на iOS/Android и доступном мобильном браузере: desktop viewport
не является доказательством закрытия OS-клавиатуры. Прокрутка и long press
не превращаются в tap; существующее интерактивное скрытие при scroll сохраняется.
