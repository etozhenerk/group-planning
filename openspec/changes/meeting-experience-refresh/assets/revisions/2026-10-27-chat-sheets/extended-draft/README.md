### Заголовок и текст опроса

В UX от 23.10 заголовок — «Новая дата встречи», а более новый согласованный
refresh/action-date.html и опубликованная ревизия используют «Предложить дату».
Сохранён **более новый** заголовок и CTA «Создать опрос». Старое уточнение
по удалению, настройкам, дедлайну, ошибкам и доступности кнопки не отменено
упрощённым HTML. Вводный hint старой формы убран по правилу не повторять
условия перед настройками; пять переключателей остаются открытыми.

Имя встречи/даты демонстрации приведены к контексту опубликованного чата:
«Настолки у Саши», 31 октября; варианты 31 октября, 1 и 2 ноября, срок 30 октября.
Это фиксированные данные макета, не проверки реального текущего времени.

### Какие композиции были предложены и отклонены

1. **Настройки:** одна форма в панели: название → дата/время → место → описание
   → обложка → Отмена/Сохранить. Обложка использует известный preview, а не
   новую крупную hero-картинку. Новые поля пояса, роли, приватности или удаления
   встречи не предлагаются. Подтверждается именно порядок/композиция,
   право организатора уже задано требованиями.
2. **Задача:** общий заголовок «Задача», название из карточки ниже, затем автор,
   адресат и статус; доступные действия идут вертикально. Адресат видит
   принять/отказаться, исполнитель — выполнить/отказаться, автор/организатор —
   отменить. В терминальных состояниях действий нет. Передачи без согласия,
   редактирования текста и новых правил не добавляется. Выбор — отдельная
   композиция подробностей, права согласованы ранее.
3. **Реакции:** заголовок «Реакция 👍» идентифицирует выбранный счётчик,
   под ним обычные строки аватар/имя. В этой панели нет повторного picker,
   контактов, CTA и переходов в чужой профиль. Выбор — расположение emoji
   и списка; возможность видеть имена уже есть в spec.

Полноценная принятая форма настроек не найдена: проверены исходные HTML
gathering-activity-feed/assets, затем raw HTML других changes по строкам
«Настройки встречи», «Изменить встречу», «Редактировать встречу», «Сохранить
изменения». Каталоги verification и снимки реализации исключены. Найденные
flow-create/create — создание, их нельзя переименовать в утверждённое редактирование.

## Переходы для будущего рендера

- Полная дата: открыть, заполнить черновик, удалить третий вариант → кнопки
  удаления исчезают; добавить вариант → появляются. Очистить либо повторить
  дату, нажать «Создать опрос» → ошибка у поля, фокус первой ошибки. Удлинить
  список → тело прокручивается, CTA и header/X остаются доступными.
- Прямые состояния: [нет даты](date-full.html?sample=missing),
  [повтор даты](date-full.html?sample=duplicate),
  [ошибка отправки](date-full.html?sample=network).
- Закрыть через X/фон/Escape/Back, открыть дату снова из плюса → DOM формы
  и черновик остаются в этой странице. Перезагрузка страницу сбрасывает.
- Ошибка файла: ввести подпись, закрыть и открыть через плюс → ввод сохранён.
  «Повторить» только возвращает демонстрацию в чат, сети/загрузки нет.
- Задача: offered → accepted → completed либо declined; organizer → cancelled.
  Это локальный показ ролей/состояний, не сохранение и не проверка серверных прав.
- Настройки: правка полей; убрать/вернуть тот же демонстрационный cover;
  Отмена/Сохранить закрывают форму. Системный picker и сохранение не имитируются.

## Границы черновиков

Выполнены проходы при 320×844, 390×844, 768×1024, 1440×1000 и реальных
viewport 320/390×430; точная матрица и действия находятся в inspection.md.
Увеличение системного текста, resize открытой панели, реальная клавиатура
и экранный диктор этим проходом не проверены. Использован reduced motion.
Индикатор `draft-unpublished` в provenance сохраняет последнюю стадию генерации
до отклонения. Текущее решение REJECTED записано в README/index; прежние hashes
не пересчитаны задним числом. Ни стадия генерации, ни проверка статичного макета
не дают product pass.

Для ввода дат использован HTML input date: это средство демонстрации тела,
**не новый эталон календаря сервиса**. Отдельный popover календаря, DST,
серверная валидация и права, системная клавиатура и полный жизненный цикл
загрузки здесь не проверены. Иконка корзины построена по принятому требованию
в существующем контурном стиле; в старом raw есть CSS `.remove-date`, но нет
готового SVG. Её нужно просмотреть вместе с рендером, а не выдавать за raw-копию.

Показаны ошибки отсутствующей/повторной даты и отдельная ошибка отправки,
но остальные поля/ограничения проверяет реальный API. Тексты ошибок не
выдумывают сетевую причину и не обещают сохранение на сервере. Ошибка файла
не закрывает кейсы всех типов/размеров и частичной загрузки.

`generate.ts` воспроизводит HTML, scoped `date-source.css`, JS и provenance.
`extended.ts` хранит только поведение макета. Для воспроизведения из корня:

```sh
node --import tsx openspec/changes/meeting-experience-refresh/assets/revisions/2026-10-27-chat-sheets/extended-draft/generate.ts
```

Публикация этих вариантов отменена. Прежние отчёты и input/capture hashes
не изменяются и не переносятся в следующий дизайн. Приложение, DS и authority
в этой подзадаче не изменялись.
