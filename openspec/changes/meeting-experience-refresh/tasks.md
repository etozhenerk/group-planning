# Tasks

Дизайн-пакет полностью согласован пользователем 25.10.2026. Реализация
выполняется для backend, web, iOS и Android. Отметки отражают реализованное
поведение и выполненные проверки соответствующей группы. Визуальная приёмка
каждого клиента обязательна отдельно; компиляции недостаточно.
Требования — `specs/*/spec.md`, эталон экранов — [ux.md](ux.md).
