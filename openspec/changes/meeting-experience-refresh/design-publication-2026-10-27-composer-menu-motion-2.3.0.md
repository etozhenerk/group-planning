# Меню composer по плюсу · 2.3.0

Пользователь прямо поручил анимировать открытие popup по плюсу в строке сообщения.
Принятая область — web/iOS/Android, прежние привязка, размеры, состав и переходы.
Вход: opacity + сдвиг вверх из 8 (`space.s8`), 180 ms (`mobileSheet`). Выход:
обратно за 150 ms (`fast`), standard easing. Никаких новых чисел или scale.
Повторное открытие продолжает текущий кадр; выход удерживает поверхность,
но сразу исключает ввод/AX. Reduce Motion — без задержки. Выбор действия
открывает форму немедленно, не ждёт завершения декоративного выхода.

Реальный raw обновлён и собран; предыдущая версия в `history/2.2.0`.
Контракт chat-actions, UX, spec, cases и manifest обновлены до клиентского кода.
Исторические проверки сохранены. Публикация не закрывает задачи реализации
и независимой приёмки; новые записи normal/reduced обязательны.
