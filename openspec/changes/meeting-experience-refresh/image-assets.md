# Иллюстрации прототипа

Изображения демонстрационные, не фотографии пользователей и не production-данные.
Все пути относительно этого изменения.

| Файл | Источник и назначение |
| --- | --- |
| `assets/friends.png` | Ранее подготовленная иллюстрация `friends-cover.png` базовых макетов; компания за столом |
| `assets/boardgame.png` | Сгенерировано встроенным imagegen для обложки и вайба; настольная игра и руки участников |
| `assets/dinner.png` | Сгенерировано встроенным imagegen для обложки и вайба; пицца и детали вечера |
| `assets/brand.svg` | Знак из `frontend/web/public/somewhere.svg` |

Содержание промптов генерации: тёплая документальная фотография домашнего вечера
взрослых друзей, настольная игра и пицца, естественный свет, без надписей,
водяных знаков и логотипов. Для `boardgame.png` — горизонтальная композиция
стола и рук без лиц. Для `dinner.png` — вертикальный крупный план пиццы на
керамической тарелке, лимонада, руки и края игры. Это описание постановки,
не доказательство реальной встречи. Обработки после генерации не выполнялись;
кадрирование превью задаётся CSS, оригинал в полном экране сохраняет пропорции.
