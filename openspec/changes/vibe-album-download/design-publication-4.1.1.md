# Публикация 4.1.1 · 29.10.2026

По повторному указанию пользователя web-эталон исправляет ошибочное разрешение
переноса отдельных кнопок. [Новая ревизия](assets/revisions/2026-10-29-album-actions-row/index.html)
держит обе кнопки рядом; при недостатке ширины переносится вся группа под
заголовок. Mobile — прежние две равные колонки. Новых токенов и native-изменений нет.

[Авторская проверка публикации](qa/2026-10-29-web-actions-row-publication/report.md)
содержит геометрию, снимки и hash. Предыдущая ревизия и старые результаты
сохранены. Design manifests остаются checkpoint с новыми report-путями;
реализация и независимая приёмка не считаются завершёнными.
