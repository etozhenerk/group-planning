# Независимая проверка строки действий web 4.1.1

**Наблюдённый узкий результат: соответствует требованию одной строки.** На
desktop1024 длинный заголовок переносит обе кнопки целиком под себя; кнопки
остаются рядом, без видимого пересечения или выхода из контейнера. На mobile320
видны две равные колонки одинаковой высоты; «Добавить фото» переносится внутри
кнопки. В preparing spinner/«Отменить» занимает ту же вторую колонку, первая
кнопка и положение фотографии визуально сохраняются.

Проверял `/root/release_history_review` независимо от исполнителя `/root`,
29.10.2026 через native Chrome156.0.8078.73 на macOS27.0.1. Viewport по DevTools:
1024×844 и320×844, Fit to window. Размеры подтверждены UI DevTools; точные DOM
координаты и загруженные шрифты отдельно не инструментировались. Это визуальная
оценка геометрии, не pixel regression.

## Фактические действия

- Открыт отдельный frozen fixture8466 без нового browser TLS interstitial,
  выполнен тестовый вход Саша. Создан собственный альбом из3 PNG с длинным
  названием; данные и SHA перечислены в `fixture.json`.
- На1024 нажата видимая primary. Открылась компактная форма «Добавить фото в
  альбом». Escape закрыл её, вернул фокус к primary и тот же альбом1/3.
- На320 нажата secondary при DevTools3G. Наблюдались pending POST и spinner с
  «Отменить»; две кнопки сохранили один ряд и высоту, фото осталось на месте.
- Отмена **не подтверждена**: к следующему CUA вызову первая подготовка уже
  завершилась и передала ZIP браузеру; клик по тому же месту начал второй
  экспорт. В raw Network видно два POST, поэтому screenshot
  `mobile-320-cancel-attempt.png` не считается cancelled. Это ограничение
  временного окна ручного прохода, а не доказанный дефект отмены.
- В браузере появились два собственных ZIP. При точечной очистке оба содержали
  только три фото текущего fixture с совпавшими SHA256/CRC. Один сохранён как
  `observed-native-3-photos.zip`; из Downloads удалены только эти совпавшие файлы.
  Это не повторный прогон полного ZIP103 и не проверка всех access-сценариев.

Native AX-клик внутри уменьшенного responsive viewport один раз попал в фото
вместо кнопки; после закрытия просмотра применён CUA-клик по координатам
видимой кнопки. Неправильный AX-hit не приписан продукту. Первое введение URL
через typeText потеряло буквы; переход исправлен paste точного URL. Эти ошибки
инструмента не являются функциональными результатами приложения.
