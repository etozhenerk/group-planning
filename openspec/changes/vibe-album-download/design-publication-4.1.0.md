# Публикация 4.1.0 · 29.10.2026

Пользователь отклонил первый макет и уточнил «рядом с добавить фото».
Это прямое решение о композиции, повторного согласования того же расположения нет.
Root применил openspec-update-change, product-copy-editor и design-system-publish.

Изменены UX, memories contract, реальные состояния прототипа, authority hashes,
общая версия и три зарегистрированных manifest. Web desktop/mobile разделены
на самостоятельные композиции; native permission/saving/partial не скрыты.
Inputs не сужались ради готовности. Опубликована component.button.borderWidth
из существующей границы secondary: одинаковое место под границу у обеих кнопок
устраняет скачок высоты при переносе текста на320. Новое визуальное значение
не введено.

Прежние reports/evidence остаются с исходными hashes. Новая публикация открывает
приёмку 4.1.0; не означает автоматического pass существующих экранов. Наблюдения
13 iOS UI-тестов и web live текущего дня относятся к своим неизменным build/source.
Проверка новой кнопки и сохранения альбома выполняется после реализации.
