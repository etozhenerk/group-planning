# Proposal

## Why

Пользователь согласовал пять независимых релизов somewhere: backend, web,
monitoring, Android и iOS. Нужны проверенные артефакты конкретного коммита,
пригодные для последующего деплоя или загрузки в магазины.

## What Changes

- Добавить выпуск по тегам component/vX.Y.Z и component/vX.Y.Z-rc.N.
- Разделить сборки API и web, собрать мониторинг (бот и HTTPS-probe) вместе.
- Подготовить подписанные Android AAB/APK и iOS archive/IPA/dSYM через секреты CI.
- Добавить манифест, SHA256, отчёт проверок и публикацию GitHub Release.
- Сохранить бот, документацию метрик и инструкции последующего развёртывания.
- Отделить публикацию артефактов от включения production и отправки в сторы.

## Capabilities

### New Capabilities

- `component-release-artifacts`: независимые воспроизводимые выпуски компонентов
  с проверяемой привязкой артефактов к коммиту и настройками подписи.

### Modified Capabilities

Нет. Связано с deployment-and-store-release и telegram-monitoring-bot;
их незавершённые проверки production не объявляются выполненными.

## Impact

Затронуты CI, scripts/release, конфигурация сборки Android, скрипты iOS,
infra/telegram-bot и документация. API/UI приложений не меняются; UX неприменим.
Ключи подписи пока не подтверждены владельцем. Backend использует память:
артефакт сервера не является разрешением принимать реальные данные.
