Старые проверки доменных прав, идемпотентности, ревизий, hidden/anonymous,
большинства, outbox и частичного сохранения не удаляются. Новые ожидания
выведены из принятого UX, а не из текущего вывода приложения. Case source hash
меняется после пересмотра сценария; массового обновления hash ради gate нет.

Фактическое здоровье baseline: web:check после технического исправления
типизации диагностического callback и пустой строки проходит (52 файла,
231 unit-тест); API — 82 схемы/38 fixtures/558 реальных HTTP-ответов;
qa:test — 23/23. Первые sandbox failures сохранены отдельно: loopback и IPC
были запрещены до запуска тестируемых действий. Повтор с нужным доступом
сохранён в новых logs, исходные ошибки не стёрты.

Native UI, реальный OAuth/сохранение, desktop pixel-регрессия и новая мобильная
композиция не принимались. Их automation health для новых UI-ожиданий остаётся
unknown/manual до воспроизводимых assertions и реального runner. Наличие
исторического теста не объявляется новой стабильной автоматизацией.

Каталог содержит 451 кейс без source/scenario/hash gaps; текущий manifest
содержит 58 продуктовых задач, 36 исключений и 327 уникальных cases. Отдельный
paused map-manifest — 8 будущих задач и 9 TC-MAP. Прежний глобальный qa:check
выявил устаревшие планы других изменений. Приёмочные галочки с доказанным
несовпадением catalogHash/недоступным планом открываются заново с preimage и
причинами в baseline/stale-acceptance; сами планы/run/evidence не переписываются.
Явная пауза сохраняется. Нового product pass этот аудит не создаёт.
