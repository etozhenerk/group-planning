# Общая мобильная основа · вход единой публикации

Область: iOS, Android, mobile web. Поздние решения из ux.md и
approved-designs.json имеют приоритет над буквами, текстовыми Back и плавающим
действием в ранних snapshots. Публикация в общие contracts/tokens выполнена единым пакетом6.1.0 в 2.12.

| Элемент | Контракт | Источник значений |
| --- | --- | --- |
| Back | Один тонкий шеврон без видимого слова, постоянного фона/рамки; контекстное доступное имя. Focus/pressed заметны. История сохраняет день/период/scroll/черновик | navigation-r2/PageBack; target.web/ios 44, android 48; icon 24, stroke 1.7, motion.fast |
| mobileSheet | Одна активная поверхность; дочернее содержимое заменяет её, не открывает второй modal. Нет лишнего Back/крестика. Handle/системное закрытие/dirty guard, возврат фокуса | component.mobileSheet, radius.sheet, motion.mobileSheet и принятые settings-r3/help-r2 |
| Условный sticky | Только при фактическом закреплении на scroll: x0/right0/bottom0, верхние углы, тень вверх, резерв измеренной высоты. Общая ошибка рядом с действием. Safe area входит в высоту | create-r4; существующие radius.sheet/цвет поверхности; новые mobile-роли тени публикуются по источнику |
| Короткая форма | Действие в потоке, без отдельной подложки/тени/верхних углов. Пересчитать overflow после IME/resize/крупного текста | vibe-r3/help-r2 |
| Обязательность | Видимая звёздочка и общая легенда; постоянный label. Ошибка у поля, aria-describedby/invalid и фокус первого ошибочного поля | create-r4/settings-r3/date-r1/place-r4/preparation-r1/help-r2 |
| Ошибка/unknown | Один связанный статус; поля и подтверждённые данные сохраняются. Unknown не становится отменой/успехом; повтор использует существующую идемпотентность | Действующие API и последние формы; без новых fixture-таймеров в продукте |
| Фото/силуэт | Публичный avatar_url проходит mapping/session/cache до всех мест идентичности; один человек — одно фото. При отсутствии/ошибке нейтральный силуэт той же геометрии. Контакты владельца не копируются в публичную модель | info-r2/profile-r2; существующая геометрия Avatar, component.participants/chat; локальные фото только demo fixtures |
| Шрифты | Системный stack, исходные утверждённые размеры/веса; web input минимум16, native sp/Dynamic Type, без hard cap обычного текста | typography.*; новые mobile-роли добавляются без изменения desktop-ролей |
| Safe area/IME | Insets из платформы, не из рамки Stageshow; доступно последнее поле/действие, фон/черновик сохраняются | platforms.md, visualViewport/SwiftUI/WindowInsets |
| Motion | Действие сразу меняет цель; выход retained до завершения; быстрый повтор не теряет поверхность/фокус. Reduced Motion без декоративных сдвигов | motion.navigation/cover/mobileSheet/fast и ux каждого пакета |

Реализации используют собственные компоненты, маршруты и API. Изолированный
адаптер reference-source/normalize.ts обслуживает только производные макеты;
его DOM-правки не переносятся в приложение. Он сохраняет обработчики примеров,
заменяет старые буквенные fallback и видимый текст Back. Остальные формы
выбраны из последних navigation-r2/принятых пакетов со своими исправлениями.

Web boundary: `(width < 740px), (pointer: coarse) and (height <= 500px)`
по текущему useMobileLayout и токенам. Перед переносом перепроверить фактический
component breakpoint; новый mobile CSS/варианты не меняют desktop-токены,
desktop route и прежние значения. Регрессия — 740/1100/1440 и coarse landscape.

Публикационная проверка включает исходные hashes, отдельные формы/state/viewport,
фото/отсутствие/broken URL, 30 участников, большой текст и IME. Наличие этого
контракта не означает готовности работающих клиентов.
