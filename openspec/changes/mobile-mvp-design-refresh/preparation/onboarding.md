# Знакомство · freeze 04.11.2026

Пользователь выбрал: «Принять тексты onboarding-r5, сохранив композицию r4 и
общие коррекции». [Восемь страниц](onboarding-copy.json) извлечены из сохранённого
r5, с hash источника. Это тексты будущей реализации всех трёх клиентов;
отдельной регистрации, профиля и справочных страниц в знакомстве нет.

[Производный макет](references/onboarding/frame.html) сохраняет реальные примеры
r4/r5, убирает видимое «Назад» в пользу общего шеврона и буквенные fallback
в пользу силуэта. Исходные r4/r5 не переписаны. Слайды при нехватке высоты
прокручиваются внутри области над действиями; кнопки остаются доступны.
Служебный query `platform=web|ios|android` показывает адаптацию hit area;
это web-render макета, не native-приёмка.

Web: 320/390/739 CSS px, браузерная история, доступные кнопки/клавиатура,
safe-area и visualViewport, без искусственного native splash. Desktop 740+
и действующая coarse-pointer/низкая landscape ветка проверяются отдельно.
iOS: SwiftUI pager, системная отмена Яндекс ID, safe area/Dynamic Type/VoiceOver.
Android: pager, system Back, Activity recreation/WindowInsets/fontScale/TalkBack.
Подписи действий совпадают. Фиксированные верхние отступы телефонной рамки
не копируются в приложения вместо фактических insets.

Pager — motion.navigation 260 ms; основной объект примера сохраняется.
Оседание приглашения/принятой задачи 12 px и приход второго фото 12/16 px —
motion.cover 280 ms. Текст не масштабируется. Новый выбор прерывает старое
доведение, pointercancel возвращает текущую страницу; вертикальный scroll
не становится перелистыванием. Reduce Motion убирает декоративное движение,
сохраняя кнопки и читаемость. Вся интерактивность внутри примеров inert,
кроме явно демонстрационного переключателя списка/календаря.

Редактура: каждый заголовок называет отдельное действие, пояснение добавляет
условие/следствие. Различия большинства даты и места и явного принятия задачи
сохранены. Подпись об отдельной регистрации оставлена на последней странице;
дублирующие рубрики r4 не возвращаются. Служебные сообщения «Демо» и внешние

возможностей сверяется по реальному кандидату перед выпуском.
