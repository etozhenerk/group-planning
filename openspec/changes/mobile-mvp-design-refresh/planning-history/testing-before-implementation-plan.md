## Риски и пирамида

- Unit: пределы quintic rotation, один законченный оборот, переходы выбранной страницы и защита повторного нажатия — расширить существующие тесты только при изменении соответствующей логики.
- Integration: сохранение OAuth return-context, отмена/повтор, восстановление сессии и обособление приглашения — переиспользовать существующие проверки, добавлять регрессию при фактическом изменении.
- E2E/ручной проход: темы встреч → вход → личные встречи; приглашение → вход → исходное приглашение; доступность и визуальная приёмка по отдельным состояниям. В r4 одобрены восемь шагов без профиля/сервисных тем. Не дублировать все правила серверных голосований в онбординге.
