## Общие коррекции

- Фото из avatar_url во всех местах идентичности; при отсутствии/ошибке нейтральный силуэт, не буква и не чужое демонстрационное фото.
- Общий тонкий шеврон navigation-r2 без видимого Назад/постоянной подложки; sheet не получает лишний Back.
- Sticky только при фактическом закреплении во время прокрутки: три края вплотную, только верхние скругления, тень вверх, reserved space.
- Заметная звёздочка и легенда обязательных полей; полевая ошибка связана с полем; общая ошибка/unknown возле действия, без дублей.
- Подписи кнопок одинаковы на платформах; реальные механизмы сохранения/входа/клавиатуры учитывают клиент.
- Desktop от 740 CSS px сохраняется; исключения landscape/coarse-pointer остаются по действующему routing-контракту.

Старые HTML могут содержать прежний Back или инициалы. В 2.4–2.11 подготовить производные эталоны с этими уже принятыми коррекциями; исходники/hash не переписывать. Публикация 2.12 связывает нормализованные референсы, tokens/contracts и каждое состояние/платформу. Существенные новые визуальные решения проходят цикл revisions.md. Дальнейшая реализация читает опубликованные manifests, а не выбирает произвольный HTML из assets.

## Исключено

- **flow-r1** — Доработка и проверка остановлены пользователем «забей». Не эталон, не реализация, не evidence.
- **account-deletion** — Пользователь выбрал оставить скрытым. Не добавлять вход, существующий API не удалять.
- **rejected-and-superseded** — Остальные ранние варианты сохранены как история, не выбирать по новизне имени или открытой вкладке.

По решению пользователя карты вынесены в [отдельную проработку](../meeting-place-picker/proposal.md). Исходные create-r5/place-r4 сохранены; производные формы используют ручной ввод без входа в picker. Предложение provider-ссылки About не принято и не публикуется.
