## Ограничения инструментального прохода

Первый опыт с browser clock на дальнюю московскую полночь пересёк клиентский срок сессии. Снимки `chromium-midnight-before/after` содержат sign-in и не засчитаны как проверка полуночи. Повтор в отдельном свежем контексте с ближайшей полночью Europe/Kaliningrad остался внутри session TTL и дал реальные наблюдения выше. Identity clock fixture не менялся; meetings clock восстановлен.

Один ранний QA driver завершился из-за `Route is already handled` у отменённого отложенного fault-запроса. Driver перезапущен с продолжением того же журнала; backend8861 не перезапускался, ранние доказательства сохранены. Эта ошибка инструмента не выдаётся за ошибку продукта.

Карты и VoiceOver не проверялись по решению пользователя. AX/keyboard/motion и browser zoom не являются проверкой озвучивания. Релизная приёмка и iOS/Android не входят в этот прогон.
