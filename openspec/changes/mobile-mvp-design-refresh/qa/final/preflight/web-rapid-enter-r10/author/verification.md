# Авторская проверка веб-поправок R10

Независимый R9 выявил две ошибки: область слайдов обнулялась при настоящем Chrome zoom200%, а позднее сохранение выделения возвращало уже отправленный черновик. Содержимое знакомства теперь имеет минимальную высоту из опубликованного токена и цепочку вертикальной прокрутки до действий. Сохранение выделения проверяет ревизию в транзакции; обычный ввод нового текста сохраняется. Неиспользуемый старый useMessageDraft удалён.

Регрессия добавлена в существующий сценарий RSVP: быстрый fill→Enter→accepted→пустое поле, повторный вход/перезагрузка и ровно одно сообщение в серверной ленте. До правки сценарий390 упал на старом тексте; после правки оба выбранных сценария390 прошли. Независимый post-CAS проход подтвердил это на320/390/739/740/1100/1440.

Авторские проверки: web:check —274 теста/62 файла; production-сборка, agent:check, design:check67 и diff --check пройдены. Полная новая приёмка использует web-r10; продуктовые задачи веба остаются открытыми до актуальных независимых отчётов и gates. Исходные R9 negative и preflight CSS сохраняют свои hashes; их pass не переносится в новый общий план.
