# Web R6 — экран приглашения

Сводка исполнителя по независимой приёмке задач 8.7 и 8.10.
[Финальный функциональный gate](invitation-root-task-ready-r6.json) подтверждает
40 применимых checks; [дизайн-отчёт](../design/mobile-mvp-invitation-web/design-review.json)
содержит 64 проверенных состояния. Все шесть обязательных suites и ранее принятые
13 checks сохранены без изменения.

Проверены роли, вход и исходный контекст ссылки, явные ответы, права после смены
ответа, закрытие участия, точная часовая граница, date-only, stale response,
обложка/Share и metadata без JavaScript. Действительная старая 43-символьная ссылка
проверена на отдельном loopback fixture с той же неизменяемой web-сборкой;
его источник и остановка записаны в evidence. Основной fixture сохранён.

[Публикационный список](invitation-publication/staging-files.json) содержит только
проверенные доказательства этого пакета. Остальные экраны и полный каталог этой
приёмкой не закрыты.
