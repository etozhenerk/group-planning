# Авторская регрессия общей нижней панели ·6.3

iOS: clean build/analyze, common-navigation r2 (обычная навигация и системный
Reduce Motion) и navigation-type с настоящим максимальным Dynamic Type прошли.
Первый common-navigation r1 дошёл до формы и не нашёл прежний тестовый label
«Закрыть»; локатор заменён на принятый «Вернуться к встречам», действия/проверки

вопреки росту подписи. Системный размер текста и keyboard preference восстановлены.

QA/instrumentation прошли; common-navigation на emulator-5554 —1 test pass.
Проверены движение текущего индикатора/реверс, системное отключение анимации,
переходы профиля/service/создания. Старые журналы ошибок форматирования сохранены.

Снимки ios/native-tabs-stable.png, ios/navigation-type-large.png и
android/common-tabs-reduced-profile.png просмотрены агентом. Панель прилегает
к нижнему/боковым краям, только верхние углы; системный нижний inset внутри
фона. При крупном iOS-тексте подписи растут/переносятся, контент прокручивается
над панелью. Первичные screenshots не редактировались; checksums рядом.
