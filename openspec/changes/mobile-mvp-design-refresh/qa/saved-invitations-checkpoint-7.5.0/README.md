# Экранный checkpoint: приглашения

Перенесён invitations-r2 на iOS и Android: счётчик, постоянное пояснение,
карточка с автором и действием «Изменить ответ», загрузка, пустое состояние,
первичная ошибка и ошибка обновления с сохранением карточек. Mobile web
проверен на существующей реализации. Desktop не переработан.

Независимые проверки поведения: web/checkpoint-review.md,
ios/checkpoint-review.md и android/r2/smoke-report.md. Исправление перекрытия
автора и действия при крупном шрифте: ios/r2/checkpoint-review.md.
Последняя коррекция нижней навигации независимо прошла на ios/r4 и android/r3:
на узком экране с крупным шрифтом подписи целые, тапы и footer доступны;
исходные candidates и отрицательные результаты сохранены отдельно.

Авторские проверки сборки и целевых сценариев находятся в author.
Android QA/test APK собраны; iOS saved-error с крупным шрифтом прошёл.
design:check проверил структуру67 manifest; agent:check и git diff --check
прошли. Это промежуточный экранный checkpoint, не итоговые design:ready и
qa:ready. Продуктовые checkbox остаются открытыми до финального кандидата.
Карты и VoiceOver исключены по решению пользователя.
