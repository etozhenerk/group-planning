## Подтверждённый дефект

### WEB-MEETINGS-R1-001 — выходной цвет карточки в WebKit

`TC-LIST-6BAF1838/web-meetings-webkit-responsive/manual`: **failed**.

В WebKit субботняя встреча24.10.2099 Europe/Moscow имеет `data-weekend=false` и сливовый фон `rgb(56,49,61)` вместо серо-зелёного. В API этой же встречи `starts_on=2099-10-24`, `starts_at=2099-10-23T21:00:00Z`, `timezone=Europe/Moscow`; подпись UI правильно показывает «Сб,24 октября». Повторено в списке и календаре, на мобильной и широкой композиции. Chromium различает пятницу и субботу правильно.

Воспроизведение: войти как Саша → открыть календарь `?view=calendar&period=upcoming&upcoming=2099-10-24` → открыть/прокрутить карточку «QA chromium плотный1» → сравнить её с пятницей23 октября в списке. В WebKit runtime `Intl.DateTimeFormat('ru-RU',{weekday:'short'})` возвращает `Сб`, а `MeetingCard.tsx:27` сравнивает ненормализованное значение с `['сб','вс']`. Это объяснение подтверждено чтением кода и отдельной runtime-записью `Intl weekday audit`; продукт не исправлялся.

Доказательства: [скриншот](run/evidence/webkit-defect-weekend-plum.png), записи `Weekend exact card`, `Weekend date API projection` и `Intl weekday audit` в журнале. TC-LIST-AB3EFA81 подтверждает совпадение обложки/организатора/аватаров между представлениями; этот pass не отменяет failed цветового кейса.
