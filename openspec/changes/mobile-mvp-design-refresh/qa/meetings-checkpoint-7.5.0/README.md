# Экранный checkpoint списка и календаря · 7.5.0

Промежуточная реализация по ускоренному экранному циклу пользователя. Продуктовые задачи и полные актуальные gates остаются открытыми до общего финального кандидата. Source/artifact hashes приведены отдельно для каждого прохода; прежние pass не перенесены на новый hash.

Web: обновлено пустое состояние прошедших; независимый R2 проверяет его и настоящее непрочитанное2→3→read→0 на Chromium/WebKit. Остальной короткий исходный smoke хранится отдельно.

Native: одна кнопка переключения вида, закреплённые заголовок/периоды, нижняя подпись непрочитанного, новые пустые/error/refresh состояния, плоский календарь с36pt/dp выделением и точками. Удалены прежние неиспользуемые компоненты и XML-мосты старого переключателя; generated XML обновлён генератором.

Авторские проверки: web check261/build; Android Debug/Release/Lint/unit и QA APK перед последними геометрическими исправлениями, затем новый QA APK/testAPK и формат для исправленного варианта; iOS clean build/analyze перед последними состояниями, затем сборки UI-host и четыре calendar-сценария. После исправления календаря три обычных сценария passed; оставшийся large-text сценарий отдельно passed после исправления QA-helper: целевой день полностью видим над нижней панелью перед нажатием. Полный clean/regression повторяется на финальном кандидате. Логи в author/ сохраняют фактический объём и не заявляют большего.

R1 native-замечания и исходные hashes сохранены; R2 Android и R3 iOS проверяют изменённые места. Ограниченный checkpoint не заменяет полную независимую приёмку manifest. Карты и VoiceOver исключены текущим решением пользователя. Desktop web сохранён.
