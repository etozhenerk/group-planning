# Проверка текстов состояний

Применён проектный product-copy-editor. Область — новые состояния
[UX v1](ux.md), не редактура соседнего согласованного дизайна.

| Блок | Вопрос пользователя / действие | Решение |
| --- | --- | --- |
| Загрузка | Нужно ли ждать и где? | Визуальный скелетон в загружаемом месте; текст только для доступности |
| Соединение | Почему обновлений нет? | Один статус; не дублировать его на каждой строке; не называть любую ошибку отсутствием сети |
| Исходящее | Сохранено ли сообщение и можно ли повторить? | Различаем локальное сохранение, ожидание, серверный ACK и ошибку; «успешно» удалено |
| История | Продолжать чтение или перейти к новому? | Количество на одной кнопке, сохранение позиции, без отдельного баннера |
| Read receipts | Кто из участников прочитал? | Имена в одном sheet, без контактов и неподтверждённого времени |
| Пустой чат | Как позвать участников? | Существующий блок приглашения; дополнительный текст не добавляем |
| Ошибка outbox | Можно ли закрыть приложение без потери? | Не обещаем сохранность до успешной записи на устройство; текст остаётся в редакторе |

Реестр строк находится в ux.md и используется всеми тремя клиентами.
Соседние строки проверены в текстовых эскизах: каждый блок имеет отдельное
назначение, ошибки сохраняют действие повтора. Проверка переноса, размеров,
screen reader и работающего UI ещё не выполнена и включена в задачи клиентов.
