# Подготовка публикации web outbox, 27.10.2026

Разрешённое состояние UX v1: одна строка с ключом actor/client_request_id в timeline;
ACK меняет данные этой строки. Composer не содержит отдельной копии очереди.
Основа — опубликованная 2.3.0; raw копирует её tokens/chat/panels без новых значений.
[Макет](assets/2026-10-27-web-outbox/index.html) принимает состояния
queued, uncertain, rejected, accepted, storage через ?state=; размеры 390×844 и 1280×800.
[Входы публикации](assets/2026-10-27-web-outbox/publication-input.json) содержат hashes.

Затронут контракт chat-actions: сообщение в timeline; одинаковые bubble/avatar;
до ACK реакции не открываются; успешное сохранение не обозначает прочтение.
Ошибка локального сохранения находится у composer, поле сохраняет текст и selection.
Возврат отклонённого текста доступен только при пустом draft: новый текст не заменяется.
Состояние uncertain сообщает «Проверяем отправку»; rejected даёт «Повторить».
Отдельная строка «Успешно» не добавляется. Новые read/unread UI не входят.

Карта текста: состояние у исходящего отвечает «что с этой отправкой»; ошибка у
composer отвечает «сохранилась ли попытка» и не дублируется в пузырьке.
Существующие названия composer/реакций сохраняются. Это применение product-copy-editor.

2.4.0 опубликована только в изолированной worktree и не даёт design:ready.
Общая публикация и registry/manifest переносятся с основным агентом при интеграции,
чтобы не инвалидировать идущее независимое motion-ревью 2.3.0 в main.
Проверка actual UI и hashes остаётся обязательной после внедрения состояния.

## Интеграция в основную рабочую копию

Срез 6f7b3a4 перенесён вместе с DS 2.4.0. Сохранено уточнение пользователя о
телефонном iOS: hardware Escape не заменяет проверку кнопок, жестов и возврата
экранной клавиатуры. Authority hashes обновлены для соответствующей правки UX
и сценариев; макеты и значения токенов не менялись. Старые отчёты сохранены.
Независимые functional/design gates остаются открыты.

## Уточнение публикации2.4.1

Первоначальное название «web outbox — изолированная публикация» описывало
рабочую копию исполнителя. Продуктовое решение UX v1 изначально охватывает
web/iOS/Android (задачи4.2,5.1,6.1). Контракт и manifest теперь перечисляют
нативные состояния явно. Макет, порядок элементов и значения токенов неизменны.
Native использует собственные опубликованные bubble/insets и Dynamic Type;
каждая платформа требует независимого review и проверки сохранения/ACK.
