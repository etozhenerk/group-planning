На коммите `f59e6a08` GitHub Repository остановился на `qa:check` с
`Stale implementation inputs`. Ошибка воспроизведена из `git archive` этого
коммита. Сравнение путей и содержимого `backend`/`contracts` выявило единственную
разницу: игнорируемый приватный dotenv-файл присутствовал только локально.
Его содержимое и контрольная сумма здесь не сохраняются.

соглашению Git, сохраняя `.env.example` и `.env.*.example`. Регрессионный тест
проверяет одинаковый отпечаток чистого checkout и рабочего дерева с локальными
настройками, а также инвалидирование при изменении примерной конфигурации.

`frontend/ios/Config/Local.xcconfig`, Android `local.properties`, состояния IDE
`.idea`/`.vscode` и кэша `.kotlin`. Они исключены по уже существующему `.gitignore`.

contracts и трёх клиентов нет ни одного файла, игнорируемого Git. Новый regression
проверяет именно воспроизводимость native-конфигурации, а не значения секретов.
