# Независимая приёмка backend b973 — SQL ожидает разрешения

Кандидат `b973b3f7b69392fe808a4b98975b51af7e76f1c7`. Новый формальный план создан до этого прогона. Свежие проверки записаны в `runtime.jsonl`: 70 верхнеуровневых тестов passed, 2 SQL helper tests явно skipped без DSN. Эти skips не считаются функциональной приёмкой SQL.

В `run.json`: **19 passed, 5 blocked**. Обязательный `backend-unit-integration` suite passed; лог сохраняет факты кеширования отдельных пакетов. Независимые probes выполнялись с `-race -count=1`.

Новые runtime probes закрыли истечение и отзыв сессии с повторным доступом; отзыв RSVP после hint при задержанном HTTP; сбор диагностики timeout/reset/storage read/write/panic без содержимого и credentials; восстановление 100 изменений при модели RTT 150 мс. Пятиминутный offline задан управляемыми часами приложения, истечение broker recovery — явным fixture hook. Отдельно выполнено успешное broker recovery, после которого всё равно запрошен HTTP catch-up.

Для SQL подготовлены два бинарника с неизменным production source b973. Полная матрица дополнена p95 страниц на 1k/10k/100k, limit 1/50/100, и отдельными процессами: commit→аварийный выход, API restart, публикация→аварийный выход до ACK, повторный drain того же event ID. Дополнительно подготовлены удаление аккаунта с активными соединениями, доставка durable terminal hint после нового процесса, имитация writer без journal и сброс cursor после смены epoch.

Автоматическая проверка дважды отклонила загрузку этих binaries на проектную VM, потребовав явного разрешения на payload и адрес назначения. Основной агент запросил это подтверждение у пользователя. Ни один новый SQL-запуск пока не произошёл; локальные SQL-бинарники и guarded harness готовы, production и существующие облачные данные не менялись.

`source-parity-b973.json`: 213 production inputs, включая embedded SQL и emoji, совпадают между MAIN и git-archive. `source-integrity.json`: исходные файлы snapshot не менялись; добавлены только test probes. Все действия и expected/actual перечислены в `interaction.json`. `qa:ready` пока возвращает incomplete из-за пяти SQL-зависимых кейсов. Готовность всего изменения или релиза не заявляется.
