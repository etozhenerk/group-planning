# Исправления web по независимому ревью · 28.10.2026

Исполнительский checkpoint; независимая приёмка финального кандидата и полный
релизный gate ещё не завершены. Production и пользовательское demo8445 не менялись.
Источник композиции — принятая Telegram-ревизия дизайн-системы 2.5.1;
новых UI-решений, цветов или бизнес-ролей этим исправлением не введено.

## Что исправлено

- Форма даты: заголовок, подписи вариантов/пяти переключателей/срока, день недели
  у вариантов, положение иконок календаря/времени и chevron приведены к raw.
  Дата окончания остаётся без дня недели; timezone и валидация сохранены.
- Dialog сохраняет заголовок вместе с содержимым до конца exit-анимации.
  Закрытие панели места/задачи/фото/файла больше не подставляет заголовок даты.
- Панель задачи показывает текущую роль, автора с аватаром, адресата/исполнителя
  и реальное created_at из API. Действия и статусы совпадают с raw; primary и danger
  используются также на desktop. Подтверждения и серверные права не менялись.
  Карта текста: header называет задачу; статус отвечает за текущее состояние;
  факты показывают автора, адресата и время; кнопки называют доступное действие.
- Full-picker реакций заново измеряется после раскрытия из quick-picker.
  При недостатке места сверху он располагается снизу с доступной сеткой;
  подробности и hashes — [reaction-placement/result.json](reaction-placement/result.json).

не перезапускались. Первоначальный candidate-run01 был записан до выделения

## Последняя коррекция и текущий freeze

Независимый reviewer дополнительно обнаружил отсутствие внутренних отступов в
preview/error загрузки. Для фото/файла/приглашения используется обычное тело Dialog
с опубликованным inset; собственная раскладка с отдельным footer остаётся у форм
даты, места и задачи. Dialog сохраняет также вид раскладки на весь exit.
Завершённые формы и файлы очищаются после закрытия: подтверждённое содержимое
не исчезает посреди анимации, повторное открытие даёт новую пустую попытку.

Полный full-run01 дал 196 pass, 4 fail, 1 skip. Разобраны все четыре:
устаревшее число иконок даты; два отсутствующих fixture path из-за запуска не из
frontend/web; подготовленная встреча за первой страницей общего списка из 54
записей. Во втором запуске проверка отцентрирована на двух принятых иконках,
working directory правильная, setup встречи ищется через существующую пагинацию.
Ни одна пользовательская проверка scrolling/focus не исключалась.
