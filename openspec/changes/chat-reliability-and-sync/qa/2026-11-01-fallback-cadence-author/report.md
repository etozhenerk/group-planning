# Исправление расписания fallback

Основание — действующий `protocol.md:91` и независимый
[web FAIL на 949d](../../../meeting-experience-refresh/qa/2026-11-01-web-transport-independent/report.md).
При исправном HTTP без WebSocket web постоянно возвращался к трём секундам;
при HTTP-ошибках получался лишний шаг 24 секунды. Такой шаг был и на native,
а iOS дополнительно накапливал ранее применённый jitter.

Исправлены три планировщика. Базовые интервалы — 3, 6, 12, 30 секунд,
затем 30 с прежним допустимым jitter. Web сбрасывает попытку только после
подписки и успешного catch-up; прежний HTTP-only режим сохраняет три секунды.
На iOS базовый интервал хранится отдельно от случайного множителя.
Начальная grace-пауза и существующие lifecycle/lease границы не менялись.
API, SDK pins, каталог кейсов и опубликованный интерфейс не менялись.

Регрессии наблюдают границы реальных вызовов владельца состояния и HTTP:
web проверяет работающий/неработающий HTTP, legacy cadence и остановку;
Android расширяет виртуальный lifecycle-тест на весь ряд и восстановление;
iOS использует настоящий FeedOwner с шестью mock HTTP-ответами и внедрёнными
MainActor sleep/random. Последний проверяет общий scheduler, не объявляется
SDK end-to-end сценарием. Фактические SDK/UI проверяются отдельно.

[Точные шесть файлов](candidate-files.json) заморожены после форматтеров.
Авторский web targeted: 8/8 PASS. Независимые проверки выполняются на новых
планах; прежние полные web/iOS/Android результаты сохранены с исходными hash.
Пункты web 1.1/4.1 временно открыты до новой квалификации текущего source.
Серверные принятые задачи на неизменных 413 inputs сохраняют свои доказательства.

## Уведомление во время catch-up

Дополнительный независимый контроль воспроизвёл потерю hint: GET завершался
через 50 мс, а его успешный cleanup отменял coalesce на 100 мс. Более новая
запись оставалась непрочитанной даже через секунду. Исходный FAIL и частично
исполненный пакет сохранены в
[отчёте гонки](../2026-11-01-web-hint-race-independent/report.md).

Очистка fallback poll/grace отделена от coalesce. Успешный GET сохраняет
полученное уведомление; остановка владельца по-прежнему отменяет все таймеры.
Проверены оба порядка завершения GET (50/150 мс) и отмена уже поставленного hint
при stop. Авторский targeted теперь 11/11; ESLint, Prettier и diff-check прошли.
Ожидания/каталог не менялись. Первоначальный отказ линтера из-за пустой строки
и частичные браузерные прогоны не объявляются полным PASS.
