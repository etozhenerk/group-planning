# iOS: прочитанность и состояние проверки

Основной агент, выбранный iPhone 18 Pro / iOS 27.0, Accessibility XXXL.
Финальный readers-a11y PASS 57.722 с: настоящий API, сообщение автора,
ошибка readers → повтор → пустой список; два других аккаунта выставляют
read markers, число становится 2 и список содержит Лену/Мишу без контактов.
Настоящий VoiceOver читает заголовок, empty и оба имени; composer под панелью
не попадает в речь. Транскрипты и просмотренные actual сохранены рядом.
После выключения VoiceOver обычный swipe закрывает панель; сообщение сохраняет
Y с допуском 2 pt. Ошибка/empty сохраняют viewport с допуском 1 pt.

5.4 остаётся открытым: именно жест Escape VoiceOver и возврат его фокуса
к исходной строке не подтверждены. Публичный XCUITest VoiceOverService умеет
читать/перемещать фокус, но не выполняет Escape. Эксперимент через UIKit
закрывал другой уровень контейнера и непригоден как доказательство поведения
SwiftUI action. Экспериментальная обвязка и неподтверждённая правка приложения
удалены. Начальная проверка с выключением/включением службы также не доказывает
возврат фокуса. Неуспешные журналы оставлены локально, PASS им не присвоен.
VoiceOver восстановлен в выключенное состояние; Mac для ручного жеста недоступен.

5.5: устройство владельцев/адаптеров/защищённого хранения сверено с UX v1 и
docs/chat-runtime.md. Отдельная строка pending, локальная ошибка, ограниченное
окно и read visibility имеют unit/UI-результаты; полные performance бюджеты
остаются 1.4/1.6/7.9, остаток accessibility — 5.4. README описывает scoped runner.
Production-код после сверки совпадает с 0b09a704: strict format, 213 unit,
чистые Debug/Release и оба analyze от 03.11 применимы без повторного общего прогона.
Свежие QA build/format/readers UI PASS. Физический iPhone не проверялся по решению
пользователя; общий независимый gate, вся клиентская приёмка и release не заявляются.
