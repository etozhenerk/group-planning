# Повтор двух legacy проверок очереди

2/2 Chromium PASS: потерянный ответ сохраняет key и ту же DOM строку,
повтор даёт одну каноническую запись; offline intent отправляется после
возврата сети без дополнительного нажатия, key сохранён после ACK.
Подтверждены согласованные same-row и automatic recovery ожидания.
Это не повтор всего web suite: другие пять failures остаются у исполнителя.
