# Проверка развёртывания 24.10.2026

## Result

Приложение **не развёрнуто**. Владелец разрешил вариант A в бюджете
5 000 ₽/месяц и выбрал `smwhere.ru`; домен покупает самостоятельно.
Вход CLI настроен, но реальный API Yandex Cloud отклонил создание диска:
`ResourceExhausted: Resource allocation is restricted`.
Размещение отложено до разрешения ограничения провайдером. Альтернативная
площадка, другой тип диска или увеличенный бюджет не выбраны.
Пользователь сам отправляет обращение в поддержку; агент его не отправлял.

## Verified

- Открыта консоль владельца; ВМ и дисков перед началом нет. В каталоге есть
  чужие сети, подсети, DNS и политики копирования — они не изменялись.
- Консоль предупреждает об ограниченном режиме облака. В ru-central1-a
  доступны квоты 2 vCPU/16 ГБ RAM; квота SSD повышена с 25 до **40 ГБ**
  запросом `BC213813091`, статус «Одобрено». Доступны 2 статических IPv4.
- Реальная форма ВМ: Intel Ice Lake, 2 vCPU 50%, RAM 4 ГБ, SSD 40 ГБ,
  обычная непрерываемая ВМ. Сумма с IPv4: **2 793,25 ₽/720 ч с НДС**,
  совпадает с опубликованной сметой. Это не фактический месячный счёт.
- Terraform **1.14.9**, provider **0.239.0**. Бинарники получены из официальных
  релизов; SHA256 сверены. Реестр/зеркало имели сетевые ограничения, provider
  установлен из официального GitHub-релиза через локальное filesystem mirror.
  Lock содержит проверенную macOS ARM64; Linux ещё не проверен.
- `terraform fmt -check -recursive`, `terraform validate`: пройдены.
- `terraform test`: **4 passed, 0 failed**. Проверены бюджетная конфигурация,
  разрешённые порты, запрет SSH `0.0.0.0/0`, недопустимый закрытый ключ в
  public-key поле, несовпадение зон; cloud-init успешно декодируется как YAML.
- Реальный `terraform plan`: **5 to add, 0 to change, 0 to destroy**,
  существующая подсеть прочитана через API, образ Ubuntu 24.04 закреплён по ID.
- `terraform apply`: созданы IP, security group и service account;
  выделение SSD отклонено провайдером. Зависимая ВМ не создавалась.
- Уборка: проверено отсутствие ВМ/дисков и неиспользуемый IP; удалены только
  эти три созданных ресурса. `refresh-only plan` подтвердил удаление всех трёх,
  его apply синхронизировал state: **0 added, 0 changed, 0 destroyed**, outputs null.
  Платных ресурсов этой попытки не оставлено. Возможно начисление за несколько
  минут резервирования неиспользуемого IP; точный счёт ещё не проверен.
- SQL-проект до реализации: [storage-design.md](storage-design.md).
  Сверены порты `meetings.Store` / `identity.Store`, существующие модели задач,
  порядок атомарных операций и поддержка PostgreSQL 16 managed-сервисом.
  Выбраны текущая SQL-очередь и pgx v5.11.0; запись решения не является адаптером.
- `npm run agent:check` пройден после подготовки инфраструктуры и SQL-проекта.
- Финальная структурная проверка проекта и `git diff --check` пройдены.
  Go/web/native код в этой работе не менялся; проверки соседних изменений
  приложений в этот отчёт не включены.

## Not verified

PostgreSQL-адаптер, миграции, readiness, релиз/systemd/Caddy, Lockbox, копии и
восстановление, Monium, алерты и внешняя проверка ещё не установлены/не реализованы.
Гостевая ОС не запускалась. Нагрузка, RPS, реальные CPU/сеть/диск и RPO/RTO не
измерены. DNS и TLS не настроены, покупка `smwhere.ru` не подтверждена.
Приложение пока использует память. Тесты Terraform не подтверждают сохранность.
Мобильные магазины не публиковались; результаты соседа по авторизации здесь
не объявляются проверкой целевого облачного окружения.
