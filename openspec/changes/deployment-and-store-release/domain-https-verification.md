## HTTPS verification

- `infra/host/Caddyfile.bootstrap-https` и `enable-bootstrap-https.sh`
  сохранены в репозитории и скопированы на ВМ в `/tmp`.
- `bash -n` прошёл; установленный Caddy 2.6.2 успешно выполнил `caddy validate`
  для конфигурации с корневым доменом и Let's Encrypt.
- Скрипт проверяет A/AAAA, сохраняет предыдущий Caddyfile и откатывает reload
  при ошибке. Запуск запрещён, если уже установлен `somewhere.service`.
- Caddy имеет постоянный каталог `/var/lib/caddy` с владельцем `caddy`.
  HTTP challenge доступен через разрешённый порт 80; 443 разрешён security group.

Конфигурация активирована 25.10.2026 в 10:28 МСК. Предыдущая сохранена на ВМ:
`/etc/caddy/Caddyfile.before-https.JcMfpK04`. Caddy `enabled` и `active`.
Журнал подтверждает успешный ACME TLS-ALPN challenge и получение сертификата.

Внешние проверки без отключения проверки сертификата:

- `http://smwhere.ru/` → HTTP 308, `Location: https://smwhere.ru/`.
- `https://smwhere.ru/` → HTTP/2 503, `Retry-After: 3600`, ожидаемая заглушка.
- TLS с проверкой цепочки и имени: SAN `smwhere.ru`, издатель Let's Encrypt YE1,
  срок 25.10.2026 06:29:37 UTC — 23.01.2027 06:29:36 UTC.
- A указывает на ВМ `158.160.246.254`, IPv6-записи нет; заглушка обслуживается
  установленным Caddy на этой ВМ.

Автоматическое продление выполняет Caddy. Проверены постоянное хранилище
`/var/lib/caddy` (владелец `caddy`, права `0750`), запуск службы при загрузке
и успешный доступ ACME извне. Процедура диагностики и сохранения состояния —
