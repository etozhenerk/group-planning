# Проверка планирования

Дата: 24.10.2026. Проверен план `deployment-and-store-release`, не реализация.

Обновление после решения пользователя: закреплены PostgreSQL на общей ВМ,
2 vCPU 50% / 4 ГБ / SSD 40 ГБ, бюджет 5 000 ₽, условия будущего managed-перехода,
нагрузочная методика и план мониторинга с вариантами Grafana/Telegram-бота.
Изменены proposal, design, service-operations, tasks и смета; client-distribution
и руководство магазинов сохраняют прежнее содержание. Новые capabilities не добавлялись.

## Результаты

- `npm run --silent openspec -- status --change deployment-and-store-release`:
  все четыре группы артефактов готовы; обе заявленные capabilities имеют specs.
- `npm run --silent openspec -- validate deployment-and-store-release --strict`:
  успешно.
- `npm run agent:check`: успешно; структура OpenSpec, инструкции и локальные ссылки.
- `git diff --check`: успешно. Новые файлы дополнительно проверены через
  `git diff --no-index --check /dev/null <file>`, поскольку обычный diff
  не включает untracked-файлы; ошибок пробелов нет.
- Арифметика независимо пересчитана с Python Decimal: облако A/B/C —
  2 985,19 / 9 397,51 / 17 087,95 ₽; среднее первого года со всеми магазинами
  и доменом — 4 035,19 / 10 447,51 / 18 137,95 ₽ в месяц при плановых 100 ₽/$.
  Дополнение PNG-бота — 21,95 ₽; A с ним — 4 057,15 ₽/месяц при оговорённом
  свободном объёме Functions. Проверены общий free tier проверки HTTPS/бота,
  запас 20%, отдельный секрет и платное чтение метрик.
- Смета просмотрена как новый Git diff; проверены годовые/разовые платежи,
  отсутствие двойного учёта ВМ в B и двух дисков/хостов БД в C. В B теперь
  сохраняется исходная ВМ/диск, поэтому прежняя оценка с уменьшением узла заменена.
- Ставки и условия проверены по публичным первичным источникам, ссылки находятся
  рядом с расчётами и этапами публикации. Статус инцидента Yandex Cloud прочитан
  в браузере, поскольку статическая выдача этой страницы требует JavaScript.
- Для мониторинга дополнительно изучены официальные Monium, Compute,
  Cloud Functions, Grafana и Telegram: системные метрики, каналы/вызов функции,
  API истории, источники Grafana и требования Image Renderer. Собственные пороги
  проекта и расчётная нагрузка отделены от свойств сервисов и результатов испытаний.

## Ограничения

Облачные ресурсы, аккаунты и домен не покупались; консоли владельца не проверялись.
Доступность конкретной ВМ/квот, активное платное членство Apple, способ оплаты Google
и свободное доменное имя не подтверждены. Нагрузка, сохранность, реальные расходы,
подпись/установка mobile и review магазинов пока не проверены.
Monium, агенты, HTTP-проверка, Grafana и бот не развёрнуты; изображения/уведомления
не отправлялись. Нагрузочный предел, реальное время функций, доступность API
и свободный free tier аккаунта не проверены. Этапы 5/10/20/50 RPS — план испытания.

Тесты и сборки приложений не запускались: изменены только новые документы этого
изменения. Все задачи реализации открыты. Это не отчёт готовности production.
Файлы авторизации и основной план соседнего агента не редактировались.

Общее дерево `main` содержит активные незакоммиченные изменения другого агента.
План оставлен отдельной новой папкой; commit/push и обновление общей ветки
не выполнялись, чтобы сохранить его незавершённую работу и не обходить правило
обновления чистого `main` перед записью.
