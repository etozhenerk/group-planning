## 3.3 — частично, checkbox оставлен открытым

- Действующая ВМ RUNNING, runtime service account имеет на folder только
  monium.metrics.writer. Для application-секрета — ресурсный lockbox.payloadViewer.
- Входящие правила: TCP80/443 публичные, SSH22 только 95.24.33.238/32.
  Go слушает loopback8080, PostgreSQL — loopback16241 (не5432).
  Внешнее TCP-подключение к обоим реальным портам заканчивается timeout.
- В журнале первого CLI-запроса подтверждены успешный IAM
  CreateForServiceAccount для probe-invoker, затем PayloadService/Get и
  PermissionDenied. Это отказ Lockbox, а не невозможность создать IAM-токен.
- Штатный runtime на ВМ получает HTTP200 от application/oauth/backup secrets,
  но ответы пустые. Метаданные этих трёх секретов не содержат current_version.
  Получение приложением непустой конфигурации из Lockbox не доказано.
- Повторный запрос payload посторонним аккаунтом отклонён автоматической
  проверкой разрешений до исполнения: риск записи секрета на Mac. Обхода нет;
  ранее полученный отказ сохранён только в виде безопасных метаданных ниже.

Никакие payload, IAM-токены, окружение приложения, приватные SSH-ключи или
полные VM metadata в репозиторий не включены. Для завершения 3.3 нужно отдельно
заполнить штатные секреты и проверить реальный путь загрузки конфигурации.
